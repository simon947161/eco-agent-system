# Build Week — Login and Submission Walkthrough

Status: `PUBLIC VIDEO REPORTED / DEVPOST NOT SUBMITTED`

## 1. Required Codex Session ID

This is **Session ID**, not “Section AD” and not a video section.

1. Open the primary Codex thread in which the core ClimateOS functionality was
   built.
2. In the composer, type `/` by itself and wait for the slash-command menu.
3. Select **Feedback** from that menu. Do not send `/feedback` as an ordinary
   chat message; that does not open the feedback dialog or create evidence.
4. Complete the feedback dialog and enable log inclusion.
5. Save the confirmation, any returned identifier, and a screenshot as Build
   Week evidence.
6. Copy the required confirmed identifier into the Devpost field only after
   checking the exact label requested by the live submission form.

Do not substitute a GitHub commit, task number or PR number.

Suggested title:

> ClimateOS Build Week — human-controlled environmental AI scientist prototype

Paste-ready report: `BUILD_WEEK_CODEX_FEEDBACK_DRAFT.md`.

## 2. YouTube account and upload

1. Sign in to the Google account that should own the submission video.
2. Open YouTube Studio: `https://studio.youtube.com/`.
3. If prompted to create a YouTube channel, stop and obtain separate Founder
   approval before creating it.
4. Choose **Create → Upload videos** and select the final Founder-approved MP4.
5. Add the approved title, description and thumbnail.
6. Audience: **No, it’s not made for kids**.
7. Complete copyright/checks screens. Do not add third-party music.
8. Visibility must ultimately be **Public** for judging, but do not publish
   without the separate Founder authorization required by the SATP.
9. After publishing, verify the URL in a private/incognito browser without
   signing in.

## 3. Devpost registration and draft

1. Sign in at `https://devpost.com/` or create an account only after separate
   Founder approval if no account exists.
2. Open the official Build Week page and choose **Join hackathon**.
3. Accept the event terms and finish registration.
4. Choose **Start a project** (or import an existing Devpost project).
5. Complete the project overview, description, category, repository, license,
   video URL, Codex Session ID and all required eligibility questions.
6. Save a draft and review every field against the prepared submission pack.
7. A saved draft is not a submitted entry. Do not press the final **Submit
   project** control without separate Founder authorization.

## 4. Mandatory final checks

- Video is public, below three minutes, and viewable while signed out.
- Current demo and repository match the claims in the submission.
- Prior work and Build Week work are clearly separated.
- No private data or unsupported scientific conclusion is present.
- Repository, video, Session ID, category and license fields are correct.
- Founder has approved the exact final video and exact Devpost preview.
- Submission receipt is preserved after authorized submission.
