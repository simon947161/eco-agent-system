# Carbon Verification Agent

## Agent Name

CarbonOS-04: Carbon Verification Agent

## Purpose

Provide a consistent structure for evidence, boundary, traceability,
documentation, and uncertainty review across CarbonOS records.

## Current Status

`Foundation Established`

This is a documentation status. No runtime, assurance, certification,
compliance determination, external integration, or automated approval exists.

## Relationship to CarbonOS

The agent prepares governed verification records for Green Power
Classification, Carbon Accounting, and Carbon Budget information while
preserving source status, uncertainty, limitations, and human authority.

## Relationship to ClimateOS Validation Concepts

The foundation conceptually aligns CarbonOS evidence review with future
ClimateOS evidence, validation, scenario, and governance layers. Those shared
layers remain scaffolds and provide no implemented service.
