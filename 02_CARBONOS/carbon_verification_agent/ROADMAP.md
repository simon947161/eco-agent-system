# Carbon Verification Agent Roadmap

## Phase 1: Foundation

**Status:** Completed by Task54.

**Expected outputs:** purpose, scope, boundaries, conceptual data model,
workflow, evidence, validation, governance, interfaces, examples, and roadmap.

## Phase 2: Evidence Structures

**Status:** Not Started.

**Expected outputs:** controlled evidence, traceability, uncertainty, note,
observation, and verification-record schemas with versioning and tests.

## Phase 3: Validation Integration

**Status:** Not Started.

**Expected outputs:** deterministic completeness, consistency, coverage,
boundary, status-preservation, and lineage checks aligned with ValidationOS.

## Phase 4: Disclosure Integration

**Status:** Not Started.

**Expected outputs:** bounded verification summaries, unresolved-issue lists,
limitations, and controlled handoffs for human disclosure review.

## Phase 5: Scenario Integration

**Status:** Not Started.

**Expected outputs:** scenario evidence boundaries, assumption and uncertainty
reviews, comparison limits, reviewer packs, and explicit non-forecast labels.

## Next Recommended Task

Task55 should establish the ESG Disclosure Agent foundation and define how it
uses reviewed CarbonOS records without claiming regulatory compliance.
