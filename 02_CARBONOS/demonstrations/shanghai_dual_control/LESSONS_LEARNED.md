# Lessons Learned

## Strengths

- Demonstrates how CarbonOS agents can be connected in one policy-driven
  scenario.
- Keeps evidence, boundaries, uncertainty, governance, and review needs visible.
- Reuses the shared
  [Demonstration Evaluation Framework](../DEMONSTRATION_EVALUATION_FRAMEWORK.md).
- Shows how scenario review can sit after disclosure preparation without
  becoming a forecast or recommendation.

## Limitations

- Uses fictional data only.
- Performs no calculations or quantitative comparisons.
- Does not interpret Shanghai policy or determine compliance.
- Does not create operational records, dashboards, APIs, or runtime workflows.
