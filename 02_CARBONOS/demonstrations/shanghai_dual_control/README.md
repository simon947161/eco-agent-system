# Shanghai Carbon Control Demonstration

## Demonstration Name

Task57: Shanghai Carbon Control Demonstration

## Purpose

Demonstrate how CarbonOS foundation agents may interact in a policy-driven
carbon dual-control scenario inspired by Shanghai carbon management concepts.

## Scenario Overview

The demonstration uses a fictional organisation and facility operating in a
conceptual Shanghai dual-control context. It explores how electricity records,
energy records, green-power information, accounting records, carbon budgets,
verification records, disclosure preparation, and scenario review may connect.

No real company data is used.

## CarbonOS Components Used

- Green Power Classification Agent
- Carbon Accounting Agent
- Carbon Budget Agent
- Carbon Verification Agent
- ESG Disclosure Agent
- Carbon Scenario Agent
- [Demonstration Evaluation Framework](../DEMONSTRATION_EVALUATION_FRAMEWORK.md)

## Current Status

`Demonstration Established`

This is a documentation-only demonstration. It adds no calculations,
forecasting, compliance engine, regulatory interpretation, APIs, or runtime
functionality.
