# Carbon Scenario Governance Notes

## Transparency

Scenario records should state type, boundary, horizon, assumptions,
constraints, unknowns, evidence status, uncertainty, owner, and limitations.

## Traceability

Scenario statements should link to accounting records, budget records,
verification findings, disclosure context, assumptions, and review notes.

## Human Oversight

Humans decide whether a scenario is suitable for planning discussion or future
ClimateOS coordination. The agent provides no autonomous recommendations.

## Documentation Quality

Scenarios should use stable identifiers, versions, clear labels, plain
language, and explicit status values.

## Uncertainty Awareness

Scenarios should not imply certainty, feasibility, priority, compliance, or
approval when the evidence does not support it.

## Prohibited Interpretations

The foundation is not a forecasting model, optimisation engine, AI advisor,
financial advisor, regulatory tool, decision engine, or automated planning
system.
