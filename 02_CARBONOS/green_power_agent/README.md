# Green Power Classification Agent

## Agent Name

CarbonOS-01: Green Power Classification Agent

## Purpose

Provide a consistent, evidence-based framework for classifying electricity
consumption through physical, trading, allocation, or unknown attribution
pathways. The agent foundation supports human review and does not make
regulatory or compliance decisions.

## Current Status

`Foundation Established`

This is a documentation status. No classification runtime, calculation,
external integration, or automated approval capability exists.

## Relationship to CarbonOS

The agent is the first planned CarbonOS agent. It applies the CarbonOS
architecture, conceptual data model, evidence traceability, uncertainty, and
human-review principles to green-power classification. Future reviewed
classification records may become inputs to carbon accounting, carbon budget,
verification, disclosure, and product carbon information workflows.
