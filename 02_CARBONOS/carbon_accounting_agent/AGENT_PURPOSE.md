# Carbon Accounting Agent Purpose

## Purpose

The Carbon Accounting Agent is intended to organise activity, energy, green
power, and emission information into traceable accounting records. It supports
preparation and review; it does not currently calculate emissions.

## Objectives

- define explicit organisational, facility, project, product, and scenario boundaries;
- connect records to sources, periods, units, methods, assumptions, and owners;
- preserve Green Power Classification results and their review status;
- organise future emission and inventory records without inventing factors;
- expose missing evidence, uncertainty, conflicts, and exclusions; and
- prepare human-readable records for later budgets, verification, and disclosure.

## Expected Users

| User | Expected use |
| --- | --- |
| Organisations | Organise reporting-wide activity and inventory records |
| Facilities | Prepare site-level energy and operational evidence |
| Carbon Managers | Review boundaries, methods, records, and uncertainty |
| ESG Teams | Prepare traceable accounting information for review |
| ClimateOS Scenario Users | Use explicitly bounded accounting assumptions |
| Human Reviewers | Check evidence, methods, limitations, and status |

## Use Cases

- organise a single facility's electricity and fuel records;
- separate mixed electricity sources using reviewed classification results;
- structure an industrial site's operational activity evidence;
- consolidate multiple facilities without hiding local gaps;
- organise product-level information under a declared lifecycle boundary; and
- flag incomplete records for further evidence and human review.

## Limitations

Task52 adds no runtime fields, calculations, emission factors, carbon claims,
professional assurance, regulatory interpretation, or external data access.
