# Carbon Accounting Agent Roadmap

## Purpose

This roadmap separates the Task52 documentation foundation from future
implementation and integration.

## Phase 1: Foundation

**Status:** Completed by Task52.

**Expected outputs:** purpose, scope, boundaries, data model, workflow,
evidence requirements, validation, governance, interfaces, examples, and
roadmap. No runtime capability is included.

## Phase 2: Accounting Logic

**Status:** Not Started.

**Expected outputs:** approved method definitions, controlled schemas,
deterministic transformations, factor-interface rules, invalid-input behavior,
human-readable records, fixtures, and tests.

## Phase 3: Inventory Structures

**Status:** Not Started.

**Expected outputs:** versioned inventory records, boundary and period control,
record inclusion and exclusion, reconciliation, uncertainty, review states,
and comparison rules.

## Phase 4: Verification Integration

**Status:** Not Started.

**Expected outputs:** evidence indexes, lineage, validation findings,
exceptions, reviewer packs, and a governed handoff to the future Carbon
Verification Agent.

## Phase 5: Disclosure Integration

**Status:** Not Started.

**Expected outputs:** bounded human-readable disclosure inputs with methods,
evidence, uncertainty, exclusions, review status, and prohibited
interpretations.

## Phase 6: Scenario Integration

**Status:** Not Started.

**Expected outputs:** scenario-labelled boundaries, assumptions, activity and
energy records, future accounting results, uncertainty, comparison limits,
and review packs aligned with ScenarioOS.

## Next Recommended Task

Task53 should establish the Carbon Budget Agent foundation and define how it
consumes reviewed accounting inventories without treating incomplete or
scenario records as operational facts.
