# Carbon Accounting Agent

## Agent Name

CarbonOS-02: Carbon Accounting Agent

## Purpose

Provide a consistent, evidence-based structure for preparing and reviewing
future carbon accounting records across organisations, facilities, projects,
products, and bounded ClimateOS scenarios.

## Current Status

`Foundation Established`

This is a documentation status. No calculations, emission factors, runtime,
external integrations, or automated decisions exist.

## Relationship to CarbonOS

The agent applies CarbonOS scope, data, workflow, evidence, governance, and
human-review principles to carbon accounting preparation. Future reviewed
records may support carbon budgets, verification, disclosure, and scenarios.

## Relationship to Green Power Agent

The agent may consume reviewed Green Power Classification Agent outputs,
including classification status, evidence, uncertainty, validation findings,
and review notes. It must preserve those statuses and must not treat a proposed
classification as verified or approved.
