# Carbon Budget Agent

## Agent Name

CarbonOS-03: Carbon Budget Agent

## Purpose

Provide a consistent, evidence-based structure for future carbon budget
planning, allocation, tracking, variance review, and scenario alignment.

## Current Status

`Foundation Established`

This is a documentation status. No calculations, forecasting, optimisation,
runtime, external integration, or automated decisions exist.

## Relationship to CarbonOS

The agent applies CarbonOS evidence, governance, uncertainty, and human-review
principles to carbon budget records. Future reviewed outputs may support
verification and disclosure preparation.

## Relationship to Carbon Accounting Agent

The agent may consume reviewed Carbon Accounting Agent inventory records,
including boundary, period, method, version, exclusions, uncertainty, and
review status. It must not treat incomplete or scenario records as final facts.
