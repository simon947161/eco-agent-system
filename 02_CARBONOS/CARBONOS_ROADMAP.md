# CarbonOS Roadmap

## Purpose

This roadmap describes controlled maturity phases for CarbonOS. Progression
requires separately approved tasks, evidence, tests where applicable, and
human review.

## Phase 1: Foundation

**Status:** Completed by Task50.

**Expected outputs:** subsystem scope, conceptual architecture, conceptual
data model, workflow, governance framework, official agent catalog, roadmap,
and repository integration.

This phase adds documentation only.

## Phase 2: Agent Definitions

**Status:** Not Started.

**Expected outputs:** complete Agent Standard specifications for the planned
Green Power Accounting, Carbon Accounting, Carbon Budget, Carbon
Verification, and Product Carbon Passport agents.

Each definition should declare evidence requirements, fields, assumptions,
validation rules, limitations, and human review authority before code is
considered.

## Phase 3: Scenario Integration

**Status:** Not Started.

**Expected outputs:** bounded scenario templates, declared baseline
conditions, controlled inputs, assumptions, expected outputs, and
human-readable scenario packs that connect approved CarbonOS definitions with
ScenarioOS conventions.

Scenario work must not be presented as forecasts or real-world decisions
without appropriate methods and review.

## Phase 4: Validation Integration

**Status:** Not Started.

**Expected outputs:** evidence checks, controlled validation rules,
uncertainty records, reviewer workflows, test fixtures, and traceable
validation reports aligned with ValidationOS and GovernanceOS.

Passing software tests alone will not imply professional verification,
assurance, compliance, or certification.

## Phase 5: Demonstration Projects

**Status:** Not Started.

**Expected outputs:** bounded, human-readable demonstration packs using
reviewed sample data, explicit assumptions, documented limitations, and clear
separation between demonstration and operational capability.

Demonstrations may show how components fit together but must not imply an
operational service.

## Next Recommended Task

Task51 should define the Green Power Accounting Agent using the repository
Agent Standard. It should remain evidence-first, reviewable, and separate from
financial certificate trading or regulatory approval.
