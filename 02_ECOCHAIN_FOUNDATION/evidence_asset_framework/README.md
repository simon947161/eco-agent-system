# Evidence Asset Framework

## Purpose

This folder defines Evidence Assets for ClimateOS.

ClimateOS does not primarily produce Data Assets. ClimateOS primarily produces
Evidence Assets.

## Definition

```text
Evidence Asset =
Reality + Data + Evidence + Context + Validation + History + Confidence
```
