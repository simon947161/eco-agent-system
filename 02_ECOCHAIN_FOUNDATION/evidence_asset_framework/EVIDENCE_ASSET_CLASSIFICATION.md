# Evidence Asset Classification

## Purpose

This document classifies Evidence Assets.

## Physical Evidence

Examples:

- weather observations
- satellite observations
- ecological observations
- sensor observations

## Process Evidence

Examples:

- project logs
- engineering records
- construction progress
- operational performance
- maintenance history

## Governance Evidence

Examples:

- approvals
- audits
- compliance records
- review decisions
- governance actions

## Boundary

No automated classification is implemented.
