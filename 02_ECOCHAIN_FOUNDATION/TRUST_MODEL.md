# Trust Model

## Purpose

The Trust Model defines how EcoChain may support trusted evidence structures.

## Trust Sources

- provenance
- validation
- confidence
- traceability
- source diversity
- review history
- relationship consistency
- governance transparency

## Trust Rule

Trust is earned through evidence history. It is not created by a token,
blockchain label, or platform claim.

## Boundary

No trust scoring algorithm or automated trust assignment is implemented.
