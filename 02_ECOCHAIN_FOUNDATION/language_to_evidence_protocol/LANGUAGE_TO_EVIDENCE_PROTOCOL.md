# Language-to-Evidence Protocol

## Purpose

The protocol defines how language can be transformed into structured evidence
without claiming to solve translation.

## Core Flow

```text
Chinese
English
Arabic
Spanish
Indigenous Knowledge
Future AI Languages
-> Evidence Schema
```

## Principle

Different languages and cultures may describe the same reality differently.
ClimateOS should preserve meaning, context, uncertainty, and cultural notes
before normalizing into evidence structures.

## Boundary

No translation, semantic engine, or automated normalization is implemented.
