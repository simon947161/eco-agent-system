# EcoChain Review Status Model

## Purpose

The EcoChain Review Status Model defines conceptual statuses for EcoChain
readiness.

## Status Values

- Candidate
- Under Readiness Review
- Ready
- Ready With Unresolved Risks
- Not Ready
- Reopened
- Revised After Entry
- Superseded

## Status Principle

Status describes current readiness.

It does not certify permanent truth and does not end ClimateOS Review.

## Status Changes

Status may change when:

- Evidence Asset Validation changes
- confidence changes
- Proof Record is reopened
- RDA context changes
- RWA alignment context changes
- governance context changes
- new evidence appears

## Boundary

No status engine, automated transitions, blockchain status writes, or approval
workflow is implemented.
