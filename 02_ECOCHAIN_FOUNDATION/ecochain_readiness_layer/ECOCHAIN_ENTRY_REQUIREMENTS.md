# EcoChain Entry Requirements

## Purpose

This document defines conceptual information that should exist before an
Evidence Asset enters EcoChain readiness.

## Required Information

- Evidence Asset ID
- Evidence Asset description
- related Evidence Packages
- related Proof Records
- related Reality Claims
- confidence state
- provenance notes
- validation history
- revision history
- governance context
- unresolved risks
- post-entry review path

## Entry Requirement Principle

EcoChain should receive reviewed evidence context, not raw unsupported claims.

## ClimateOS Responsibility

ClimateOS is responsible for continuing review before and after EcoChain
participation.

## Boundary

No entry schema, blockchain transaction, token minting, smart contract, or API
is implemented.
