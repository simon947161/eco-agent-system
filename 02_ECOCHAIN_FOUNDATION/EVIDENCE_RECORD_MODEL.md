# Evidence Record Model

## Purpose

Evidence records describe what was observed, synthesized, or structured as
evidence.

## Record Categories

- Observation records
- Process records
- Evidence candidate records
- Evidence asset records
- Governance evidence records

## Common Fields

- record name
- reality type
- source
- context
- evidence type
- confidence
- validation status
- provenance
- history

## Boundary

No evidence database or schema enforcement is implemented.
