# Eco Agent System v0.1

This is the first Professional Agent System for the Eco Engine Interface Layer.

## Folder placement

Put this folder here:

D:\EcoEngine\eco_agent_system

## Run

Open PowerShell:

cd D:\EcoEngine\eco_agent_system
python main.py

## Output

The system prints the combined report and saves:

professional_agent_report.json

## Data source behavior

The system first tries to load:

D:\EcoEngine\eco_dna_B_hot_dry_windy_hyper_evap.json

If that file does not exist, it uses:

data\sample_eco_dna.json
