# ClimateOS Evidence Passport Web MVP Skeleton

This prototype is static-only and mock-only. It is not a runtime system, not a backend service, not an operational Evidence Passport system, not a scoring system, not a compliance or assurance tool, and not a production deployment.

## Purpose

This static skeleton makes the ClimateOS Evidence Passport workflow visible for Founder review.

It shows:

- Case Overview.
- Source Intake.
- Signal Register.
- Claim Candidates.
- Knowledge Objects.
- Evidence Candidates.
- Evidence Readiness.
- Risk Flags.
- Human Review.
- Founder Gate.
- Archive / Closure.

## Files

- `index.html` - static review surface.
- `styles.css` - static visual layout.
- `data/mockEvidencePassport.js` - mock-only candidate records.
- `app.js` - local rendering and section navigation only.

## Boundary

No runtime, backend service, production API, database schema, persistence layer, authentication, authorization, MCP, n8n, QCloud integration, automation, scheduler, scoring, operational Evidence Passport, compliance guidance, assurance guidance, certification guidance, ESG/carbon conclusions, standards interpretation, framework interpretation, deployment, live source intake, live GitHub automation, live model-provider connection, or Task481 is created here.

## How To Review

Open `index.html` directly in a browser. No install, build, server, or network connection is required.
