# Agent Name

## Purpose

Describe the narrow problem this agent supports and who reviews its outputs.

## Inputs

List required and optional inputs, formats, provenance, and missing-data rules.

## Outputs

List human-readable and machine-readable outputs and what they mean.

## Evidence Requirements

Describe evidence sources, confidence, uncertainty, traceability, and review.

## Runtime Fields

List stable fields, allowed values, identifiers, statuses, and defaults.

## Validation Rules

Describe deterministic checks, invalid-input handling, and tests.

## Governance Notes

State resource, cost, approval, human-review, privacy, and audit boundaries.

## Limitations

List capabilities the agent does not provide.

## Example Scenario

Provide a small demonstration input and expected output, clearly labelled.

## Future Tasks

List incremental extensions without claiming they already exist.

> Warning: This template does not implement scientific validation by itself.
> It only defines structure for future reviewable agent development.
