# Forecast Model Comparison

## Purpose

Forecast model comparison helps ClimateOS avoid dependency on one provider or
one modelling style.

## Comparison Dimensions

| Dimension | Review Question |
| --- | --- |
| Source | Who created or maintains the model? |
| Availability | Is it public, open-source, commercial, restricted, or To be verified? |
| Input type | What data does it require? |
| Output type | What does it produce? |
| Time horizon | What horizon is appropriate? |
| Domain fit | Is the model suitable for this climate, ecological, or planning context? |
| Assumptions | What assumptions are explicit or hidden? |
| Validation | Has output been compared with observed reality? |
| Governance risk | Could output be misused as truth or decision authority? |
