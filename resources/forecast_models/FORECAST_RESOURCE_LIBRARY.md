# Forecast Resource Library

## Purpose

The Forecast Resource Library provides a provider-neutral reference list for
future planning-layer forecast plugins.

Forecast providers may include foundation models, traditional statistical
models, domain models, expert models, and future forecasting engines.

## Positioning

Forecast providers are optional planning-support candidates.

They are not:

- ClimateOS core dependencies
- EcoEngine replacements
- truth engines
- automated governance systems

## ClimateOS Use

Forecast outputs may support:

- planning questions
- scenario inputs
- risk review
- option testing
- future validation
- evidence formation after reality comparison

## Validation Requirement

Every forecast output should remain a Forecast Candidate until compared against
later observed reality, assumptions, uncertainty, bias, provider reliability,
and governance relevance.
