# Forecast Model Resources

## Purpose

This folder records forecast model candidates that may support future
ClimateOS planning and validation work.

ClimateOS does not currently run these models.

## Core Principle

```text
Forecast output is not truth.
Forecast output is a Forecast Candidate.
```
