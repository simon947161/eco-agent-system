# BIM Common Data Environment RDA

## Pattern

BIM and common data environments organize building and infrastructure design,
model, document, review, and handover records.

## RDA Relevance

This pattern can support design traceability, construction traceability, and
asset lifecycle evidence.

## Example Records

- model version
- design issue
- approval status
- construction document
- handover record
- asset information requirement

## Boundary

ClimateOS does not implement BIM or CDE integration in this task.
