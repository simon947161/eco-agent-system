# Digital Twin RDA

## Pattern

Digital twins connect modeled systems with observations, operations, scenarios,
and performance records.

## RDA Relevance

This pattern can support infrastructure, energy, water, land, and planning RDA.

## Example Records

- system model
- observed state
- operational state
- scenario input
- simulated output
- performance comparison

## Boundary

ClimateOS does not implement digital twin runtime in this task.
