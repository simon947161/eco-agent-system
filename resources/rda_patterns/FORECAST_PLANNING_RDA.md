# Forecast Planning RDA

## Pattern

Forecast and planning systems generate scenario inputs, model outputs, forecast
candidates, assumptions, option comparisons, and observed outcome records.

## RDA Relevance

This pattern can support Planning and Scenario RDA.

## Forecast Rule

Forecast outputs are Forecast Candidates, not truth, until validated.
