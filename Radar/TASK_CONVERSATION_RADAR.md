# Task: Conversation Radar

## Objective
Design and implement a Conversation Radar Skill.

## Requirements
1. Capture conversation summaries.
2. Extract:
   - Keywords
   - Knowledge Points
   - Idea Points
   - Wish/Intent Points
   - Reasoning Points
   - Next Actions
3. Store entries as markdown.
4. Support semantic retrieval.
5. Support project linking:
   - ClimateOS
   - EcoEngine
   - CCZPS
   - CarbonOS
6. Generate searchable index.

## Future
- Vector search
- GitHub integration
- Daily memory digest
- Radar dashboard
- Human-in-the-loop validation
