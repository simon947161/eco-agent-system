# Conversation Radar

Purpose: Build a searchable memory and insight index across ChatGPT, Codex, GitHub and ClimateOS work.

## Vision
Humans remember moments, not entire conversations. Conversation Radar captures key ideas, reasoning, goals and next actions so they can be rediscovered later.

## Core Objects
- Knowledge Points
- Idea Points
- Wish / Intent Points
- Reasoning Points
- Next Actions
- Keywords
- Related Projects

## Example Query
'Find the discussion about Radar Layer and Task Schedule from June 2026.'

## Long-term Goal
Create a semantic memory system that can retrieve important project conversations by concept rather than exact wording.
