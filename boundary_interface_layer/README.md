# Boundary Interface Layer v0.1

The **Boundary Interface Layer** is a simple prototype for classifying geospatial points along a dry-to-wet gradient.

It uses a basic climate boundary metric:

**B = P - ET**

Where:
- **B** = boundary value
- **P** = precipitation
- **ET** = evapotranspiration

## Boundary Classes

- `wet` if `B > 20`
- `boundary` if `-20 <= B <= 20`
- `semi_arid` if `-80 <= B < -20`
- `arid` if `B < -80`

## Files

- `sample_boundary_points.json`: sample points for testing.
- `boundary_calculator.py`: computes `boundary_value` and class.
- `boundary_output.json`: output generated by calculator.
- `boundary_map.py`: generates `boundary_map.html` using folium if installed.

## Run

From inside the `boundary_interface_layer/` directory:

```bash
python boundary_calculator.py
python boundary_map.py
```

This is a **v0.1 prototype** and does not connect to live climate APIs.
