# Scenario Assumption Model

## Purpose

The Scenario Assumption Model defines how assumptions should be documented and
reviewed in ClimateOS scenarios.

## Assumption Types

- climate assumption
- ecological assumption
- infrastructure assumption
- governance assumption
- behavior assumption
- forecast assumption
- data availability assumption
- intervention assumption

## Assumption Review

Assumptions should be reviewed for:

- source
- evidence support
- uncertainty
- relationship to forecast candidates
- relationship to proof records
- sensitivity to change
- governance relevance
- revision pathway

## Assumption Principle

Hidden assumptions make scenarios fragile.

ClimateOS should preserve assumptions explicitly so future evidence can revise
them.

## Boundary

No assumption engine, sensitivity model, or automated validation is added.
