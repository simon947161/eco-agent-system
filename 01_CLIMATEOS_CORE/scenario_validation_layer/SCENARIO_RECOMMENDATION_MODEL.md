# Scenario Recommendation Model

## Purpose

The Scenario Recommendation Model defines when a scenario may become a
recommendation candidate.

## Recommendation Candidate

A recommendation candidate is a review-supported planning output.

It is not an automated governance decision.

## Recommendation Conditions

A scenario may become a recommendation candidate when:

- assumptions are explicit
- forecast candidates are reviewed
- Evidence Packages are reviewed
- Proof Records have current status
- confidence state is documented
- uncertainty is preserved
- revision pathway remains open
- governance context is clear

## Recommendation Boundary

Scenario recommendations remain revisable and require human governance review.

## Boundary

No recommendation engine, automated decision, approval system, or governance
runtime is implemented.
