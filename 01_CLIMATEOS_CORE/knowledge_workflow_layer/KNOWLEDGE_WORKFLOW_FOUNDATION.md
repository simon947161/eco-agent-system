# Knowledge Workflow Foundation

## Purpose

The Knowledge Workflow Foundation defines how knowledge moves through
ClimateOS from raw observation and discussion into structured knowledge,
evidence, validation, planning, and future runtime use.

## Core Flow

```text
Observation
-> CRP
-> Knowledge Runtime
-> Evidence
-> Validation
-> Planning
-> Future Runtime
```

## Role

The workflow layer does not store knowledge itself. It describes how knowledge
should move between layers while retaining context, source, maturity,
traceability, and review requirements.

## Relationship To Task73 And Task74

- Task73 defines Knowledge Runtime and Knowledge Objects.
- Task74 defines provider interfaces and adapters.
- Task75 defines the workflow that moves knowledge through ClimateOS.

## Boundary

This document does not implement a workflow engine or automated process.
