# Knowledge Workflow Stages

## Purpose

This document defines the main stages of ClimateOS knowledge workflow.

## Stages

| Stage | Purpose |
| --- | --- |
| Observation | Record what was noticed or reported. |
| Discussion | Explore meaning, uncertainty, and possible implications. |
| CRP | Structure the conversation into radar-ready points. |
| Knowledge Object | Make knowledge identifiable and referenceable. |
| Evidence Candidate | Determine whether knowledge may support evidence. |
| Validation Review | Review assumptions, confidence, source, and context. |
| Planning Support | Use reviewed knowledge to support planning questions. |
| Future Runtime Use | Provide reviewed context to future runtime systems. |
| Revision | Update knowledge as reality or understanding changes. |
| Archive | Preserve history without treating old knowledge as current. |

## Boundary

These stages are conceptual and do not create a workflow engine.
