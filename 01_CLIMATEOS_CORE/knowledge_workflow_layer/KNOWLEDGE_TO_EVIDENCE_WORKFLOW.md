# Knowledge To Evidence Workflow

## Purpose

This workflow explains how Knowledge Objects may support evidence formation.

## Flow

```text
Knowledge Object
-> Evidence Candidate
-> Evidence Review
-> Evidence
```

## Evidence Support

Knowledge may support evidence when it provides:

- source context
- domain reasoning
- prior observations
- standards or references
- assumptions
- validation requirements
- relationship to RDA or Proof of Reality

## Boundary

A Knowledge Object is not evidence by default. It must be reviewed before it
can support evidence claims.
