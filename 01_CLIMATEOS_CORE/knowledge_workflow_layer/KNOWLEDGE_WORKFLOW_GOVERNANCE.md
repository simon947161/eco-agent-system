# Knowledge Workflow Governance

## Purpose

Knowledge Workflow Governance defines review principles for moving knowledge
between ClimateOS layers.

## Principles

- preserve traceability
- avoid treating discussion as evidence
- avoid treating forecasts as truth
- keep source and provider boundaries visible
- record uncertainty
- preserve human review
- respect maturity status
- separate knowledge from runtime action

## Governance Boundary

Knowledge can support governance, but knowledge does not create automated
governance decisions.

## Relationship To Validation

Validation determines whether knowledge can support claims, evidence, planning,
or future runtime context.
