# Knowledge To Planning Workflow

## Purpose

This workflow explains how Knowledge Objects may support planning and scenario
work.

## Flow

```text
Knowledge Object
-> Planning Question
-> Scenario Context
-> Forecast Candidate Review
-> Planning Support
```

## Planning Support

Knowledge may support:

- scenario framing
- option comparison
- risk identification
- forecast assumption review
- governance context
- stakeholder participation
- resilience planning

## Boundary

Knowledge does not replace human judgment, validation, or governance review.
