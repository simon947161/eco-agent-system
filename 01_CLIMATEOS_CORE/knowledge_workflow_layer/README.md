# Knowledge Workflow Layer

## Purpose

The Knowledge Workflow Layer defines how knowledge flows through ClimateOS.

It connects:

```text
Observation
-> CRP
-> Knowledge Runtime
-> Evidence
-> Validation
-> Planning
-> Future Runtime
```
