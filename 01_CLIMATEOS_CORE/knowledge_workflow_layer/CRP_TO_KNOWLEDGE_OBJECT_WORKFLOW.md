# CRP To Knowledge Object Workflow

## Purpose

This workflow defines how CRP outputs may become Knowledge Objects.

## Flow

```text
CRP
-> Review
-> Classification
-> Knowledge Object
-> Knowledge Runtime
```

## Required Preservation

When a CRP becomes a Knowledge Object, it should preserve:

- source conversation or note
- date
- project context
- related tasks
- related ClimateOS layers
- assumptions
- risks
- open questions
- maturity status
- citation requirements

## Boundary

This document does not implement CRP parsing, object creation, or LLM
retrieval.
