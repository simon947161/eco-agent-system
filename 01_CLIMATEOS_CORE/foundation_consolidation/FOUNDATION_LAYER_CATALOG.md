# Foundation Layer Catalog

## Purpose

This catalog groups current ClimateOS foundation layers into practical
categories for navigation and review.

## Core Reality-To-Evidence Layers

| Layer | Location | Role |
| --- | --- | --- |
| Observation Layer | `01_CLIMATEOS_CORE/observation_layer/` | Records environmental and community observations. |
| Relationship Layer | `01_CLIMATEOS_CORE/relationship_layer/` | Connects observations into system relationships. |
| Radar Layer | `01_CLIMATEOS_CORE/radar_layer/` | Detects change signals and emerging attention areas. |
| Evidence Layer | `01_CLIMATEOS_CORE/evidence_layer/` | Synthesizes evidence candidates and evidence structures. |
| Validation Layer | `01_CLIMATEOS_CORE/validation_layer/` | Defines confidence, uncertainty, and calculation transparency. |
| Proof of Reality Layer | `01_CLIMATEOS_CORE/proof_of_reality_layer/` | Structures proof mechanisms for reality claims. |
| RDA Layer | `01_CLIMATEOS_CORE/rda_layer/` | Defines Reality Data Assets from real-world processes. |
| Evidence Asset Framework | `02_ECOCHAIN_FOUNDATION/evidence_asset_framework/` | Defines contextualized, validated evidence objects. |
