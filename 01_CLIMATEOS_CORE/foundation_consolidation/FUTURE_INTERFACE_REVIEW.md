# Future Interface Review

## Purpose

This review identifies future-facing interfaces mentioned or implied by the
foundation phase.

## Forecast And Planning Interface

Future forecast and planning work should treat model outputs as candidates,
not truth.

Potential future pieces:

- Forecast Resource Library
- Forecast Candidate model
- Forecast Validation model
- Planning / Scenario Layer
- Task100 forecast validation preparation

## Obsidian And Knowledge Garden Interface

The project may later need a knowledge interface that connects:

- CRP notes
- Obsidian vault structures
- strategic notes
- project records
- evidence summaries
- decision history

This should remain separate from runtime claims until a concrete integration is
designed.

## NatureHash Interface

NatureHash may become a future identity or Proof of Nature research layer.

Current status: concept or vision only.

## Task100 Interface

Task100 should not be treated as a simple demo. It may become a validation
architecture, benchmark, or runtime preparation layer.

Task71 recommends scoping Task100 carefully before implementation work begins.
