# Foundation Phase System Map

## Main Foundation Map

```text
Reality
-> Observation
-> Relationship
-> Radar
-> Evidence
-> Validation
-> Proof of Reality
-> RDA
-> Evidence Asset
-> EcoChain
-> RWA Alignment
-> Governance / Participation / Cultivation
```

## Planning And Forecast Side Path

```text
Planning Question
-> Scenario Input
-> Forecast Candidate
-> Forecast Validation
-> Evidence
-> Scenario Reasoning
-> Planning Support
-> Governance / Cultivation
```

## Important Boundary

Forecast output is not truth.

Forecast output is a candidate input for validation and planning.

## Cross-Cutting Layers

Some layers operate across the chain rather than in only one location:

- Evidence
- Validation
- Governance
- Participation
- Knowledge Interface
- Forecast / Planning

## External Inputs

External providers such as NASA, Copernicus, ECMWF, BOM, Open-Meteo, local
sensors, and community observation feed the Observation Layer. They are not
ClimateOS itself.

## Scientific Engine Boundary

EcoEngine remains separate from ClimateOS. ClimateOS may call EcoEngine in the
future for scientific computation, scenario reasoning, threshold detection, or
pattern analysis, but Task71 does not implement that runtime path.
