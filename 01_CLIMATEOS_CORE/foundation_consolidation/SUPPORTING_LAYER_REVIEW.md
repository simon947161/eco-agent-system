# Supporting Layer Review

## Purpose

Supporting layers help the ClimateOS foundation remain provider-independent,
engine-independent, reviewable, and future-ready.

## EcoEngine Integration

ClimateOS does not replace EcoEngine.

EcoEngine remains the scientific, scenario, and possibility reasoning engine.
ClimateOS can call EcoEngine in future runtime designs, but the current
foundation only documents the boundary.

## NASA And Multi-Source Observation

NASA and other providers are observation resources. They are not ClimateOS.

ClimateOS should remain provider-independent and capable of receiving
observation resources from NASA, Copernicus, ECMWF, BOM, Open-Meteo, local
sensors, community observation, and future providers.

## NatureHash

NatureHash remains a future identity or Proof of Nature research layer.

It is not implemented as a mature algorithm, token system, or operational proof
system.

## Language-To-Evidence Protocol

The Language-to-Evidence Protocol is a future semantic evidence bridge.

It may help map language, local knowledge, cultural meaning, and project
records into evidence structures. It is currently a documentation foundation.

## Knowledge Interface Placeholder

The Knowledge Interface placeholder reserves a future interface for Obsidian,
Knowledge Garden, CRP notes, project records, and other structured project
knowledge.

No runtime integration is claimed.
