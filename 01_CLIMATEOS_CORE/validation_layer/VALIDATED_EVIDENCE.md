# Validated Evidence

## Purpose

This document defines the difference between evidence and validated evidence.

## Evidence

Evidence is a synthesized relationship structure with traceable support.

Evidence may still contain uncertainty, gaps, conflicting observations, or
unreviewed assumptions.

## Validated Evidence

Validated evidence has passed a defined validation process.

It should include:

- Evidence source references
- Validation method
- Confidence context
- Uncertainty notes
- Reviewer notes or review status
- Limitations

## Difference

Evidence is prepared for evaluation.

Validated evidence has been evaluated.

## Boundary

No validation process or approval workflow is implemented.
