# Validation System Map

## Purpose

This map shows where validation sits inside ClimateOS.

## Visual Architecture

```text
Observation
-> Relationship
-> Radar
-> Evidence
-> Validation
-> Validated Evidence
-> EcoChain
-> RWA
-> Governance
```

## Major Components

```text
Validation Layer
├─ Validation Principles
├─ Validation Types
├─ Confidence Framework
├─ Evidence Quality Framework
├─ Calculation Transparency Rules
├─ Calculation Classification
├─ Scientific Alignment
├─ Uncertainty Framework
└─ Proof of Reality Validation
```

## Boundary

This is an architecture document only. It does not create a runtime validation
system, dashboard, API, compliance engine, or automated decision process.
