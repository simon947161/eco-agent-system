# Validation Principles

## Purpose

These principles define how ClimateOS should approach evidence validation.

## Principles

### Validation Must Be Transparent

The reviewer should be able to see what was checked and why.

### Validation Must Be Reproducible

The same evidence package should be reviewable again using the same stated
method.

### Validation Must Be Traceable

Validation should preserve links to source observations, evidence structures,
assumptions, and review notes.

### Validation May Be Revised

New observations or stronger evidence may change a validation result.

### Validation Is Evidence-Based

Validation should evaluate evidence, not opinion or unsupported claims.

### Validation Is Uncertainty-Aware

Validation should record uncertainty, limits, boundary conditions, and unknowns.

## Boundary

These are governance and review principles only. No automated validation is
implemented.
