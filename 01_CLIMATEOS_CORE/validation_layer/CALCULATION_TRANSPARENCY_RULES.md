# Calculation Transparency Rules

## Purpose

This is the core transparency document for future ClimateOS calculations.

Every future calculation must be explainable, reviewable, and traceable.

## Mandatory Documentation Requirements

Every future calculation must document:

- Formula
- Inputs
- Units
- Assumptions
- Physical Meaning
- Scientific Basis
- Limitations
- Validation Method
- Calculation Type

## Formula

The formula or method must be stated clearly enough for review.

## Inputs

All inputs must be named and their sources should be traceable.

## Units

Units must be documented for each input and output.

## Assumptions

Assumptions must be explicit and reviewable.

## Physical Meaning

The calculation should explain what real-world process it represents.

## Scientific Basis

The calculation should state the scientific field or reasoning it depends on.

## Limitations

Known limits, edge cases, and unsuitable uses must be documented.

## Validation Method

The method for checking or reviewing the calculation must be described.

## Calculation Type

The calculation should be classified using
[Calculation Classification](CALCULATION_CLASSIFICATION.md).

## Boundary

No formulas are added here. This document establishes transparency
requirements only.
