# Forecast Candidate Model

## Definition

A Forecast Candidate is a forecast output that may support planning but has not
yet been validated against reality.

## Examples

- rainfall forecast
- water demand forecast
- energy demand forecast
- solar output forecast
- vegetation stress forecast
- fire risk forecast
- infrastructure demand forecast
- maintenance risk forecast
- carbon budget forecast
- project performance forecast
- scenario outcome forecast

## Required Chain

```text
Forecast Candidate
-> Validation Requirement
-> Observed Reality
-> Error / Bias / Confidence Review
-> Validated Forecast Evidence
-> Scenario Planning Support
```

## Rule

A Forecast Candidate must not be treated as truth, proof, approval, or
governance instruction.
