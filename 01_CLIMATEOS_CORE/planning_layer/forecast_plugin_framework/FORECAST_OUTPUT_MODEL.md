# Forecast Output Model

## Purpose

This model defines possible forecast outputs for future planning support.

## Possible Outputs

- future time-series value
- expected trend
- probability range
- uncertainty range
- anomaly signal
- risk signal
- scenario comparison support
- planning support note

## Classification

All forecast outputs must be classified as:

```text
Forecast Candidate
```

until validated.

## Boundary

Forecast outputs are not Proof of Reality, Evidence Assets, RWA Alignment
Candidates, or governance decisions by themselves.
