# Forecast Plugin Framework

## Purpose

This folder defines the ClimateOS Forecast Planning Plugin Framework.

Forecast providers may support future planning and scenario work, but ClimateOS
does not become a forecasting system.

## Core Principle

```text
Forecast output is not truth.
Forecast output is a Forecast Candidate.
```
