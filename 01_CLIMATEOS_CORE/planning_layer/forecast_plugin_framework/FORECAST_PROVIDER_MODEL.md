# Forecast Provider Model

## Definition

A Forecast Provider is an external model, method, system, expert process, or
future engine capable of producing forecast outputs.

## Provider Candidates

- TimesFM
- Chronos
- Moirai
- MOMENT
- traditional statistical models
- domain-specific forecast models
- expert models
- future forecasting engines

## Required Metadata

Each provider candidate should document:

- provider name
- source or origin
- model type
- public or open-source availability status
- input requirements
- output type
- suitable and unsuitable use cases
- limitations
- validation requirements
- governance risks

## Boundary

A Forecast Provider is not ClimateOS core and is not an EcoEngine replacement.
