# Forecast Input Model

## Purpose

This model defines possible inputs for future forecast providers.

## Possible Inputs

- time-series observations
- weather records
- energy generation records
- energy demand records
- water level records
- streamflow records
- soil moisture records
- vegetation records
- maintenance records
- project operation records
- carbon / ESG records
- planning assumptions
- scenario variables

## Possible Source Layers

Inputs may come from:

- Observation Layer
- RDA Layer
- Multi-Source Observation Framework
- NASA / external data providers
- local sensors
- community observations
- operational records
- governance records

## Boundary

This document does not implement data ingestion, data conversion, validation, or
forecast execution.
