# Forecast Plugin System Map

## Planning Plugin Map

```text
Planning Question
-> Scenario Input
-> Forecast Provider
-> Forecast Candidate
-> Validation Requirement
-> Observed Reality Comparison
-> Forecast Confidence
-> Scenario Reasoning
-> Planning Support
-> Governance / Cultivation
```

## Main ClimateOS Chain

```text
Reality
-> RDA
-> Proof of Reality
-> Evidence Asset
-> EcoChain
-> RWA Alignment
```

## Connection Point

Forecast Candidates connect to the main chain only after structured recording,
validation, and evidence review.

```text
Planning Question
+ Scenario Input
+ Forecast Candidate
+ Forecast Source
+ Assumptions
+ Validation Requirement
= Planning / Scenario RDA Candidate
```

Forecasts should not directly become RWA Alignment Candidates.
