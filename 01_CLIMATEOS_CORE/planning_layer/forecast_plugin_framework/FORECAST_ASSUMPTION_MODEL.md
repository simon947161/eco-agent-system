# Forecast Assumption Model

## Purpose

Forecast assumptions must be recorded so forecast candidates can be reviewed
later.

## Assumption Fields

- forecast question
- time horizon
- spatial scope
- input records used
- missing data
- preprocessing assumptions
- scenario assumptions
- provider assumptions
- model version
- governance relevance
- validation requirement

## Review Questions

- What conditions are assumed to continue?
- What external shocks are excluded?
- What data quality limits exist?
- What time horizon is appropriate?
- What would make the forecast invalid?

## Boundary

Assumption recording does not validate the forecast. It makes future validation
possible.
