# Forecast Plugin Framework

## Purpose

The Forecast Plugin Framework defines how external forecast models may support
future ClimateOS planning, scenario analysis, validation, evidence formation,
and governance.

## Positioning

Forecast engines ask:

```text
What is most likely to happen?
```

EcoEngine asks broader questions:

```text
What may happen?
What should happen?
What should not happen?
How can a better outcome be cultivated?
```

ClimateOS organizes:

```text
Forecast
-> Validation
-> Evidence
-> Reasoning
-> Planning
-> Governance / Cultivation
```

## Provider-Neutral Principle

TimesFM, Chronos, Moirai, MOMENT, traditional models, domain models, and future
forecasting systems are Forecast Provider Candidates, not ClimateOS core.

## Boundary

ClimateOS does not currently run forecast models. This framework prepares the
conceptual interface only.
