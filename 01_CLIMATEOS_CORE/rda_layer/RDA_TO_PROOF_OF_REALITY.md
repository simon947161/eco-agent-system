# RDA to Proof of Reality

## Purpose

This document explains how RDA supports Proof of Reality.

## Chain

```text
RDA
-> Reality Claim
-> Evidence Package
-> Cross-Validation
-> Confidence Level
-> Proof Record
```

## Supported Claims

RDA may support:

- natural reality claims
- operational reality claims
- governance reality claims
- planning reality claims

## Boundary

No proof runtime is implemented.
