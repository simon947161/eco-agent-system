# RDA to EcoChain

## Purpose

This document explains how RDA may later support EcoChain.

EcoChain should not record every raw RDA.

EcoChain may record:

- validated RDA references
- proof records
- evidence asset references
- process traceability records
- governance traceability records
- confidence updates

## EcoChain Definition

EcoChain remains a Validated Evidence Chain.

## Boundary

No blockchain implementation, token model, or EcoChain runtime is implemented.
