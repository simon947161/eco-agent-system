# RDA Module Patterns

## Project RDA Module

```text
Project Identity + Planning Data + Approval Data + Procurement Data
+ Construction Data + Operation Data + Maintenance Data + Outcome Data
+ Validation Data
```

## Product / Material RDA Module

```text
Material Identity + Origin + Composition + Supply Chain
+ Environmental Footprint + Usage + Repair + Reuse + Recycling
```

## Infrastructure RDA Module

```text
Asset Identity + Design Data + Construction Data + Inspection Data
+ Operation Data + Maintenance Data + Failure / Risk Data
+ Lifecycle Performance
```

## Natural System RDA Module

```text
Location + Time Window + Observation + Satellite / Sensor Data
+ Human Observation + Ecological Context + Validation + Confidence
```

## Governance RDA Module

```text
Decision + Authority + Policy Basis + Consultation + Approval + Audit
+ Compliance + Review + Outcome
```

## Forecast / Planning RDA Module

```text
Planning Question + Scenario Input + Forecast Candidate + Model Source
+ Assumptions + Validation Requirement + Observed Outcome
+ Forecast Confidence
```
