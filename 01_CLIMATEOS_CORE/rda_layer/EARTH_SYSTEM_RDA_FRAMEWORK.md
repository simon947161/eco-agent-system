# Earth-System RDA Framework

## Purpose

This framework defines how Earth-system-related reality data emerges from
natural systems, infrastructure systems, resource-flow systems, operational
processes, governance processes, and planning processes.

## Core Positioning

ClimateOS focuses on Earth-System Related RDA, not generic RWA.

Earth-System Related RDA includes data assets connected to climate, water, land,
energy, infrastructure, resources, ecology, agriculture, communities,
governance processes, operational processes, and planning processes.

## Requirement

RDA must be traceable back to real-world physical, operational, planning, or
governance reality.

## Boundary

RDA is foundation documentation here. No data asset runtime exists.
