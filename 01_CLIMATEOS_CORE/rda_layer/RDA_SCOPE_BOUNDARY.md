# RDA Scope Boundary

## Purpose

This document distinguishes Generic RWA from Earth-System Related RDA.

## Generic RWA

Generic RWA may include:

- art
- collectibles
- intellectual property
- general financial assets
- luxury goods
- unrelated tokenized assets

These are outside the current ClimateOS core scope.

## Earth-System Related RDA

Earth-System Related RDA includes data connected to:

- physical systems
- ecological systems
- built assets
- resource flows
- infrastructure operations
- environmental performance
- community resilience
- governance actions
- planning and scenario processes

## Boundary

Task69 does not create a full RWA framework.
