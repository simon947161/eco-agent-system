# Physical World Mapping

## Purpose

Physical World Mapping connects RDA back to reality.

## Mapping Requirements

RDA should preserve:

- physical location
- time window
- observed system
- process context
- source record
- measurement or record method
- uncertainty
- validation status

## Principle

An RDA that cannot be traced to physical, operational, planning, or governance
reality should not be treated as Earth-System Related RDA.
