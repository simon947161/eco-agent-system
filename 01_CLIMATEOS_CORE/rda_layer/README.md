# Earth-System RDA Layer

## Purpose

The RDA Layer defines Earth-System Related Reality Data Assets for ClimateOS.

RDA means Reality Data Assets.

ClimateOS does not focus on generic RWA. ClimateOS focuses on Earth-System
Related RDA that is traceable back to real-world physical, operational,
planning, or governance reality.
