# RDA Definition

## Definition

A Reality Data Asset is a structured, traceable, and verifiable data object
derived from real-world natural, operational, planning, or governance
processes.

## What RDA Is Not

RDA is not merely raw data.

RDA is not merely a database entry.

RDA is not automatically an asset.

## What Makes RDA Valuable

RDA becomes valuable when it can support:

- evidence
- validation
- process traceability
- planning
- governance
- compliance
- risk assessment
- performance assessment
- future Evidence Asset formation
