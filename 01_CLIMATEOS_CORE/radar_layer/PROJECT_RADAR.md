# Project Radar

## Purpose

Project Radar defines conceptual tracking of ClimateOS project activity and
emerging project needs.

## Project Types

| Project Type | Purpose |
| --- | --- |
| Observation Projects | Track site observations, diary activity, and source gaps |
| Validation Projects | Track review needs, uncertainty, and evidence checks |
| Restoration Projects | Track ecological recovery, intervention context, and observation needs |
| Pilot Projects | Track bounded demonstrations, lessons learned, and reuse opportunities |

## Review Needs

Project signals require owner, boundary, status, evidence, assumptions,
dependencies, risks, and governance notes.

## Limits

No project management system, scheduling engine, recommendation engine, or
automated governance workflow is implemented.
