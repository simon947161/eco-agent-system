# Radar Types V1

## Purpose

Radar categories describe where ClimateOS may look for change signals. They
are conceptual categories only.

| Radar Type | Purpose |
| --- | --- |
| Policy Radar | Track policy change concepts and review needs |
| Technology Radar | Track emerging technology context and capability shifts |
| Evidence Radar | Track new evidence candidates and source changes |
| Climate Radar | Track climate and environmental change signals |
| Project Radar | Track ClimateOS project status and emerging needs |
| Relationship Radar | Track possible shifts in system relationships |
| Governance Radar | Track decision, accountability, and review signals |
| Community Radar | Track place-based community observations and concerns |

## Use

Each radar type may produce evidence candidates, review notes, and governance
questions after human review.

## Limits

No radar type is implemented as a runtime, crawler, monitor, alert system, or
recommendation engine.
