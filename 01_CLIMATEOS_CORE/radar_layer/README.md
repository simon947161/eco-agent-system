# Climate Radar Layer V1

## Purpose

The Climate Radar Layer identifies what is changing in reality. It sits between
the Relationship Layer and the Evidence Layer.

Radar is not a search engine. Radar is not a news feed. Radar is a change
detection framework.

## Strategic Questions

```text
Observation asks: What happened?
Relationship asks: Why did it happen?
Radar asks: What is changing?
Evidence asks: What can be proven?
Validation asks: Is it true?
Governance asks: What should be done?
```
