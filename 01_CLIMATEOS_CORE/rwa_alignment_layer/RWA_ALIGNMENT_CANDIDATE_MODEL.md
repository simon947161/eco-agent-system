# RWA Alignment Candidate Model

## Definition

An RWA Alignment Candidate is a real-world value object that has not become an
asset product, but has enough structured evidence to be evaluated for future
asset, insurance, finance, compliance, audit, or governance use.

## Examples

- a verified renewable energy project
- a verified water resilience project
- a verified carbon reduction process
- a verified ecological restoration area
- a verified infrastructure maintenance record
- a verified community resilience improvement
- a verified resource efficiency improvement
- a verified land management improvement
- a verified supply-chain sustainability process

## Important Boundary

A candidate is not yet a financial product.
A candidate is not yet a token.
A candidate is not automatically tradable.

It is only a structured readiness object.
