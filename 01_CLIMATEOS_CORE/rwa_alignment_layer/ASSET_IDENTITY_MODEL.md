# Asset Identity Model

## Purpose

Future RWA-aligned objects may require identity.

## Identity Fields

- object name
- object type
- location
- time window
- owner / custodian / responsible party
- governance context
- evidence package reference
- proof record reference
- RDA references
- Evidence Asset references
- EcoChain record candidates
- risk profile
- confidence level

## NatureHash

NatureHash may be a future possible identity / proof-of-nature research layer.

Task70 does not implement NatureHash, invent mathematical hash formulas, or
claim identity is already solved.
