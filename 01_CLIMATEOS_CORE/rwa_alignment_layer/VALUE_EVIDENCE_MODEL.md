# Value Evidence Model

## Definition

Value Evidence is the evidence that supports why a real-world object may have
value.

## Evidence Types

- physical evidence
- ecological evidence
- operational evidence
- governance evidence
- financial evidence
- risk reduction evidence
- resilience evidence
- compliance evidence
- performance evidence
- community benefit evidence
- carbon or ESG evidence

## Principle

Value should not be asserted without evidence.

```text
Claimed Value
-> Evidence
-> Validation
-> Confidence
-> RWA Alignment Candidate
```

## Boundary

No valuation model or financial product is implemented.
