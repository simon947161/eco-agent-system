# Real-World Value Object Model

## Definition

A Real-World Value Object is an object, process, project, place, system, or
outcome that may carry value because it is connected to real-world physical,
ecological, operational, or governance reality.

## Physical Value Object

Examples: land parcel, water infrastructure, renewable energy system,
ecological restoration site, carbon reduction site, agricultural production
system.

## Operational Value Object

Examples: maintained infrastructure, improved energy performance, verified
production efficiency, verified resource-flow efficiency, verified lifecycle
management.

## Governance Value Object

Examples: approved project, audited compliance process, verified community
participation, verified resilience planning, verified environmental management
process.

## Ecological Value Object

Examples: restored vegetation, improved soil condition, reduced erosion,
protected biodiversity, verified ecosystem recovery.
