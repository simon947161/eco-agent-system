# Forcing Systems

## Purpose

Forcing systems describe pressures or drivers that influence environmental
relationships.

## Forcing Factors

| Factor | Purpose |
| --- | --- |
| Temperature | Provides heat and cold context for ecological and physical response |
| Rainfall | Provides water input context |
| Wind | Provides drying, movement, exposure, and disturbance context |
| Radiation | Provides sunlight, heat, and energy context |
| Land Use Change | Provides human-driven landscape change context |
| Human Activity | Provides management, disturbance, infrastructure, and community context |
| External Disturbance | Provides event-driven pressure such as fire, flood, heatwave, storm, or drought |

## Interpretation

A forcing factor may influence relationships, flows, feedbacks, disturbance,
and recovery. The existence of a forcing factor does not prove causation.

## Limits

This document defines concepts only. It does not model forcing, calculate
impact, assign attribution, or forecast change.
