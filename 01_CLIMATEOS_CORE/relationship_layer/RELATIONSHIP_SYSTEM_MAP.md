## Major Sub-Components

```text
Observation
  -> Observation records
  -> Evidence candidates

Relationship
  -> Interactions
  -> Forcing systems
  -> Flow systems
  -> Feedback systems
  -> Disturbance
  -> Recovery and resilience

Radar
  -> Change awareness
  -> Emerging signals

Evidence
  -> Reviewed observations
  -> Provenance
  -> Limitations

Validation
  -> Reality checks
  -> Uncertainty review
  -> Human assessment

Governance
  -> Human response
  -> Accountability
  -> Decision context
```

## Limits

This map is documentation only. It does not create radar, validation,
governance, or automated decision functionality.
