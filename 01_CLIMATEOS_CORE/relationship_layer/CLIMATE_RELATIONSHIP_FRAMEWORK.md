# Climate Relationship Framework

## Purpose

The Climate Relationship Framework defines relationships as the core
analytical object of ClimateOS.

```text
Relationship
  |
  v
Interaction
  |
  v
Feedback
  |
  v
System Behaviour
```

## Relationship

A relationship connects two or more environmental, ecological, human, or
governance elements. It asks how one part of a system relates to another.

## Interaction

An interaction is the observed or hypothesised way that related elements
influence each other.

## Feedback

A feedback is a repeating influence where system response changes the
conditions that produced it.

## System Behaviour

System behaviour is the visible pattern that emerges from relationships,
interactions, feedbacks, forcing systems, flows, disturbances, and recovery.

## Core Rule

ClimateOS does not treat environmental indicators as isolated facts.
Indicators are interpreted through relationships and must be supported by
observation, evidence, validation, and governance review.

## Limits

This framework is conceptual. It contains no equations, simulations,
forecasting, machine learning, or automated analysis.
