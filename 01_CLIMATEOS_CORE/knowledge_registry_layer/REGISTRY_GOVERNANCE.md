# Registry Governance

## Purpose

Registry governance defines how registered knowledge should remain trustworthy
and maintainable.

## Governance Principles

- preserve source traceability
- preserve provider boundaries
- avoid unreviewed runtime use
- distinguish knowledge from evidence
- distinguish forecast candidates from truth
- keep maturity and status visible
- preserve version history
- support human review

## Review Questions

- Is the source clear?
- Is the provider clear?
- Is the object current?
- Is its maturity appropriate?
- Is it safe to use for evidence, validation, or planning?

## Boundary

No access control, compliance engine, or automated governance enforcement is
implemented.
