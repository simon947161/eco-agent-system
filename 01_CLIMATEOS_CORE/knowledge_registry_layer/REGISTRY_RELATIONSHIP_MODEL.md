# Registry Relationship Model

## Purpose

The Registry Relationship Model records how Knowledge Objects relate to one
another.

## Relationship Types

- supports
- extends
- depends_on
- supersedes
- related_to
- validates
- cites
- conflicts_with
- prepares

## Use

Relationships help contributors understand which knowledge objects are
foundational, which are derived, and which should be reviewed together.

## Boundary

No graph database or automated relationship extraction is implemented.
