# Knowledge Registry Foundation

## Purpose

The Knowledge Registry Foundation defines a conceptual inventory for ClimateOS
Knowledge Objects.

It helps future contributors answer:

- What knowledge exists?
- Where did it come from?
- Which layer uses it?
- What maturity does it have?
- What does it reference?
- Is it ready for evidence, validation, planning, or runtime use?

## Core Principle

The registry is a governance and traceability concept before it is a technical
system.
