# Registry Metadata Model

## Purpose

Registry metadata preserves traceability and context.

## Metadata Fields

- registry ID
- Knowledge Object ID
- provider ID
- provider type
- source path or URL
- title
- classification
- maturity
- version
- creation date if known
- last reviewed date if known
- related layers
- related tasks
- related evidence
- related validation
- citation requirement
- access boundary
- limitations

## Boundary

No metadata extraction or validation engine is implemented.
