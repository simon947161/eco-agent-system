# Registry Glossary

## Knowledge Registry

A conceptual inventory of Knowledge Objects, metadata, relationships, status,
and review readiness.

## Registry Entry

A conceptual record for one Knowledge Object.

## Registry ID

A stable identifier for a registry entry.

## Registry Metadata

Context and traceability information associated with a Knowledge Object.

## Registry Relationship

A typed relationship between registered Knowledge Objects.

## Registry Status

The review state of a registry entry.

## Runtime Ready

A future status for knowledge approved for runtime context. Not implemented in
Task76.
