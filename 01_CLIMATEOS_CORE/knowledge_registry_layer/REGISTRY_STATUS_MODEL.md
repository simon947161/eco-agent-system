# Registry Status Model

## Purpose

Registry status helps distinguish available knowledge from reviewed or
deprecated knowledge.

## Suggested Statuses

| Status | Meaning |
| --- | --- |
| Proposed | Candidate entry not yet reviewed. |
| Registered | Entry exists and has basic metadata. |
| Reviewed | Human review has checked source, context, and scope. |
| Validated | Evidence and validation support the object for a defined use. |
| Runtime Ready | Future state for approved runtime context. |
| Deprecated | Retained for history but not recommended for current use. |

## Boundary

No automated status update or approval system is implemented.
