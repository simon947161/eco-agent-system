# Knowledge Registry Layer

## Purpose

The Knowledge Registry Layer defines how ClimateOS may maintain a conceptual
registry of Knowledge Objects, providers, relationships, status, and review
readiness.

It builds on:

- Knowledge Runtime
- Knowledge Provider Layer
- Knowledge Workflow Layer
