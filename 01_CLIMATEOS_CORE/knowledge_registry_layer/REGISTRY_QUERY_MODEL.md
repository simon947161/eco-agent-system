# Registry Query Model

## Purpose

The Registry Query Model defines conceptual ways a future user or agent might
ask about registered knowledge.

## Query Dimensions

- by topic
- by task
- by layer
- by provider
- by maturity
- by status
- by evidence relationship
- by validation relationship
- by planning relationship

## Example Questions

- Which Knowledge Objects support Task100?
- Which objects are related to forecast validation?
- Which provider supplied this object?
- Which objects are deprecated?
- Which objects are ready for planning review?

## Boundary

This is not a search implementation, API, vector query, or LLM retrieval
system.
