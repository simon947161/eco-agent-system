# Registry Entry Model

## Purpose

A registry entry is the conceptual record for one Knowledge Object.

## Suggested Fields

| Field | Purpose |
| --- | --- |
| Registry ID | Stable registry identifier. |
| Knowledge Object ID | Identifier from the Knowledge Runtime. |
| Title | Human-readable object title. |
| Provider ID | Source provider reference. |
| Source Path Or URL | Where the object can be found. |
| Classification | Foundation, strategy, research, domain, planning, governance, or runtime knowledge. |
| Maturity | Concept, Foundation, Prototype, Validated, Operational, or Deprecated. |
| Version | Current version or revision. |
| Related Layers | ClimateOS layers connected to the object. |
| Related Tasks | Task IDs connected to the object. |
| Review Status | Review readiness or known limitations. |

## Boundary

This is a documentation model only.
