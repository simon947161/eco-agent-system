# Review Output Model

## Purpose

The Review Output Model defines conceptual outputs that may result from the
ClimateOS Review Workflow.

## Output Types

- Review Position
- Confidence Update
- Conflict Note
- Revision Note
- Evidence Request
- Recommendation Candidate
- Governance Output Candidate
- Unresolved Status

## Recommendation Candidate

A Recommendation Candidate is not an automated decision.

It is a review-supported statement that may inform human judgment, governance
coordination, or future planning.

## Governance Output Candidate

A Governance Output Candidate translates review into governance-relevant
language while preserving uncertainty, confidence, and revision status.

## Output Requirements

Outputs should preserve:

- evidence references
- assumptions
- confidence state
- uncertainty
- conflict status
- revision history
- human review needs

## Boundary

No recommendation engine, governance engine, API, dashboard, or automated
decision mechanism is created.
