# Review Conflict Workflow

## Purpose

The Review Conflict Workflow defines how ClimateOS may conceptually handle
conflicting evidence, interpretations, forecasts, or participant signals.

## Conflict Principle

Conflict is a review signal, not a failure.

Conflict should be preserved until it is resolved, reduced, escalated, or
accepted as an uncertainty.

## Conflict Flow

```text
Conflict Detected
-> Source Comparison
-> Assumption Review
-> Evidence Quality Review
-> Confidence Impact
-> Escalation Decision
-> Revision or Unresolved Status
```

## Conflict Types

- observation conflict
- knowledge conflict
- evidence conflict
- forecast conflict
- provider conflict
- expert interpretation conflict
- community observation conflict
- AI agent output conflict
- governance relevance conflict

## Relationship To Confidence Framework

The [Confidence Framework Layer](../confidence_framework_layer/README.md)
defines how disagreement, minority signals, escalation, and confidence updates
are represented.

## Boundary

No automated conflict resolution, enforcement, voting, scoring, or decision
engine is added.
