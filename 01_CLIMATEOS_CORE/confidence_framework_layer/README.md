# Confidence Framework Layer

## Purpose

The Confidence Framework Layer defines how ClimateOS represents confidence,
uncertainty, consensus, disagreement, escalation, and confidence change over
time.

Confidence is not truth. Consensus is not truth. Disagreement is not failure.
