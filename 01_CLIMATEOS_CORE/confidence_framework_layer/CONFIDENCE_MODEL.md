# Confidence Model

## Purpose

The Confidence Model defines confidence as a reviewable state of support for a
claim, interpretation, forecast candidate, relationship, evidence package, or
collective judgment.

## Definition

Confidence describes the current level of support after considering:

- evidence quality
- evidence traceability
- independent confirmation
- uncertainty
- conflicting evidence
- minority signals
- reviewer notes
- validation status

## Confidence Is Not Truth

Confidence does not prove that a claim is true.

It records how well the claim is currently supported and where uncertainty
remains.

## Confidence Inputs

Future confidence review may consider:

- Observation records
- Evidence Packages
- Proof of Reality records
- Earth Intelligence outputs
- Forecast Candidates
- Human review
- Agent review
- Collective Validation signals
- Validation Runtime outputs

## Confidence Decay

Confidence may weaken over time when:

- evidence becomes outdated
- source conditions change
- assumptions are no longer valid
- stronger conflicting evidence appears
- review history becomes stale
- forecast windows expire

## Boundary

No scoring scale, ratio, formula, or automated confidence engine is defined.
