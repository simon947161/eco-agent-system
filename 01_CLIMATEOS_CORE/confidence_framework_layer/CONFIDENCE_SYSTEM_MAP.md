# Confidence System Map

## Purpose

This map shows where the Confidence Framework fits within ClimateOS.

## System Flow

```text
Reality
-> Observation
-> Evidence Package
-> Proof of Reality
-> Knowledge Validation
-> Collective Validation
-> Confidence Framework
-> Validation Runtime
-> Governance Review
-> Task100
```

## Confidence Review Flow

```text
Evidence
-> Uncertainty
-> Consensus
-> Disagreement
-> Minority Signals
-> Independent Confirmation
-> Escalation
-> Confidence Update
```
