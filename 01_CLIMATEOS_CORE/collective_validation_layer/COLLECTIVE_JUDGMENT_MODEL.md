# Collective Judgment Model

## Purpose

The Collective Judgment Model defines how validated signals may support shared
judgment before human action.

## Inputs

- observed reality
- evidence quality
- validation findings
- confidence status
- uncertainty notes
- human review
- agent review
- Earth Intelligence signals
- forecast candidate review
- minority signals

## Output

Collective Judgment is a reviewed confidence context for human and governance
action. It is not an automated decision.

## Boundary

No consensus engine, voting system, or automated governance action is
implemented.
