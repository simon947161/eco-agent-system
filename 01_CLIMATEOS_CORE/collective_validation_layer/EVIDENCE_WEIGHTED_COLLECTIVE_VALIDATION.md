# Evidence Weighted Collective Validation

## Purpose

Evidence-weighted Collective Validation defines how ClimateOS may support
trustworthy collective judgment.

## Core Chain

```text
Reality
-> Observation
-> Evidence
-> Validation
-> Confidence
-> Collective Judgment
-> Human Action
```

## Authority-Weighted Versus Evidence-Weighted Decisions

Authority-weighted decisions prioritize institutional status, formal hierarchy,
or organizational rank.

Evidence-weighted decisions prioritize evidence quality, validation status,
traceability, uncertainty, and observed reality.

ClimateOS should prioritize evidence quality rather than institutional
hierarchy.

## Boundary

Collective Validation supports human action. It does not replace human
decisions or automate governance.
