# Participation Model

## Purpose

The Participation Model defines how participants may conceptually contribute to
ClimateOS collective validation.

## Contribution Types

- observation
- testimony
- evidence submission
- domain review
- local context
- forecast interpretation
- Earth Intelligence interpretation
- contradiction or challenge
- uncertainty note
- governance relevance note

## Validation Principle

Confidence should emerge through validation rather than status.

## Boundary

No participation platform, voting process, token model, or automated
contribution ranking is implemented.
