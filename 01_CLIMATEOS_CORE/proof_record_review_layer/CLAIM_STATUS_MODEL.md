# Claim Status Model

## Purpose

The Claim Status Model defines possible conceptual states for Reality Claims
and Proof Records.

## Status Values

- Candidate
- Under Review
- Strengthening
- Weakening
- Supported
- Contested
- Unresolved
- Reopened
- Split Into Competing Hypotheses
- Merged With New Evidence
- Superseded

## Status Principle

Status describes current review state, not absolute truth.

## Status Changes

Status may change when:

- new evidence arrives
- Evidence Package Review changes
- confidence updates
- Collective Validation signals change
- conflict appears
- forecast candidates are validated or invalidated
- governance context changes

## Boundary

No status engine, scoring rule, automatic transition, or approval workflow is
implemented.
