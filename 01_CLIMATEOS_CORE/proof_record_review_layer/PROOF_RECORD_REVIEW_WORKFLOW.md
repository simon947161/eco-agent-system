# Proof Record Review Workflow

## Purpose

The Proof Record Review Workflow defines a conceptual path for reviewing
Reality Claims and Proof Records.

## Workflow

```text
Reality Claim
-> Evidence Package Review
-> Proof Record Review
-> Claim Status Review
-> Confidence Review
-> Collective Validation Review
-> Revision History
-> Review Workflow
-> Governance Output Candidate
```

## Workflow Notes

The workflow remains open. A Reality Claim may return to earlier stages when
new evidence, conflict, or uncertainty appears.

## Relationship To Evidence Package Review

Evidence Package Review evaluates whether evidence is ready to participate in
review. Proof Record Review evaluates the current status of the claim and proof
record using that evidence.

## Boundary

No workflow engine, runtime, API, scoring system, or automated governance output
is created.
