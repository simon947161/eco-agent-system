# Proof Record Review Foundation

## Purpose

This foundation defines how ClimateOS may review Reality Claims and Proof
Records as living review objects.

It does not determine absolute truth.

It determines the current review status of a Reality Claim based upon available
evidence.

## Core Review Philosophy

Reality Claims may:

- strengthen
- weaken
- remain unresolved
- reopen
- split into competing hypotheses
- merge with new evidence

Proof Records therefore remain living records.

They are never permanently frozen.

## Required Relationships

Proof Record Review relates to:

- Proof of Reality
- Evidence Package Review
- Confidence Framework
- Collective Validation
- ClimateOS Review Engine
- Review Workflow
- Governance Runtime
- EcoChain
- Task100

## Boundary

This is documentation only. It does not implement proof runtime, automated
truth determination, APIs, blockchain, scoring, or governance decisions.
