# Computation Response Types

## Purpose

Computation response types describe possible future results EcoEngine may
return to ClimateOS.

## Examples

### Indicator

A structured measure or signal from a computation.

### Boundary

A returned description of a system limit or operating range.

### Relationship Strength

A future indication of how strongly two or more environmental variables appear
to relate.

### Threshold Status

A future indication of whether a condition is below, near, or beyond a defined
threshold.

### Transition Signal

A future indication that a system may be changing state.

### Confidence Information

Information describing uncertainty, confidence, assumptions, or review needs.

## Boundary

These response types are conceptual only. No response schema or runtime
handling is implemented.
