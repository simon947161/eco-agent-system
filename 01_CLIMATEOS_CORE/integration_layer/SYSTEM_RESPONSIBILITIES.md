# System Responsibilities

## Purpose

This document defines responsibility boundaries between ClimateOS and
EcoEngine.

## ClimateOS Responsibilities

- Organize governance runtime context
- Preserve observation and relationship context
- Manage evidence and validation pathways
- Track traceability, confidence, and review status
- Support future governance decisions

## EcoEngine Responsibilities

- Provide scientific computation capability
- Process suitable environmental inputs
- Return structured computation results
- Preserve calculation transparency in future implementations
- Document assumptions, units, and limitations

## Shared Responsibilities

- Maintain traceability
- Preserve input and output meaning
- Keep calculations explainable
- Support validation review
- Avoid unsupported claims

## Boundary

This document defines responsibilities only. It does not assign runtime
ownership or implement system integration.
