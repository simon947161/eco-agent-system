# CCZPS Alignment

## Purpose

This document explains the relationship between CCZPS, ClimateOS, and
EcoEngine.

## CCZPS Role

CCZPS provides climate zone context.

## ClimateOS Role

ClimateOS uses climate zone context to organize evidence, validation, and
governance interpretation.

## EcoEngine Role

EcoEngine may use climate zone context in future scientific computation.

## Alignment Concept

```text
CCZPS Context
-> ClimateOS Interpretation
-> EcoEngine Computation Context
-> Evidence and Validation
```

## Boundary

No CCZPS runtime changes, classification logic, or EcoEngine integration are
implemented.
