# Engine Interface Concept

## Purpose

The Engine Interface Concept defines terms for future interaction between
ClimateOS and scientific engines.

## Engine

An external or separate computation system that can process structured inputs.

## Input

Information passed to an engine for computation.

## Output

Information returned by an engine after computation.

## Result

A structured output that ClimateOS may interpret as evidence or validation
context.

## Confidence

Information describing uncertainty, support, assumptions, or reliability.

## Traceability

The ability to follow a result back to its inputs, method, assumptions, and
review notes.

## Boundary

This document defines concepts only. No interface, adapter, schema, or API is
implemented.
