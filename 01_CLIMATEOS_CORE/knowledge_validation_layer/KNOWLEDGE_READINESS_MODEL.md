# Knowledge Readiness Model

## Purpose

Knowledge Readiness describes whether a Knowledge Object can support downstream
ClimateOS layers.

## Readiness Levels

| Level | Meaning |
| --- | --- |
| Intake Ready | Source and basic metadata exist. |
| Review Ready | Context, assumptions, and limitations are visible. |
| Evidence Support Ready | The object may support evidence after evidence review. |
| Planning Support Ready | The object may support planning scenarios or decisions. |
| Runtime Context Ready | Future state for reviewed runtime use. |
| Deprecated | Retained for history but not current use. |

## Required Metadata

- source
- provider
- version
- maturity
- context
- related tasks
- related layers
- limitations
- review status

## Boundary

Readiness is conceptual and does not authorize automated runtime use.
