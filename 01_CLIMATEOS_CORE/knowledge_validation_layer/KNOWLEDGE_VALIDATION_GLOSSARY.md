# Knowledge Validation Glossary

## Knowledge Validation

Review of Knowledge Object readiness, metadata, context, conflict status, and
downstream suitability.

## Knowledge Readiness

The conceptual state describing whether knowledge can support evidence,
planning, or future runtime context.

## Knowledge Conflict

A mismatch between sources, versions, interpretations, providers, maturity, or
evidence relationships.

## Trust Update

A conceptual change in confidence about a Knowledge Object.

## Runtime Context Ready

A future readiness state for reviewed knowledge. Not implemented in Task79.
