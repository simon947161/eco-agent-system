# Runtime Interface Glossary

## Validation Runtime Interface

The conceptual interface boundary that future ClimateOS and domain runtimes may
inherit.

## Runtime Input

A review object or contextual object provided to a future runtime session.

## Runtime Output

A structured result or pack produced by a future runtime session.

## Runtime Context

The evidence, governance, scenario, confidence, and revision context needed to
interpret runtime interaction.

## Runtime Session

A bounded future validation interaction.

## Runtime State

The conceptual status of a future validation session or result.

## Runtime Invocation

A conceptual request to start a future validation session.

## Runtime Result

A structured output that remains open to review and revision.
