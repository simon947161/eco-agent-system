# Runtime Context Model

## Purpose

The Runtime Context Model defines contextual information that should accompany
future validation runtime interactions.

## Context Types

- project context
- domain runtime context
- governance context
- spatial context
- temporal context
- evidence context
- scenario context
- confidence context
- revision context
- EcoChain readiness context

## Context Principle

Runtime validation without context can produce misleading outputs.

Future runtimes should preserve enough context for human review, evidence
traceability, and revision.

## Boundary

No context runtime, context database, API, or automated context builder is
implemented.
