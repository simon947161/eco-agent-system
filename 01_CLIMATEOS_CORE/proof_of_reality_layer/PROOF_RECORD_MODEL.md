# Proof Record Model

## Definition

A Proof Record is a structured record created after a Reality Claim has been
reviewed through evidence packaging and validation.

## Fields

- reality claim
- evidence package reference
- validation status
- confidence level
- source types
- cross-validation summary
- contradictions
- uncertainty
- history
- traceability
- relationship to Evidence Asset
- possible EcoChain record type

## Boundary

No proof record database, blockchain, or runtime registry is implemented.
