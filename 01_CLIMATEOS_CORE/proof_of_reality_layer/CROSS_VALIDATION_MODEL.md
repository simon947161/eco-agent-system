# Cross Validation Model

## Definition

Cross-validation is the process of checking a Reality Claim against multiple
independent or semi-independent sources.

## Example

```text
Whistleblower testimony
+ satellite image
+ weather record
+ sensor record
+ local observation
+ operational log
+ governance record
```

## Cross-Validation Must Identify

- supporting evidence
- missing evidence
- contradictory evidence
- source independence
- source reliability
- timing consistency
- spatial consistency
- process consistency

## Boundary

No cross-validation scoring, algorithm, or runtime is implemented.
