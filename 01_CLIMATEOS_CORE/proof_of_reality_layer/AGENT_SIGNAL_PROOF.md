# Agent Signal Proof

## Purpose

Agent signals may provide Reality Claim Candidates from AI agents, sensor
agents, field robots, and future autonomous observers.

## Signal Sources

- AI agents
- sensor agents
- field robots
- future autonomous observers

## Principle

Agent signals are not inherently true and not inherently false.

They should be packaged with evidence, source context, limitations, and
validation requirements.

## Boundary

No autonomous agent validation or agent signal runtime is implemented.
