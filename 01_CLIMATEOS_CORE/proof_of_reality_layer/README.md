# Proof of Reality Layer

## Purpose

The Proof of Reality Layer defines how ClimateOS may express reality claims,
support them with evidence packages, cross-validate them, assign confidence
levels, and transform reviewed claims into proof records.

ClimateOS must never assume:

```text
Prediction = Truth
Single witness = false
Crowd consensus = truth
```

All claims enter as Reality Claim Candidates.
