# Reality Claim Model

## Definition

A Reality Claim is a statement about a real-world condition, event, process,
change, decision, risk, or outcome.

Reality Claims must be treated as claim candidates, not verified facts.

## Examples

- This area is entering drought stress.
- This project has begun construction.
- This maintenance record shows unresolved failure risk.
- This community reports repeated flood impact.
- This whistleblower reports an unrecorded environmental incident.
- Multiple local observers report abnormal ecosystem change.

## Required Fields

- claim statement
- reality type
- claimant or source type
- time
- location or system boundary
- claim content
- supporting evidence
- contradictions
- uncertainty
- confidence level
- validation status

## Boundary

No claim registry or validation runtime is implemented.
