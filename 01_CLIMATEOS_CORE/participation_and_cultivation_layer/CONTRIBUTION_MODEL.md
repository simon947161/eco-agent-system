# Contribution Model

## Purpose

The Contribution Model defines what participants may contribute to ClimateOS.

## Contribution Types

- Observations
- Photos
- Field notes
- Sensor records
- Local knowledge
- Scientific review
- Data interpretation
- Restoration activities
- Maintenance records
- Governance feedback
- AI-assisted summaries
- Validation notes

## Contribution Flow

```text
Contribution
-> Observation or Review Context
-> Evidence Candidate
-> Validation
-> Governance Coordination
-> Cultivation Outcome
```

## Principle

Contributions should remain traceable, reviewable, and clear about uncertainty.

## Boundary

No contribution submission workflow, database, identity system, or reward system
is implemented.
