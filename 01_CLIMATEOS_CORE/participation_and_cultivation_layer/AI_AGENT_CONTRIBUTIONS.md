# AI Agent Contributions

## Purpose

AI agents may support ClimateOS by organizing, summarizing, checking, and
preparing documentation under human oversight.

## Contribution Examples

- Drafting documentation
- Summarizing observations
- Preparing evidence review packs
- Checking internal links
- Organizing task queues
- Identifying missing assumptions
- Preparing human-readable review notes

## Guardrails

AI agents must not claim authority, approval, scientific certainty, regulatory
status, or autonomous decision-making capability.

AI outputs should remain reviewable by humans.

## Boundary

No autonomous AI governance, automated recommendations, or uncontrolled agent
runtime is implemented.
