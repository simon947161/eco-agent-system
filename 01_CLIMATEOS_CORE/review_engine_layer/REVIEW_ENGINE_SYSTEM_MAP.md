# Review Engine System Map

## Purpose

This map shows how the ClimateOS Review Engine relates to existing foundation
layers.

## Review Engine Chain

```text
Knowledge Runtime
-> Knowledge Validation
-> Validation Runtime
-> Collective Validation
-> Confidence Framework
-> ClimateOS Review Engine
-> Task100
```

## Input Context

```text
Observation
-> Knowledge
-> Evidence
-> Reality Claims
-> Forecast Candidates
-> Earth Intelligence
-> EcoEngine Relationship Analysis
-> Collective Signals
-> Confidence
-> Review Engine
```

## EcoEngine Boundary

```text
EcoEngine
-> Relationship Analysis
-> ClimateOS Review Engine
-> Integrated System-Level Review
```

EcoEngine analyses relationships.

ClimateOS Review Engine performs integrated system-level review based upon
those relationships, evidence, validation, confidence, and other inputs.
