# Review Input Model

## Purpose

The Review Input Model defines the types of inputs that may inform the
ClimateOS Review Engine.

## Input Categories

- Observation records
- Knowledge Objects
- Evidence Packages
- Reality Claims
- Forecast Candidates
- Earth Intelligence provider outputs
- EcoEngine relationship analysis
- human experience
- scientific knowledge
- expert opinion
- community observation
- AI agent outputs
- minority signals
- whistleblower signals

## Input Principle

Inputs contribute to review. Inputs do not become final authority by status
alone.

## Input Review Questions

Each input should be assessed for:

- source
- traceability
- evidence quality
- assumptions
- uncertainty
- relationship to other inputs
- conflict with other evidence
- validation status
- confidence impact

## Relationship To Existing Layers

Inputs may be supplied by the Knowledge Runtime, Evidence Layer, Proof of
Reality Layer, Forecast Plugin Framework, Earth Intelligence Interface,
Collective Validation Layer, and Confidence Framework.

## Boundary

No input adapter, data ingestion, API, runtime router, or automated input
processing is implemented.
