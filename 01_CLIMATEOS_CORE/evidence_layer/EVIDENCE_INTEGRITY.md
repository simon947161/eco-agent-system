# Evidence Integrity

## Purpose

Evidence Integrity describes the conditions that make an evidence structure
trustworthy enough for review.

## Integrity Sources

### Time

Evidence should preserve when observations were made and how patterns changed.

### Location

Evidence should preserve where observations were made and the relevant climate
zone or ecological setting.

### Observation Diversity

Evidence is stronger when different observation types support the same pattern.

### Relationship Consistency

Evidence should preserve whether observed relationships are consistent or
contradictory.

### Historical Consistency

Evidence should compare current patterns with historical context where
available.

### Cross-Validation

Evidence should be prepared for later review against independent sources.

## Boundary

This document defines review concepts only. It does not implement validation or
automated quality scoring.
