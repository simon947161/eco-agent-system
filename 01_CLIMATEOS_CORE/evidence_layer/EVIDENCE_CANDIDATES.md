# Evidence Candidates

## Purpose

An Evidence Candidate is a possible evidence structure that requires review
before it can be treated as evidence.

## Examples

- Potential drying trend
- Potential vegetation decline
- Potential resilience improvement
- Potential restoration effect
- Potential climate-zone-specific stress pattern

## Candidate Requirements

An evidence candidate should include:

- Source observations
- Relationship context
- Time and location context
- Uncertainty notes
- Review status

## Review Boundary

An evidence candidate is not validated evidence. It should not trigger
automated decisions or governance responses without review.
