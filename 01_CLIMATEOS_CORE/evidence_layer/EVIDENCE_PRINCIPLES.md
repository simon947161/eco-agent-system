# Evidence Principles

## Purpose

These principles guide how ClimateOS should treat environmental evidence.

## Principles

### Evidence Emerges From Relationships

ClimateOS evidence should be based on relationships between conditions, not
isolated measurements.

### Evidence Requires Context

Evidence needs time, location, climate zone, ecological setting, and source
context.

### Evidence Requires Multiple Observations

A single observation may be important, but evidence strengthens when multiple
observations support the same pattern.

### Evidence Requires Traceability

Each evidence structure should preserve its source path back to observations,
relationship assumptions, and review notes.

### Evidence Is Dynamic

Evidence can change as new observations, disturbances, or reviews appear.

### Evidence Can Strengthen Or Weaken Over Time

Repeated support can strengthen evidence. Contradictory observations,
uncertainty, or changed conditions can weaken it.

### Evidence Requires Validation

Evidence synthesis is not final proof. Validation is a separate step.
