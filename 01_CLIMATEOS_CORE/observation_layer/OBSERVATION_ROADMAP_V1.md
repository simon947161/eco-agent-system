# Observation Roadmap V1

## Phase 1: Manual Observation

Create human-readable site configurations and manual observation records using
the templates in this folder.

## Phase 2: Open-Meteo Integration

Future task: evaluate whether weather context can be imported from Open-Meteo
with clear provenance, limits, and review.

## Phase 3: NASA Integration

Future task: evaluate whether NASA data can support observation context with
source, resolution, license, and uncertainty controls.

## Phase 4: Knowledge Layer

Future task: organise reviewed observations into place-based ecological
knowledge records.

## Phase 5: Radar Layer

Future task: explore whether observation patterns can support a radar-style
awareness layer without forecasting or automated decisions.

## Phase 6: Validation Layer

Future task: connect reviewed evidence to validation workflows, uncertainty
records, and governance review.

## Limits

The roadmap is planning only. No integration, runtime, forecasting,
validation, governance, or database capability is implemented.
