# Sentinel Network V1

## Purpose

Sentinel Network V1 defines the first conceptual observation sites for the Eco
Observation Diary. These sites represent an ecological gradient across
elevation, climate, land use, and regional context.

## Initial Sentinel Sites

| Sentinel | Site | Conceptual Role |
| --- | --- | --- |
| Sentinel A | Dinner Plain | Alpine and high-elevation observation context |
| Sentinel B | Batlow | Mountain agriculture, forest edge, and recovery context |
| Sentinel C | Tumut | Valley, river, forestry, and transition context |
| Sentinel D | Wagga Wagga | Inland plains, heat, agriculture, and regional town context |

## Ecological Gradient Concept

The network is designed to observe differences across:

- elevation;
- temperature exposure;
- rainfall patterns;
- vegetation type;
- land use;
- water context;
- community observation context; and
- seasonal rhythm.

## Site Use

Each site should eventually have a site configuration record using
[Site Configuration Template](SITE_CONFIGURATION_TEMPLATE.md).

## Limits

The site list is a foundation only. It does not create monitoring hardware,
field operations, sensors, data feeds, or automated analysis.
