# Eco Observation Diary Concept

## Purpose

The Eco Observation Diary is a long-term ecological memory system for
ClimateOS. It records structured observations that can later support evidence,
knowledge, radar, validation, and governance layers.

## Definition

The diary is a regional ecological observation system. It preserves place-based
signals across time, including weather context, vegetation condition, water
context, ecological rhythm, and community notes.

## What It Is Not

- Not a weather station
- Not a forecasting platform
- Not a validation system
- Not a governance runtime
- Not an automated decision system
- Not an API or database

## Design Principle

The diary should make small, repeated observations durable. Its value comes
from continuity, context, transparency, and reviewability.
