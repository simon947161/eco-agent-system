# ClimateOS Maturity Framework

## Purpose

The ClimateOS Maturity Framework prevents the repository from confusing vision,
concepts, foundation documents, prototypes, and runtime capabilities.

## Why It Matters

ClimateOS is evolving from documentation foundations toward possible future
runtime systems. Contributors must know whether a layer is implemented,
planned, or only a long-term vision.

## Maturity Levels

```text
VISION -> CONCEPT -> FOUNDATION -> PROTOTYPE -> RUNTIME
```

## Operating Rule

A document may describe a future capability, but it must not imply that the
capability exists until it is implemented, tested, and documented as runtime.

## ClimateOS Position

ClimateOS should be understood as a Reality-to-Evidence Engineering Runtime
architecture. It transforms Natural Reality, Operational Reality, and
Governance Reality into trusted evidence structures.
