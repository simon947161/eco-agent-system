# Roadmap Alignment

## Purpose

This document aligns maturity status with future ClimateOS roadmap decisions.

## Alignment Rules

- FOUNDATION layers may be used for documentation, planning, and review.
- PROTOTYPE tasks should define inputs, outputs, tests, and limitations.
- RUNTIME tasks should include validation, error handling, and clear boundaries.
- External data work should remain provider-independent.
- EcoEngine work should remain engine-independent from ClimateOS governance.

## Next Roadmap Priorities

- Maintain layer status documentation.
- Define Reality Data Asset and Evidence Asset examples.
- Create reviewed sample records before runtime.
- Keep EcoChain as Validated Evidence Chain until implementation is approved.
