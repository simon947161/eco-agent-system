# Maturity Definitions

## VISION

A long-term direction or strategic concept. It is not designed or implemented.

## CONCEPT

A named idea with initial boundaries, but without a full foundation structure.

## FOUNDATION

Human-readable architecture, scope, definitions, limitations, and roadmap
documents exist. No runtime capability is implied.

## PROTOTYPE

Limited executable or workflow capability exists for review and learning. It is
not production-ready or authoritative.

## RUNTIME

Executable capability exists with defined inputs, outputs, tests, limitations,
and operating boundaries.

## Rule

Do not describe a layer as RUNTIME unless repository evidence supports it.
