# Knowledge Metadata Model

## Purpose

Knowledge metadata helps ClimateOS preserve traceability across providers.

## Metadata Fields

- Knowledge Object ID
- provider ID
- provider type
- source path or source URL
- title
- creation date if known
- last updated date if known
- version
- maturity
- classification
- related ClimateOS layer
- related task
- citation requirement
- access boundary
- confidence note

## Boundary

This model does not define a database schema or metadata extraction runtime.
