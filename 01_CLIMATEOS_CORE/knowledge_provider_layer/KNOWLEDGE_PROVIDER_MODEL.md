# Knowledge Provider Model

## Definition

A Knowledge Provider is a source or platform that may supply Knowledge Objects
or knowledge source material to ClimateOS.

## Provider Fields

- provider ID
- provider name
- provider type
- status
- version
- scope
- capability
- knowledge categories
- governance owner if known
- access boundary
- citation requirement

## Provider Status Values

- Concept
- Candidate
- Foundation
- Prototype
- Operational
- Deprecated

## Boundary

This model is conceptual. It does not create a registry database or provider
runtime.
