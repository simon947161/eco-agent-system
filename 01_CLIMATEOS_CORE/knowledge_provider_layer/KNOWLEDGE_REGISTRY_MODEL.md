# Knowledge Registry Model

## Purpose

The Knowledge Registry Model defines a conceptual registry for knowledge
providers.

## Registry Fields

| Field | Purpose |
| --- | --- |
| Provider ID | Stable identifier. |
| Provider Name | Human-readable provider name. |
| Provider Type | Provider category. |
| Status | Concept, Candidate, Foundation, Prototype, Operational, or Deprecated. |
| Version | Provider interface or source version. |
| Scope | Knowledge scope supplied by the provider. |
| Capability | Supported conceptual capabilities. |
| Knowledge Categories | Foundation, strategy, research, domain, planning, governance, or runtime knowledge. |

## Boundary

This registry is conceptual. No database, configuration file, API, or runtime
registry is created.
