# Knowledge Provider Layer

## Purpose

The Knowledge Provider Layer defines how future knowledge providers may supply
knowledge into the ClimateOS Knowledge Runtime.

Knowledge Runtime was established in Task73. Task74 defines provider-facing
interfaces while keeping ClimateOS platform-independent.
