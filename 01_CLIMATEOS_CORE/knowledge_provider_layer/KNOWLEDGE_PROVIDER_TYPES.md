# Knowledge Provider Types

## Purpose

This document identifies provider types that ClimateOS may support in the
future.

## Provider Types

| Provider Type | Role |
| --- | --- |
| Obsidian | Future Knowledge Garden provider. |
| GitHub | Repository-based foundation and task knowledge provider. |
| Local Markdown | File-based knowledge source for portable documents. |
| Local Documents | Local reports, PDFs, Word documents, or structured files. |
| Enterprise Knowledge Base | Organizational knowledge platform. |
| Future Knowledge APIs | External or internal knowledge services. |
| Future MCP Providers | Model Context Protocol provider sources. |
| Future Vector Databases | Future retrieval infrastructure provider. |

## Boundary

No provider is implemented in Task74. Obsidian, vector databases, MCP providers,
and APIs are provider concepts only.
