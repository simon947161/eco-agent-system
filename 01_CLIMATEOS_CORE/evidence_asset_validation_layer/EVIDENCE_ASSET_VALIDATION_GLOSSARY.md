# Evidence Asset Validation Glossary

## Evidence Asset

A review object combining reality, data, evidence, context, validation, history,
and confidence.

## Evidence Asset Candidate

An Evidence Package or related set of proof records that may become an Evidence
Asset after review.

## Evidence Asset Validation

The conceptual process of evaluating whether an Evidence Asset is ready for
EcoChain readiness review.

## Evidence Asset Readiness

The state in which an Evidence Asset is sufficiently reviewed, traceable,
confidence-aware, and revision-ready to enter EcoChain readiness review.

## Living Object

A review object that remains open to future evidence and revision.

## Revision Capability

The ability to update an Evidence Asset when better evidence, confidence
changes, or governance context appears.

## EcoChain Participation

Future participation in EcoChain readiness or record concepts. It is not
implemented by this layer.
