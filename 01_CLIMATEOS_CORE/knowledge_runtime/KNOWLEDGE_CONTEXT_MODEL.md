# Knowledge Context Model

## Purpose

Knowledge must retain context so it is not misapplied.

## Context Fields

- project
- location
- climate zone
- governance scope
- time
- assumptions
- related evidence
- related RDA
- related validation
- related forecast candidate if relevant
- related Proof of Reality claim if relevant

## Context Principle

Knowledge without context can become misleading.

ClimateOS should preserve where knowledge came from, what it applies to, what
it does not apply to, and what assumptions it carries.

## Boundary

This document does not implement context retrieval or automated reasoning.
