# Knowledge Classification

## Purpose

Knowledge classification helps ClimateOS separate different knowledge roles
without turning the repository into a single unstructured document pile.

## Categories

| Category | Meaning |
| --- | --- |
| Foundation Knowledge | Stable architecture and framework documents. |
| Runtime Knowledge | Future runtime records, outputs, and operating context. |
| Strategy Knowledge | CRP, strategy notes, planning decisions, and direction-setting material. |
| Research Knowledge | Papers, experiments, technical notes, and research findings. |
| External Knowledge | Standards, provider documentation, laws, policies, or public references. |
| Domain Knowledge | Climate, ecology, water, energy, land, carbon, ESG, or governance knowledge. |
| Planning Knowledge | Scenario, forecast, option, risk, and project planning knowledge. |
| Governance Knowledge | Decisions, review requirements, participation, accountability, and policy context. |
| Future Vision | Concepts not yet mature enough for foundation or runtime use. |

## Boundary

Classification is conceptual only. No automated tagging, embeddings, vector
search, or classification runtime is added.
