# ClimateOS Knowledge Runtime

## Purpose

The Knowledge Runtime defines how ClimateOS organizes, indexes, references,
retrieves, and evolves knowledge independently from any specific storage
platform.

ClimateOS does not treat knowledge as only documents. It treats knowledge as:

```text
Knowledge Object
```
