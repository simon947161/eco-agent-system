# Knowledge Lifecycle

## Purpose

The Knowledge Lifecycle defines how an observation or discussion can become a
reviewable Knowledge Object.

## Lifecycle

```text
Observation
-> Discussion
-> CRP
-> Knowledge Object
-> Foundation
-> Validation
-> Runtime Use
-> Revision
-> Archive
```

## Lifecycle Notes

- Observation records what was noticed.
- Discussion explores meaning and uncertainty.
- CRP captures structured conversation radar output.
- Knowledge Object makes the content referenceable.
- Foundation documents stable concepts.
- Validation reviews evidence and assumptions.
- Runtime Use applies reviewed knowledge in future systems.
- Revision updates knowledge as reality changes.
- Archive preserves history without treating old knowledge as current.

## Boundary

This lifecycle is conceptual. No runtime workflow, agent, or automation is
implemented.
