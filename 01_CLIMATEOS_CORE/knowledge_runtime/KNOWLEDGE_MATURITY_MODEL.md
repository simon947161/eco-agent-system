# Knowledge Maturity Model

## Purpose

Knowledge maturity helps ClimateOS distinguish early ideas from validated or
operational knowledge.

## Maturity States

```text
Concept
-> Foundation
-> Prototype
-> Validated
-> Operational
-> Deprecated
```

## State Meanings

| State | Meaning |
| --- | --- |
| Concept | Early idea or future vision. |
| Foundation | Documented framework or architecture. |
| Prototype | Early tested form or structured example. |
| Validated | Reviewed against evidence, assumptions, and use context. |
| Operational | Used in a governed runtime or repeatable workflow. |
| Deprecated | Retained for history but no longer recommended. |

## Boundary

Maturity status is conceptual unless future validation and runtime processes
define review evidence.
