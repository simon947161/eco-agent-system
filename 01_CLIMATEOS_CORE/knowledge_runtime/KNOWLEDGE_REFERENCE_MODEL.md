# Knowledge Reference Model

## Purpose

The Knowledge Reference Model defines how one Knowledge Object may reference
another.

## Relationship Types

| Relationship | Meaning |
| --- | --- |
| supports | One object strengthens or provides basis for another. |
| extends | One object builds on another. |
| depends_on | One object requires another to be understood or used. |
| supersedes | One object replaces or updates another. |
| related_to | Objects are connected but not dependent. |
| validates | One object provides validation context for another. |
| cites | One object references another as a source. |

## Boundary

This model does not implement graph databases, automated relationship
extraction, or reasoning engines.
