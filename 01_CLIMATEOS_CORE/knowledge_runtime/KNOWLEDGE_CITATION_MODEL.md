# Knowledge Citation Model

## Purpose

ClimateOS knowledge should be reproducible and traceable.

The Knowledge Citation Model defines how knowledge should cite sources.

## Citation Targets

- foundation documents
- CRP
- external sources
- future research
- standards
- runtime outputs

## Suggested Citation Fields

- source title
- source path or URL
- author or maintainer if known
- publication or creation date if known
- access date for external sources
- version or revision
- quoted or paraphrased claim
- relationship to current Knowledge Object

## Boundary

This document does not implement citation extraction, reference management, or
automated source validation.
