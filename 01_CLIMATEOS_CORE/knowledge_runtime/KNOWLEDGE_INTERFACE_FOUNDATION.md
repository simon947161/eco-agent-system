# Knowledge Interface Foundation

## Purpose

The Knowledge Interface Foundation defines how ClimateOS can organize and
reference knowledge as a first-class resource.

Knowledge should support Observation, Evidence, Validation, RDA, Forecast,
Planning, Proof of Reality, EcoChain, and governance work without depending on
one storage platform.

## Core Positioning

ClimateOS treats knowledge as:

```text
Knowledge Object
```

not merely as documents, folders, notes, or database rows.

## Possible Knowledge Origins

- CRP
- strategy notes
- GitHub foundation documents
- research notes
- domain knowledge
- external standards
- future Obsidian Knowledge Garden
- future enterprise knowledge bases

## Storage Independence

Possible providers may include GitHub, Obsidian, local Markdown, enterprise
knowledge bases, future cloud knowledge systems, and future knowledge APIs.

The Knowledge Runtime should remain provider-independent.
