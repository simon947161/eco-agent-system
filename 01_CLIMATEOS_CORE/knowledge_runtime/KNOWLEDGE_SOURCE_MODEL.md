# Knowledge Source Model

## Purpose

The Knowledge Source Model defines where Knowledge Objects may originate.

## Source Categories

- GitHub foundation documents
- CRP records
- strategy notes
- research notes
- external standards
- domain knowledge
- local Markdown
- future Obsidian Knowledge Garden
- future enterprise knowledge base
- future cloud knowledge provider
- future knowledge API

## Source Metadata

Each source should preserve:

- source name
- source type
- owner or maintainer
- creation date if known
- version or revision
- access boundary
- citation requirement
- confidence or maturity note

## Boundary

This document does not implement provider connectors, APIs, synchronization, or
Obsidian automation.
