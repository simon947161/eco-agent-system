# ClimateOS Core

## Purpose

Provide the shared kernel, evidence conventions, validation boundaries,
governance controls, ontology, and interfaces used by subsystem families.

## Future Scope

Stable minimal-core schemas, reusable Agent Factory components, deterministic
runtime contracts, and cross-system compatibility.

## Example Future Agents

Core evidence router, review coordinator, schema validator, and report builder.
