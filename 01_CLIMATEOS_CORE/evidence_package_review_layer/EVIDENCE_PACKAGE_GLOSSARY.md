# Evidence Package Glossary

## Evidence Package

A structured set of evidence references, provenance, context, relationships,
assumptions, uncertainty, conflicts, and review notes.

## Completeness

The degree to which an Evidence Package contains enough information to be
reviewed.

## Traceability

The ability to follow evidence back to source, context, and review history.

## Provenance

The origin and handling history of evidence.

## Context

The spatial, temporal, ecological, operational, governance, and relationship
conditions needed to interpret evidence.

## Review Readiness

The state in which an Evidence Package is sufficiently clear and traceable to
participate in ClimateOS Review.

## Validation Readiness

The state in which an Evidence Package is prepared for future validation
processes.

## Revision Readiness

The ability for an Evidence Package to be updated when better evidence or new
conflict appears.
