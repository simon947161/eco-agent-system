# Evidence Context Model

## Purpose

The Evidence Context Model defines the context needed to interpret evidence
within ClimateOS Review.

## Context Types

- spatial context
- temporal context
- climate zone context
- ecological context
- operational context
- governance context
- source context
- relationship context
- uncertainty context

## Context Principle

Evidence without context may be misleading.

ClimateOS should preserve the conditions under which evidence was created,
observed, interpreted, or transformed.

## Relationship Context

Evidence should describe relevant relationships where possible, such as:

- rainfall and soil moisture
- vegetation and temperature
- forecast candidate and observed outcome
- governance claim and supporting evidence

## Boundary

No context engine, geospatial runtime, climate model, or automated
interpretation system is added.
