# Evidence Package Review Layer

## Purpose

The Evidence Package Review Layer defines how the ClimateOS Review Engine may
evaluate whether an Evidence Package is complete, traceable, reviewable, and
ready to participate in ClimateOS Review.

This layer does not determine whether reality is true.
