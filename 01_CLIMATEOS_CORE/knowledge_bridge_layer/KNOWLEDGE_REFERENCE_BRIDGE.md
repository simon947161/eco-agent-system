# Knowledge Reference Bridge

## Purpose

The Knowledge Reference Bridge defines how references from external knowledge
systems may conceptually map into ClimateOS relationships.

## Reference Sources

- Obsidian links
- Markdown links
- GitHub links
- local document references
- CRP references
- strategy note references
- future MCP resource references

## ClimateOS Relationship Types

- supports
- extends
- depends_on
- supersedes
- related_to
- validates
- cites
- conflicts_with

## Boundary

No link parser, graph database, backlink crawler, or automated relationship
extraction is added.
