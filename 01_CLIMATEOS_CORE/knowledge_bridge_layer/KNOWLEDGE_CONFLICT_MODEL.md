# Knowledge Conflict Model

## Purpose

The Knowledge Conflict Model defines how future bridge systems should describe
conflicts between knowledge sources.

## Conflict Types

- version conflict
- source conflict
- maturity conflict
- metadata conflict
- reference conflict
- classification conflict
- provider conflict
- content interpretation conflict

## Conflict Handling Principles

- preserve both claims until reviewed
- do not automatically overwrite knowledge
- record source and provider context
- identify affected Knowledge Objects
- require human review for high-impact conflicts

## Boundary

No conflict detection or resolution engine is implemented.
