# Knowledge Mapping Model

## Purpose

The Knowledge Mapping Model defines how provider-specific knowledge may map to
ClimateOS Knowledge Objects.

## Mapping Concepts

| Provider Concept | ClimateOS Concept |
| --- | --- |
| Obsidian note | Knowledge Object candidate |
| Markdown heading | Knowledge section or context |
| Tag | Classification candidate |
| Backlink | Reference candidate |
| Folder | Provider scope or domain context |
| Frontmatter | Metadata candidate |
| GitHub document | Knowledge Object candidate |
| Local document | Knowledge Source candidate |

## Required Preservation

Mappings should preserve:

- source
- provider
- title
- metadata
- references
- version
- context
- limitations

## Boundary

No parser, mapper, metadata extractor, or automated conversion is implemented.
