# Future Obsidian Bridge Foundation

## Purpose

This document defines a future bridge concept between ClimateOS Knowledge
Runtime and Obsidian-style knowledge systems.

## Positioning

Obsidian is a future Knowledge Provider candidate.

It is not:

- ClimateOS core
- a required dependency
- an implemented integration
- an automated synchronization runtime
- a validation engine

## Strategic Role

The bridge may later help ClimateOS connect:

- Knowledge Objects
- local knowledge gardens
- CRP notes
- strategy notes
- project records
- future agent context

## Provider Independence

The Obsidian bridge must not prevent future compatibility with GitHub, local
Markdown, MCP providers, enterprise knowledge bases, or future knowledge APIs.
