# Knowledge Bridge Layer

## Purpose

The Knowledge Bridge Layer defines the conceptual bridge between ClimateOS
Knowledge Runtime and future external knowledge systems.

The first target provider is Obsidian, but ClimateOS must remain provider
independent.
