# Provider Capability Model

## Purpose

The Provider Capability Model describes what a future Earth intelligence
provider may offer.

## Capability Categories

- observation
- simulation
- forecast
- digital twin
- evidence support
- planning support
- validation support
- governance context

## Suggested Capability Fields

- provider name
- provider type
- capability category
- spatial scope
- temporal scope
- uncertainty support
- validation support
- access boundary
- limitations

## Boundary

No capability registry or automated provider evaluation is implemented.
