# Simulation Provider Interface

## Purpose

The Simulation Provider Interface defines how future simulation providers may
support ClimateOS without becoming ClimateOS core.

## Conceptual Providers

- Destination Earth
- Earth-2
- scientific simulation platforms
- future Digital Earth systems
- future domain-specific simulation providers

## Possible Simulation Uses

- scenario exploration
- climate process simulation
- digital twin scenario support
- stress testing
- planning support

## Boundary

No simulation is implemented or executed.
