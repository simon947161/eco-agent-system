# Forecast Provider Interface

## Purpose

The Forecast Provider Interface defines how future forecast providers may supply
Forecast Candidates for planning and validation.

## Conceptual Providers

- ECMWF
- AIFS
- forecast model providers
- Digital Earth platforms
- future domain-specific forecast systems

## Forecast Principle

Forecast output is not truth.

Forecast output is a Forecast Candidate until validated against observed
reality and reviewed for uncertainty, bias, and governance relevance.

## Boundary

No forecast provider is integrated, called, or executed.
