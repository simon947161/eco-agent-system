# Earth Intelligence Routing

## Purpose

Earth Intelligence Routing defines how ClimateOS may conceptually route future
questions to appropriate provider categories.

## Routing Examples

| Question Type | Candidate Interface |
| --- | --- |
| What was observed? | Observation Provider Interface |
| What may happen under a scenario? | Simulation Provider Interface |
| What is likely to happen? | Forecast Provider Interface |
| What does a digital twin indicate? | Digital Twin Provider Interface |
| What evidence can be formed? | Evidence Interface |
| What needs validation? | Validation Interface |

## Boundary

No router, provider selector, API, or automated dispatch system is implemented.
