# Validation Input Model

## Purpose

The Validation Input Model defines possible future inputs to Validation
Runtime.

## Input Types

- Knowledge Objects
- Reality Claims
- Proof of Reality records
- Evidence Packages
- Forecast Candidates
- RDA records
- Evidence Assets
- EcoChain records
- Earth Intelligence provider outputs
- human review notes
- agent review notes

## Input Requirements

Inputs should preserve source, context, version, maturity, assumptions,
limitations, and related tasks or layers.

## Boundary

No input schema, API, or ingestion runtime is implemented.
