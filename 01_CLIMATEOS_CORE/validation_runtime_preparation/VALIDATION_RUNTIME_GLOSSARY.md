# Validation Runtime Glossary

## Validation Runtime

Future ClimateOS runtime for coordinating validation processes. Not
implemented in Task80.

## Validation Process

The staged review of knowledge, claims, evidence, forecasts, RDA, Evidence
Assets, and review findings.

## Cross Validation

Comparison across independent sources or methods.

## Confidence Update

A recorded change in confidence after review.

## Human Review

Accountable human review of evidence, assumptions, and governance relevance.

## Agent Review

Future assisted review by AI agents. It does not replace human accountability.

## Runtime Output

Future reviewed validation output package. Not implemented in Task80.
