# Provider Governance

## Purpose

Provider governance defines review concerns for using external observation
resources in ClimateOS.

## Governance Concerns

- Licensing
- Citation
- Data ownership
- Privacy
- Consent
- Dataset versioning
- Provider limitations
- Update frequency
- Uncertainty
- Human review
- Suitability for intended use

## Principle

External data should not become evidence or governance input without preserving
provider context and limitations.

## Boundary

No governance engine, policy automation, license checker, or compliance system
is implemented.
