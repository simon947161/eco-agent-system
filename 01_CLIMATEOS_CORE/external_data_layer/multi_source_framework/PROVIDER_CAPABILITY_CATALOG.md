# Provider Capability Catalog

## Purpose

This conceptual catalog lists potential observation capabilities by provider
family.

## Placeholder Catalog

| Provider Family | Possible Capabilities |
| --- | --- |
| NASA | Satellite observation, vegetation, soil moisture, fire, terrain, atmospheric context |
| Copernicus | Earth observation, land surface, atmospheric, emergency, and climate resources |
| ECMWF | Weather, reanalysis, forecast context, atmospheric resources |
| BOM | Australian weather, rainfall, climate, warnings, and hydrological context |
| Open-Meteo | Open weather and meteorological context |
| Local Sensors | Site-level water, temperature, soil, air, and operational observations |
| Community Observation | Local notes, photos, vegetation stress, disturbance, and lived experience |
| Future Providers | New observation sources that follow ClimateOS governance requirements |

## Boundary

This catalog is conceptual. It does not verify endpoints, current availability,
licensing, or operational suitability.
