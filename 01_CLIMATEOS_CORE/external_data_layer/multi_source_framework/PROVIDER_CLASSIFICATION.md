# Provider Classification

## Purpose

Provider classification helps ClimateOS distinguish source types without
depending on one provider.

## Classification Types

### Satellite Provider

Provides remote sensing or Earth observation resources.

### Meteorological Provider

Provides weather, climate, atmospheric, rainfall, or hydrological information.

### Local Sensor Provider

Provides site-level measurements from installed devices or field systems.

### Community Observation Provider

Provides human observation, local notes, photographs, or lived experience.

### Research Provider

Provides research datasets or derived scientific products.

### Future Provider

Provides a new resource type not yet represented.

## Boundary

No automated classification system is implemented.
