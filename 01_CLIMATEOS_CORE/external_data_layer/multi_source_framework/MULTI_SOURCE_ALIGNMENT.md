# Multi-Source Alignment

## Purpose

Multi-source alignment explains how ClimateOS may place different observation
resources into a shared context.

## Alignment Dimensions

- Location
- Time
- Climate zone
- Event window
- Observation type
- Units
- Resolution
- Provider limitations
- Evidence purpose
- Validation need

## Example Alignment

```text
BOM rainfall
+ NASA soil moisture
+ local water level
+ community vegetation stress note
= complementary observation context
```

## Boundary

No alignment algorithm, data transformation, or automated evidence synthesis is
implemented.
