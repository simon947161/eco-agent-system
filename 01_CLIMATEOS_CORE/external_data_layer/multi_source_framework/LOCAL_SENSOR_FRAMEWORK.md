# Local Sensor Framework

## Purpose

Local sensors may provide site-level observations that complement satellite,
weather, and community sources.

## Example Sensor Types

- Water level sensors
- Temperature sensors
- Soil moisture sensors
- Rain gauges
- Air quality sensors
- Flow meters
- Vegetation or site cameras

## Review Requirements

Local sensor observations should preserve:

- Sensor location
- Sensor owner or operator
- Calibration context
- Units
- Measurement frequency
- Maintenance notes
- Known limitations
- Data gaps

## Boundary

No sensor integration, hardware protocol, database, or real-time data pipeline
is implemented.
