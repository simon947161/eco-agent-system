# Observation Provider Model

## Purpose

The Observation Provider Model defines common fields for describing providers
that may supply observation resources to ClimateOS.

## Provider Fields

| Field | Purpose |
| --- | --- |
| Provider Name | Human-readable provider name |
| Provider Type | Satellite, meteorological, sensor, community, or future type |
| Observation Categories | Resource categories the provider may support |
| Spatial Coverage | Geographic coverage |
| Temporal Coverage | Time coverage or update window |
| Access Method | Possible access route |
| Data Format | Expected format or representation |
| Governance Requirements | Citation, licensing, ownership, and review needs |
| Validation Requirements | Checks needed before use |
| Limitations | Known constraints or unsuitable uses |

## Boundary

This is a documentation model only. No provider registry or schema is
implemented.
