# NASA Data Governance

## Purpose

This document defines governance concerns for future NASA Earthdata use inside
ClimateOS.

## Governance Concerns

### Licensing

Future use should respect dataset licensing and usage terms.

### Citation

NASA datasets should be cited according to provider guidance.

### Versioning

Dataset versions and processing levels should be preserved where available.

### Data Provenance

ClimateOS should preserve where data came from and how it was used.

### Update Frequency

Future systems should document how often a resource changes.

### Uncertainty

Known uncertainty should be preserved and passed into validation.

### Dataset Limitations

Resolution, coverage, missing data, and unsuitable use cases should be recorded.

### Human Review

NASA-derived evidence should remain reviewable by humans.

## Boundary

No governance engine, license checker, citation generator, or automated policy
system is implemented.
