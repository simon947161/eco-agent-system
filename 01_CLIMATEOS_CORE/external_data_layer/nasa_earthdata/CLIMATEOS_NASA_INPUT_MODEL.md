# ClimateOS NASA Input Model

## Purpose

This document defines how NASA data may become ClimateOS inputs in future
systems.

## Example Inputs

### Rainfall Input

May support hydrology, drought, vegetation, and disturbance context.

### Soil Moisture Input

May support dryland condition, vegetation stress, and water balance context.

### Vegetation Index Input

May support vegetation condition, recovery, and ecological signature context.

### Fire Anomaly Input

May support disturbance, fire risk, and recovery evidence context.

### Elevation Input

May support terrain, water flow, and climate zone interpretation.

### Biomass Input

May support carbon storage, ecological condition, and restoration context.

## Boundary

This model is conceptual only. No NASA data is converted into ClimateOS records.
