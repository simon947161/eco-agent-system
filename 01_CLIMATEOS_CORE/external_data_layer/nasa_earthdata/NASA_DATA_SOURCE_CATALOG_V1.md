# NASA Data Source Catalog V1

## Purpose

This conceptual catalog lists initial NASA Earth observation resource
categories that may be useful to ClimateOS in future work.

No live API calls are made.
No current endpoint availability is verified.

## Placeholder Categories

| Category | Possible ClimateOS Use |
| --- | --- |
| Precipitation | Rainfall context and hydrological evidence candidates |
| Soil Moisture | Drought, vegetation, and water balance context |
| Vegetation | Vegetation condition, stress, and recovery context |
| Biomass | Carbon storage and ecological condition context |
| Fire / Thermal Anomaly | Fire activity, heat anomaly, and disturbance context |
| Elevation / Terrain | Water flow, landform, and climate zone context |
| Land Surface | Land cover, land surface condition, and change context |
| Atmospheric Conditions | Weather and atmospheric relationship context |
| Extreme Event Observation | Flood, storm, drought, heat, or fire event context |
| Space / External Event Observation | External event context where relevant |

## Boundary

This is a placeholder catalog only. It does not select datasets for operational
use.
