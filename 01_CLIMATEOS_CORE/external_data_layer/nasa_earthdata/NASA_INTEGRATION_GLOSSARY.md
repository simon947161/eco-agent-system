# NASA Integration Glossary

## Observation Resource

An external data resource that may describe an environmental condition.

## Dataset

A named collection of data with a defined source and structure.

## Provider

The organization or system that makes a dataset available.

## External Data Layer

The ClimateOS layer responsible for conceptual organization of external
observation resources.

## Ingestion

The future process of bringing external data into a ClimateOS-compatible form.

## Data Provenance

Information about where data came from and how it was obtained or transformed.

## Spatial Resolution

The spatial detail of an observation resource.

## Temporal Resolution

The time interval or update frequency of an observation resource.

## ClimateOS Observation Record

A structured ClimateOS record that describes an observation with time, location,
source, and context.

## EcoEngine Input

A structured input that may be consumed by EcoEngine in future computation
workflows.
