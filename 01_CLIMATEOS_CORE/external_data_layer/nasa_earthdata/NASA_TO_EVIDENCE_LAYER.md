# NASA To Evidence Layer

## Purpose

This document explains how NASA observations may support evidence synthesis.

## Principle

NASA data alone is not evidence.

NASA data becomes evidence only when placed into:

- Spatial context
- Temporal context
- Relationship context
- CCZPS context
- Validation context

## Future Flow

```text
NASA Observation
-> ClimateOS Observation Record
-> Relationship Context
-> Evidence Candidate
-> Evidence
```

## Boundary

No evidence synthesis, ingestion, validation, or automated conversion is
implemented.
