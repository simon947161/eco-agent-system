# Reference Object Glossary

## Purpose

This glossary defines terms used in Task96.

## Terms

### Reference Object

A human-readable conceptual object used for examples, demonstrations, and
Task100 architecture discussion.

### Reality Claim

A claim about the state of reality that requires evidence and review.

### Knowledge Object

A structured knowledge item that may support evidence, validation, planning, or
future runtime context.

### Evidence Package

A grouped set of evidence items, provenance, and traceability context.

### Proof Record

A living record connecting a claim with supporting and conflicting evidence.

### Scenario Candidate

A proposed scenario that requires validation before governance use.

### Evidence Asset

A reviewed evidence object that may later be assessed for EcoChain readiness.

### Validation Pack

A structured validation output that preserves review context and result
information.

### Revision Status

The current state of an object as it moves through review, update, and
re-review.

### Conceptual Object

An object described for architecture clarity, not implemented as software.
