# Reference Proof Record

## Purpose

A Reference Proof Record illustrates how ClimateOS may connect a Reality Claim
to supporting and conflicting evidence.

## Conceptual Object

```text
Object Type: Proof Record
Claim Reference: Reference Reality Claim
Evidence References: Reference Evidence Package
Review Status: Living record, not final proof
Confidence Context: Evolves with evidence
Revision Status: Open
```

## Required Context

A Proof Record should describe:

- claim relationship
- evidence relationship
- review history
- confidence context
- uncertainty
- conflicting evidence
- reopening conditions

## Validation Relationship

Proof Records may flow through:

```text
Reality Claim Review
-> Proof Record Review
-> Collective Validation
-> Confidence Framework
-> Validation Pack
```

## Boundaries

This is not absolute truth, legal proof, blockchain proof, or immutable final
state.
