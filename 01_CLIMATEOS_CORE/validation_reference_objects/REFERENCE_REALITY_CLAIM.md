# Reference Reality Claim

## Purpose

A Reference Reality Claim illustrates how ClimateOS may describe a claim about
the state of reality before review.

## Conceptual Object

```text
Object Type: Reality Claim
Claim: A site has reduced vegetation stress after restoration activity.
Context: Placeholder ecological observation scenario.
Evidence Relationship: Requires observation records and supporting evidence.
Validation Relationship: Requires proof record review and evidence package review.
Status: Unresolved until reviewed.
Revision Status: Open.
```

## Required Context

A Reality Claim should identify:

- what is being claimed
- where the claim applies
- what evidence supports it
- what uncertainty remains
- what review path is needed

## Validation Relationship

Reality Claims may feed:

```text
Proof Record Review
-> Evidence Package Review
-> Collective Validation
-> Confidence Framework
-> Validation Pack
```

## Boundaries

This reference claim is not verified reality. It is an example object for
Foundation review.
