# Validation Reference Objects Foundation

## Purpose

Task96 defines reusable conceptual Reference Objects for ClimateOS validation
work.

Reference Objects help future examples and demonstrations use consistent
language without creating live runtime objects.

## Scope

Task96 defines reference forms for:

- Reality Claims
- Knowledge Objects
- Evidence Packages
- Proof Records
- Scenario Candidates
- Evidence Assets
- Validation Packs

## Design Principles

Reference Objects should be:

- human-readable
- reusable across examples
- aligned with existing Foundation layers
- stable enough for Task100 review
- revisable as the Foundation matures

Reference Objects should not become:

- executable schemas
- database records
- runtime objects
- automated validation inputs
- certification artifacts

## Relationship To Task95

Task95 explains example validation sessions.

Task96 defines the conceptual objects those examples can refer to.

## Relationship To Task100

Task96 supports Task100 by giving the Foundation a small, consistent set of
objects that future validation architecture can discuss clearly.

## Boundaries

No object runtime, registry service, API, database, generator, or automated
validation capability is added.
