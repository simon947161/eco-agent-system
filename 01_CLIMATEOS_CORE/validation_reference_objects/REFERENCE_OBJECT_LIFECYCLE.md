# Reference Object Lifecycle

## Purpose

This document defines the conceptual lifecycle of Validation Reference Objects.

## Lifecycle Stages

```text
Draft
-> Reviewable
-> Reviewed
-> Revision Requested
-> Updated
-> Re-reviewed
-> Archived or Superseded
```

## Draft

The object is described as a conceptual reference.

## Reviewable

The object has enough context to participate in examples or demonstrations.

## Reviewed

The object has been examined against Foundation requirements.

## Revision Requested

The object requires better context, evidence, or alignment.

## Updated

The object is revised after review.

## Re-reviewed

The object is assessed again after changes.

## Archived Or Superseded

The object is retained for traceability but is no longer the preferred example.

## Task100 Alignment

Task100 may use lifecycle language to explain how validation objects remain
reviewable and revisable.

## Boundaries

No lifecycle engine, status service, database, or automated workflow is added.
