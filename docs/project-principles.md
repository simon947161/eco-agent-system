# Eco Agent System - Project Principles

Eco Agent System is an experimental open-source project for environmental decision support.

This document defines the core principles for contributors, maintainers, and future AI-assisted workflows.

## 1. Physical Reality First

Environmental systems operate under physical constraints.

Climate, water, energy, soil, vegetation, ecosystems, and infrastructure conditions should be understood through observation, evidence, and scientific reasoning.

## 2. Stewardship Before Ownership

Environmental value is not only created by ownership.

Long-term care, monitoring, maintenance, restoration, and protection are important forms of contribution.

## 3. Contribution Before Authority

Project influence should come from useful contribution, responsible participation, and trust.

Contributions may include code, documentation, field observations, environmental indicators, planning knowledge, maintenance records, scientific review, governance design, and community experience.

## 4. Dialogue Before Control

Understanding should come before intervention.

Tools in this project should support comparison, review, and informed decision-making.

## 5. Long-Term Feedback

Environmental outcomes often appear slowly.

The project should support long-term thinking, delayed feedback, and maintenance-based evaluation.

## 6. Shared Humility

Humans and AI systems can both be wrong.

All models are incomplete.

All contributors should remain open to revision when new evidence appears.

## 7. Preserve Good Intent

A useful environmental project should record not only outputs, but also the purpose behind important actions.

Constructive intent, public-good motivation, and responsible maintenance are valuable parts of project history.

## 8. Knowledge as a Living System

Environmental knowledge should not remain isolated.

The project aims to connect planning, environmental science, engineering, GIS, climate adaptation, maintenance, risk reduction, and intelligent decision-support systems.

## 9. Human-AI Co-Stewardship

AI should support human judgement, not replace it.

Human users should use AI systems with care, review, and accountability.

## 10. Seed the Future

This project is early-stage.

Contributors are encouraged to build in a way that future maintainers, researchers, planners, and AI-assisted tools can understand, review, and improve.
