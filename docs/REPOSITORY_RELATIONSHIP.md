# Repository Relationship

## Repository Role

`eco-agent-system` is the environmental intelligence and decision-support foundation.

It supports CCZPS, ClimateOS, CarbonOS, WaterOS, EcoEngine-style reasoning, evidence interpretation and human-reviewed environmental decision support.

## Position in the Wider System

```text
Simon / Personal Headquarters
        ↓
Eco Agent System / Environmental Intelligence Foundation
        ↓
ClimateOS, CarbonOS, WaterOS, Evidence Passport and regional applications
```

## Relationship to Other Repositories

- `Simon` is the personal headquarters and project index.
- `climateos-knowledge-garden` is the internal Obsidian account book for CRP, radar notes and project memory.
- `BuildingOS` is the infrastructure governance platform.
- `wagga-climate-os` is a regional application that may reuse environmental intelligence patterns.
- `project-runtime-initiative` is planned as the independent human-AI project coordination runtime.
- `climateos-book` is the formal publication layer for ClimateOS knowledge.

## Boundary

This repository should focus on environmental reasoning and decision support:

- environmental evidence
- scenario comparison
- governance decision support
- climate, water, vegetation, resilience and carbon logic
- evidence passport and traceability concepts

Do not use this repository as the main home for:

- personal portfolio materials
- raw Obsidian notes
- book manuscript production
- generic multi-agent budget/runtime protocol
- application-specific website content unless it directly demonstrates the environmental engine

## Operating Rule

Eco Agent System is the environmental engine room.

If the question is about environmental evidence and decision support, it belongs here. If the question is about generic agent coordination, it belongs in the future Project Runtime Initiative.
