# Planning Approval Support Report Template

The report combines scenario background, required data sources, GIS/DEM readiness, validation status, expert review outcomes, evidence strength, unresolved risks, human approval boundaries, and recommended next steps.

It is a support report, not a planning application, approval, professional certification, engineering design, or construction instruction. Until required spatial evidence and qualified reviews are supplied, generated scenarios remain `not_ready_for_approval`.

The deterministic example is in `cczps_lite/output/planning_approval_support_report.json` and `.md`.
