# Expert Review Record Template

Expert review records are human-authored, auditable governance records. Each record contains reviewer role, review date, reviewed scenario or module, review category, finding, evidence reference, confidence level, required follow-up, and approval/rejection/conditional status.

Signed records must not be overwritten. Revisions are new records so prior findings remain inspectable. Generated examples use `record_status: template`, `confidence_level: not_assessed`, and `decision_status: not_reviewed`; they are not expert opinions.

Examples are in `cczps_lite/output/expert_review_records.json` and `.md`.
