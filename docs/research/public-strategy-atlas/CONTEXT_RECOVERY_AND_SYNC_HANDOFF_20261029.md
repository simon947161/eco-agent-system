## 2. 为什么看起来像“丢了”及其处理

- ChatGPT 工作会话、Codex 本地 worktree、OneDrive 与 GitHub **不是同一个存储空间，也不能假设会自动双向同步**。
- 本地 Git commit 即使干净，也不等于 `git push`。在另一个设备或隔离 Workspace 中，未推送的提交仍不可见。此处没有权限读取办公室机器的本地提交，也未读到 R0/K 的完整成果。
- Council 管理的设备和 OneDrive 可能包含工作记录、组织信息或特定知识产权，**不能为了跨机同步把整个目录、内部会议资料或会话原文直接复制到私人 GitHub**。
- 应将其分成：A 纯公开研究代码/图/合法允许上传的资料，B 私人但适合独立保存的想法/抽象模型，C Council 非公开/可能受雇佣条款约束的材料。C 留在机构批准的系统，**只在适当授权下**转移；遇不确定先做无敏感内容的摘要和权限审查。
