# CRP Harvest — GEGG CRL v0.1

- 核心知识点：公司退出应分离控制权、经济权、劳动回报、IP与使命资产。
- 想法点：建立 `Purpose Completion & Fair Exit Protocol`，把体面退出作为企业设计输入。
- 愿望点：参与者完成目标、获得合理回报后可以有序分开，环境使命仍被保护。
- 推理点：永久绑定个人既不公平也不稳健；预先约定的退出机制能降低冲突和权力寻租。
- 关键决策：采用分层退出、Good Leaver公平价值、使命资产登记、年度完成度审查；暂不照搬海外信托。
- 未解决问题：澳大利亚实体形式、股权比例、估值公式、遗留环境分配比例、员工池和税务处理。
- 下一步行动：Founder审阅；之后仅形成律师/会计师审阅清单，不实施真实股权或公司动作。
- 项目关联关键词：`GEGG` `CRL` `Fair Exit` `Purpose Completion` `Steward Ownership` `Employee Ownership` `Mission Lock` `Auto-Company`。
