# CRL-004 — Buyer / Problem Discovery Protocol v0.1

Design only. No interview or message is authorised.

The protocol records: participant authority and consent; organisation class; current problem and consequence; existing workaround; urgency trigger; evidence standard; procurement path; budget ownership; alternatives; willingness-to-pay range only after the problem is understood; conflicts; source and timestamp.

Questions must be neutral. A conversation is invalidated as market evidence if it pitches before discovery, implies certification, suppresses negative feedback, or lacks authority/consent. Raw personal data is excluded from the CRL evidence pack; only a minimised, consented record may later be admitted.
