## 4. Limitations and unresolved questions

- No authoritative source containing the verbatim original definitions of
  `GGG-001`—`GGG-008` was recovered. This package binds those IDs to the
  previously approved Phase 0–2 deliverable sequence and records the gap.
- The validator is a bounded prototype, not a complete schema engine or
  production security boundary.
- The fixtures are synthetic; no real project, customer, environmental or
  building decision is authorized.
- MCP/OpenAPI/event transport, identity namespaces, signatures, registry
  deployment and event-sourced storage remain unresolved.
- Placement into an authoritative GitHub branch requires a separately scoped
  publish action; this batch deliberately avoided the dirty ClimateOS worktree.
