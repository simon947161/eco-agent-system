P1-A / 02 · 历史方法

AWT2015：先恢复公式，再判断适用性

F2015L00060：2015-01-19 至 2025-03-31。2026年咨询文件是提案，不能作为生效规则使用。

§17 · Equation 1 · 年度净减排账AN = A0 + AAcc历史 P0 的章节引用已在新审计中更正；冻结原记录保持原样。

甲烷如何计入

填埋基准潜力 × 州级收集假设 × 氧化折减，再与项目燃料、电力、堆肥、消化和燃烧排放比较。

三个易错点

F(C→CH₄)=1.336；Eq16 的 CE=0.98 是收集效率；外部因子通常按报告期末版本，§31电力因子另有规则。

没有授权的修正

已核对的20式未显式使用气温、水温、降雨、海拔或Q10。州因子与电网因子不等于气候响应。

§43–46要求监测、校准、报告与分参数缺失处理；不能把缺失数据统一置零。旧项目过渡与外部NGER版本仍需专业逐项审查。

P1-A / 03 · 生物化学

产生、氧化、捕集与排放是不同量

有机碳经过水解、发酵及产甲烷过程，生成的甲烷还会溶解、储存、迁移、被氧化或进入收集装置。

有机物
组成 / 可利用性→厌氧降解
群落 / 温度 / pH→CH₄ 产生
溶解 / 储存 / 迁移→去向分流
氧化 / 收集 / 大气

覆盖层氧化

甲烷氧化菌需要甲烷与氧气。土壤水分同时影响活性与气体扩散，最优实验水分不能当作全场默认值。

捕集并非全部销毁

收集量、燃烧销毁量、装置泄漏与排气分别登记。避免重复扣减，也不能遗漏侧向迁移和库存变化。

塘面通量并非产生率

塘面释放可能含上游带入的溶解甲烷；曝气、风及水动力改变脱气。测得通量不能全部归因于本塘微生物产生。

物理约束：所有质量项必须使用相同边界、单位与积分时间。CH₄质量、CO₂e核算与获签信用量不等价。

P1-A / 04 · 温度与季节

更暖，不自动意味着更高净排放

温度可以同时改变有机物分解、甲烷产生与甲烷氧化。水分、底物和收集状态决定这些变化如何叠加。

文献观察

Yvon-Durocher2014汇总跨尺度温度响应；其平均表观Ea不是Cooma设施参数。Allingham2013的塘体观测中，降雨还携带粪污底物。

实验的边界

Lam2026的温度×水分土瓶实验说明交互作用；均质、筛分土与重复注气不等同于具有裂隙的真实填埋覆盖层。

季节的混杂

水温、分层、进水负荷、风、曝气及采样时段共同变化。两季观测不等于全年连续验证，相关性不等于因果。

研究模型族 · 不执行r(T) = rref Q₁₀(T−Tref)/10Q10需注明温区、水分、对象与校准；不得默认取2或加进AWT法定式。

P1-A / 06 · 变量体系

位置是背景，反应层状态才是机制输入

直接测量 / 元数据

传感器实际水温、填埋体温度、流量、pH、ORP；BOM站点坐标与海拔属于站点元数据，不是设施测量。

代理 / 推算

目前未知

设施反应层温度、真实捕集效率、覆盖层结构与厂级长期排放。未知保留UNKNOWN，不能用地图或新闻填值。
