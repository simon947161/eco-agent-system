BATCH D · 07 / 12

HYPOTHESIS / CONSERVATION

生成与排放之间还有什么

气象影响生成、氧化、输运和储存；运营改变收集与销毁。净排放方向不必与生成一致。

底物与生成→储存 / 收集 / 氧化→地表与设备排放
只测净通量，不能唯一反推出全部过程。CH₄、N₂O、CO₂和能源需各自证据。
