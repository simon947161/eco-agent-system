# D0 — 同一过程、同一可测量边界
2026-11-04 · DESIGN_ONLY · P1-A科学准入 PENDING

首选过程为**生活/混合固体废物填埋 CH₄**。污水塘、堆肥、自然湿地不混入训练或排名。Cooma、Lakes Creek及两污水厂仍为此前部分身份候选；本轮未获得它们的气体观测，也不以美国观测替代这些地点的实测。

## 比较对象
主目标 y_j 是指定设施 footprint 在完整区间 [t0,t1) 向大气排放的 CH₄ 质量 [kgCH₄]；辅助目标 q_j=y_j/Δt [kgCH₄/h]。表面通量 [kgCH₄/m²/h] 只有通过可论证的空间积分才可换成设施量。塔站坐标不是填埋场坐标；气团足迹不是行政边界。

| 方法 | 可比较性 |
|---|---|
| A-legal：历史AWT2015信用规则 | 输出tCO₂e与项目反事实、资格、分期有关；对实测场址CH₄为 NOT_COMPARABLE。只比较规则结构。 |
| A-factor：独立经验因子基线 | 仅在因子与同一排放目标、历史活动量及时间支持匹配时可比较；不是AWT公式改造。当前无合格因子，参数留空。 |
| B：IPCC FOD | 产生量、回收量、氧化量分开；清单部门边界与整场大气排放边界须桥接。年度原式不直接参加日峰排名。 |
| C：过程响应模型族 | 与B同一废物历史、边界和观测算子；需独立过程测量。额外输入的价值与算法价值分开报告。 |

## 必须冻结的比较合同字段
- facility_id、cell_id、polygon版本/CRS、观测footprint及覆盖比例；不以许可证计设施。
- 废物历史 W[i,t]、组分/DOC/DOCf、初始库存/关闭与填埋日期、覆土/收集变更；所有方法共用证据版本。缺历史不能只给C拟合自由初值却让B用零初值。
- t0/t1原始时钟、UTC转换规则、时区/DST、采样/平均时段；数据频率与模型输出频率分开。
- 气体量：质量优先；体积必须注明参考T[K]、P[Pa]、干湿基准和CH₄摩尔分数。上述值当前未锁定，不默认标准温压。质量kg、t与Gg显式换算。
- 生成G、收集Rcol、销毁D、氧化O、表面排放Es、旁路/设备滑脱Ed、侧向/溶解输出X、储量变化ΔM。若观测只覆盖Es，不拿Es+Ed预测比较。
- 历史AWT tCO₂e与物理CH₄分表；研究主目标不需要GWP。将来若转换，锁定评估报告/时域/化石或生物源定义；本轮GWP=null。生物源CO₂不是物理零排放。
- 年积分只用于全年度代表性与缺测不确定性可证明的资料。稀疏航测或风向筛选塔数据不能无说明年化。事件峰需足够时间分辨率；不把年度量均匀摊成小时“预测”。

## 两条公平比较轨道
1. 共同信息轨道：相同历史活动、运营及气象可用截止时刻，相同观测算子；B默认参数及C参数来源公开。可预注册匹配校准预算的版本。
2. 增强信息轨道：C增加实测体温/水分时，单列新增测量成本与信息收益；不能把增量全部归功模型。既有CALMIM等也可作为增强基线。

接受的是比较设计的可审查性，不是模型有效性。单位/部门/过程/时空支持不能桥接时，结论必须为 NOT_COMPARABLE，而非“误差较大”。
