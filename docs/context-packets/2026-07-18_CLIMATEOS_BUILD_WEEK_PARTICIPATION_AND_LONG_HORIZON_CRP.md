## Corrected submission identity

### Project name

**ClimateOS — A Living Human–AI Operating System for Climate Stewardship**

### Core description

ClimateOS is a sustainable, growing human–AI operating system for shared
climate stewardship and governance. It combines human life experience, local
observation, values and action responsibility with AI long-term memory,
scientific synthesis, multi-model reasoning, evidence organisation and system
execution.

The Build Week work makes one part of that long-term system directly
experienceable: a human can bring a meaningful environmental question into a
structured runtime, inspect how it becomes ongoing research, and remain an
active participant in its memory, interpretation and action.

  environmental question;
