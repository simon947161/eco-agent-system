# Task672 External Model Category Map

## Purpose

Define model categories ClimateOS may discuss before any adapter is proposed.

## Category Map

| Category | Examples | Review Need | Boundary |
| --- | --- | --- | --- |
| Open scientific models | Peer-reviewed or open-source research tools | Method, assumptions, version, validation history | No execution or integration in this batch. |
| Government or institutional tools | Public climate, water, land, biodiversity, or hazard tools | Authority, update cycle, method note, jurisdiction | Public description only; no data call. |
| Commercial scientific tools | Licensed analytics or modelling platforms | Permission, cost, restriction, output rights | No connector or account use. |
| Research prototypes | Lab tools, papers, experimental models | Maturity, reproducibility, uncertainty | Cannot be treated as operational proof. |
| Local specialist models | Expert spreadsheets, local agency models, site tools | Owner, calibration, auditability, review status | Requires explicit permission before reuse. |
| Foundation or language models | Text, summarization, reasoning, extraction assistants | Non-authoritative role, hallucination risk, review workflow | Suggestions only; no final decision authority. |
| Founder-reserved private models or assets | Private EcoEngine material or reserved prototypes | Founder Gate required before any discussion beyond boundary | No access, no scan, no summary, no reconstruction. |

## Human Meaning

The same word "model" can mean very different things. A hydrology simulation, a
satellite product, a planning spreadsheet, and a language model do not have the
same authority. ClimateOS must avoid mixing them into one vague bucket.

## Review Questions

- Who owns the model?
- What does the model claim to represent?
- What inputs does it require?
- What outputs does it produce?
- What assumptions does it carry?
- What is the validation history?
- What is the licensing or permission status?
- What uncertainty remains?
- What kind of human review is needed?

## Current Capability

This category map is conceptual. It does not identify, select, connect to, or
execute any specific external model.
