# Task678 Founder Gate Triggers For Future Model Integration

## Purpose

Define events that require explicit Founder authorization before any future
external model integration work can begin.

## Founder Gate Triggers

Founder Gate is required before:

- naming a specific private EcoEngine asset for reuse;
- accessing any `D:\eco_engine_v200` material;
- connecting ClimateOS to any external model provider;
- creating adapter, connector, API, CLI, MCP, database, authentication, or
  automation code;
- running a model or calling a model provider;
- retrieving live data from an external provider;
- persisting model outputs in an operational record;
- turning model output into scoring, certification, compliance guidance,
  assurance guidance, ESG conclusion, carbon conclusion, or governance action;
- allowing an agent to invoke, route, or interpret model output without human
  review;
- publishing model-derived outputs outside the bounded review context;
- using commercial or restricted-license model outputs;
- using sensitive, private, or non-consented input data.

## Gate Package Requirements

A future Founder Gate package should identify:

- model identity and owner;
- permission and licensing state;
- proposed use and non-use;
- data input boundary;
- output boundary;
- validation evidence;
- uncertainty handling;
- failure handling;
- privacy and private-asset controls;
- human review process;
- expert review process where needed;
- prohibited uses;
- tests and review records;
- stop condition.

## Human Authority Rule

No external model may decide, approve, verify, score, certify, assure,
determine compliance, produce ESG or carbon conclusions, interpret standards,
interpret frameworks, or replace Human Review or Founder Gate.

## Current Capability

This document defines gate triggers only. It does not open any gate.
