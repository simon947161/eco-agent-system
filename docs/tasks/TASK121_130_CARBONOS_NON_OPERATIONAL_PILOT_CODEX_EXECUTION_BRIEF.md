## Evidence Discipline

Codex must preserve clear separation between:

- raw data
- observation
- inference
- evidence
- claim
- recommendation

Pilot cases must be labelled fictional, illustrative, or non-operational.

No pilot output may be presented as a validated environmental conclusion.

## Expert Review Triggers

Task121-130 must preserve all 13 Task101 expert review triggers:

1. high uncertainty
2. conflicting evidence
3. low confidence
4. missing critical data
5. regulatory consequence
6. engineering consequence
7. safety consequence
8. insurance consequence
9. legal consequence
10. financial consequence
11. public-impact consequence
12. irreversible or high-cost project action
13. domain-specific technical judgment

If a fictional pilot activates a trigger, the document must state that expert review would be mandatory in a real case.

## Action-Authority Boundary

A CarbonOS / ClimateOS recommendation is not an action authority.

It may identify a possible next step, review requirement, or decision option, but it cannot authorize implementation, approval, construction, investment, compliance declaration, public claim, or operational action without the required human, expert, or governance approval.

This statement must appear in the README and in any fictional pilot case, review, or architecture gate document that contains recommendations.
