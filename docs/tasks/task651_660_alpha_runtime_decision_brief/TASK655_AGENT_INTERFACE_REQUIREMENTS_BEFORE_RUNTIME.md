# Task655 Agent Interface Requirements Before Runtime

## Purpose

Separate Agent Interface questions from Human Interface questions before any
runtime is authorized.

## Agent Interface Meaning

The Agent Interface is the future boundary through which ClimateOS may assign,
constrain, inspect, and audit agent work.

It is not agent autonomy. It is agent governance.

## Future Agent Types

Possible future agents may include:

- observation intake assistant;
- source and citation assistant;
- evidence structuring assistant;
- BiodiversityOS inquiry assistant;
- CarbonOS comparison assistant;
- WaterOS / LandOS routing assistant;
- model-output review assistant;
- risk and misuse review assistant;
- Founder Gate preparation assistant.

## Required Constraints Before Agents Run

Before any agent runtime exists, ClimateOS must define:

- task scope;
- allowed sources;
- prohibited sources;
- private asset boundary;
- evidence-state permissions;
- human review checkpoints;
- audit trail requirements;
- stop conditions;
- output labels;
- non-authority rules.

## Human-Agent Relationship

Agents may help gather, structure, compare, and explain. They must not silently
decide, certify, score, deploy, or override human review.

## Current Capability

This file frames future agent-interface requirements. It does not implement
agents, agent runtime, MCP tools, automation, tool calling, memory systems, or
model connectors.
