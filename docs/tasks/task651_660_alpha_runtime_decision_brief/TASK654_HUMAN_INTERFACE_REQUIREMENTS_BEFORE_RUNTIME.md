# Task654 Human Interface Requirements Before Runtime

## Purpose

Describe what the human-facing interface must be able to explain before Alpha
Runtime should be authorized.

## Human Interface Meaning

The Human Interface is the part of ClimateOS that helps people understand,
question, review, and govern system work.

It is not just a dashboard. It is where humans see the state of knowledge and
decide what can or cannot move forward.

## Required Human-Readable States

The interface must clearly show:

- observation;
- hypothesis;
- evidence candidate;
- evidence need;
- reviewed evidence;
- disputed interpretation;
- rejected claim;
- uncertainty;
- human review required;
- Founder Gate required;
- prohibited use.

## Required Human Actions

Humans must be able to:

- pause a record;
- request more evidence;
- reject a claim;
- mark uncertainty;
- require expert review;
- escalate to Founder Gate;
- distinguish model assistance from reviewed evidence;
- prevent public-facing use.

## Interface Principle

The interface must make uncertainty visible. It must not hide uncertainty behind
beautiful screens, automation language, or artificial confidence.
