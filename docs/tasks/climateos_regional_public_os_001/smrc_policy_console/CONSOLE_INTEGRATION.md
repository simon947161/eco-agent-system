## Console 中增加的最小能力

1. **政策资源页**：版本、文件摘要、适用时段、来源、已替代/待核状态、定位与读取范围；旧版本可重开。
2. **目标与空间映射**：CSP战略目标→LSPS行动→DP/OP实施条目；明确原文关系/研究者解释，旧CSP编号不得无声映射到新编号。
3. **三主线研究卡**：问题、已知、假设、反证、指标口径、所缺证据、下一检验。复用EEO、Receipt、Passport及L/S等级。
4. **责任与机会卡**：按公开职能记录责任，人员另设核验日；展示对谁有用、成本和受益、已有措施、低成本试验、停止条件及独立性检查。
5. **研究治理视图**：来源新鲜度、缺口、冲突、待人工判断和最新运行证据。只呈现研究与证据状态，不以总分替代政府决定。
