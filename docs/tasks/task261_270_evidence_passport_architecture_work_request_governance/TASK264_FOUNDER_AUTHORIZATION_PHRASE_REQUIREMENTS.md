# Task264 Founder Authorization Phrase Requirements

## Purpose

Define how Founder authorization phrases must be handled for any future Evidence Passport Architecture Work Request.

## Exact Phrase Requirement

A future architecture batch must not begin unless the exact Founder authorization phrase required by that future batch is provided.

## No Implied Authorization Rule

Authorization must not be inferred from context, intent, prior recommendations, prior completion, or adjacent wording.

## No Paraphrased Authorization Rule

Paraphrased authorization is not sufficient when an exact phrase is required.

## No Authorization By Intent Rule

Intent to proceed is not authorization unless the exact required Founder phrase is provided.

## No Authorization By Recommendation Rule

A recommendation for a next batch does not authorize that batch.

## No Authorization By Completion Of Prior Task Rule

Completion of Task261-270, or any prior task, does not authorize future architecture work.

## No Authorization By Template Rule

A template or package requirement does not authorize architecture work.

## Founder Phrase Placement Requirement

A future request package must place the required Founder authorization phrase in a dedicated authorization section.

Execution must not begin until that exact phrase appears in the user instruction or authorization record.

## Repository Identity Confirmation Requirement

Before any future request execution, repository root, branch, remote URL, and working tree status must be confirmed.

Execution must stop if repository identity is wrong or uncertain.

## Boundary Confirmation Requirement

The future authorization phrase or brief must restate no-runtime, no-implementation, no-automatic-continuation, and any other active boundaries.

## Block-Before-Execution Rule

If the exact required Founder phrase is missing, Codex must stop before creating files, updating indexes, committing, pushing, or beginning the batch.

## Future Phrase Authority Boundary

Task261-270 does not define or grant that future architecture authorization phrase.

This task may define requirements for future authorization phrase handling, but must not authorize future architecture.
