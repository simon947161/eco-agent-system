# 创始人报告：同样一吨温室气体，在不同高度排放是否一样？

日期：2026-11-09。**目前不能给出“高空同一吨更强”的通用结论，也不能证明所有气体、所有时域都完全一样。** 必须先问：同一种气体？比较附近浓度，还是全球长期增温？是只有排放高度改变，还是燃料消耗、NOx、水汽与尾迹也改变了？

## 这轮真正取得了什么

优先检查 NASA ATom。其仪器资料证明，飞机可测量经过水汽修正、校准及采样时滞修正的 CH4/CO2 干摩尔分数；但本轮未取得可重放的 ATom 飞行数值文件，两个相关入口返回 403 后停止。

备选 NOAA AirCore 的公开 CC0 ZIP 已实际下载、计算 SHA-256，并从中按预先规则选择一份 2012-01-14 BIG002 剖面。归档了 **2,137 条气体记录和 5,457 条气象记录**。记录的高度字段范围约 **722–21,686 m**，这是文件的 Alt 字段范围，不冒充已解决的海拔基准，也不是 ATom 的高度范围。

结构检查发现 CH4、CO2、P、T、RH 字段有值；CO 有 127 条 NaN；整数秒时间标签有 138 个重复增量，而带小数秒字段无重复。这不是重复测量已被证实，不能按整数秒直接合并。数据可用来审查原始结构，但气象精度、湿度参照与同步、垂直基准和代表性预算不完整，因此 **没有运行跨高度 P1 换算，没有比较高低层效应，没有运行排放或气候模型**。

第三候选只检查 WDCGG Jungfraujoch 元数据。它是固定高山站，不是同次飞行的多个高度；政策确认、气象配对及误差还未完成。到三候选为止，不再扩展。

## 已有科学支持什么，反证在哪里

1. **同样的摩尔分数，不同气压温度下，mg/m³ 可以不同。** 这由理想气体关系解释：每立方米空气的分子数量变了。它不意味着同一吨 CH4 的 GWP 自动改变，也不意味着现场排放量变化。此项是理论与既有 P1 参考测试支持，不是本轮高空实测比较通过。
2. **释放地点和高度会影响输送、稀释、暴露和被仪器采到的浓度。** 但一次气球下降同时改变时间、位置和气团；本次剖面不能把这些变化唯一归因于高度。
3. **航空总气候效应不能等同于 CO2 本身。** 航空研究包含 NOx 化学、水汽、尾迹和云。Grewe 等的空间反事实主要是 NOx/水汽；其中甲烷响应是 NOx 改变化学后引起的变化，不是固定质量 CH4 在两个高度释放的直接试验。把这些研究写成“高空一吨 CO2 比地面一吨更强”会混淆对象。
4. **CO2 的长期充分混合响应，是重要零假说。** 已发表模型常把长寿命 CO2 近似看作充分混合，并使用全球脉冲响应。该假设适合形成比较基线，却不是单靠模型设定就证明位置完全无关。本轮没有独立重现同质量不同高度的 CO2 气候对照。
5. **CH4 可能更需要位置相关的化学检验，但目前不能量化。** 必须区分直接 CH4 排放与 NOx 导致的 CH4 寿命变化，并控制 OH、气团、太阳辐射、背景排放和时间尺度。现有本轮证据不足以建立海拔甲烷因子。

## 能否按地区定制减排？可以研究条件，不能凭高度发明系数

即使长期每吨气体效应接近，地区的最佳行动仍可能不同：工艺、源强、可捕集性、运行可靠性、成本和当地环境不同。

| 活动域 | 有条件的研究方向 | 必需实测与限制 |
|---|---|---|
| Cooma 填埋设施候选 | 有机物分流、覆盖层与捕集维护的可行性比较 | 身份/许可/真实废物组成、湿度、气量、CH4、氧化及泄漏；现有高空观测不能代替这些数据 |
| Rockhampton 污水设施候选 | 工艺与负荷控制、厌氧单元捕集、设备运行及 N2O 权衡 | 实际水温、COD/BOD、流量、停留时间、曝气、气体通量、能源；不能因气候较暖就给减排百分比 |
| 农业/矿业/城市 | 分源监测和泄漏管理，检查可干预性 | 不以区域背景浓度倒推个别源强；需合法设施观测和源识别 |
| 航空 | 燃油/CO2 与 NOx、尾迹分别列账，评估安全和气象约束 | 多目标权衡；民航涡轮主要使用航空煤油，不能套用“柴油效率=每吨 CO2 高度效应” |

这些是**条件化方法建议，不是项目效果验证**。没有新的 IPCC/ACCU/AWT 法定系数、信用或配额建议。
