## 3. Rejection reasons

Standard rejection codes:

| Code | Meaning |
|---|---|
| `RJ-SOURCE-CLASS` | attributed statement presented as independent fact |
| `RJ-VERSION` | controlling version unresolved |
| `RJ-SPATIAL` | spatial support or geometry inadequate |
| `RJ-HEIGHT` | measurement/reference height absent or incompatible |
| `RJ-TIME` | period, averaging or recovery inadequate |
| `RJ-QC` | calibration or quality-control evidence absent |
| `RJ-METHOD` | correlation/extrapolation/model method absent |
| `RJ-UNCERTAINTY` | uncertainty budget absent |
| `RJ-LICENCE` | retention/reuse basis unresolved |
| `RJ-AUTHORITY` | qualified consenting reviewer absent |

Claims `C-009` to `C-012` fail multiple codes. They must not be softened to “low confidence”; they remain rejected or prohibited.

## 4. Re-review triggers

Re-review may begin only after a material trigger:

- public EIS or technical wind appendix appears;
- current official layout/GIS becomes available with terms;
- met-mast/LiDAR coordinates, heights, period and QC summary become public;
- a licence-compatible dataset and uncertainty method become available;
- the Founder authorizes a bounded inquiry or qualified reviewer contact;
- a controlling later record resolves a version conflict.

The mere passage of time is not a re-review trigger.
