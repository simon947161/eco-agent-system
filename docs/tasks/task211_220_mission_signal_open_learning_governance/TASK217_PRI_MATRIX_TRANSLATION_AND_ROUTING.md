# Task217 PRI Matrix Translation And Routing

## Purpose

Document the relationship between ClimateOS and PRI / Matrix governance without making PRI an implementation dependency for ClimateOS.

## Principle

```text
Translate first.
Route second.
Govern third.
Execute last.
```

Execution is last and requires separate authorization.

## ClimateOS And PRI

PRI / Matrix may provide governance, routing, continuity, and translation concepts that help ClimateOS manage future complexity.

PRI / Matrix does not automatically authorize ClimateOS implementation.

## Translation First

Translation means converting external governance concepts into ClimateOS-compatible language before use.

Translation should clarify:

- source system
- meaning
- ClimateOS relevance
- boundary
- uncertainty
- ownership
- review requirement

## Route Second

Routing decides where the translated signal belongs:

- Mission governance.
- Signal governance.
- Open Learning.
- Knowledge Harvest.
- Evidence Passport planning.
- AEP review.
- Roadmap Task200.
- Roadmap Task300.
- Deferred recommendation.
- Outside ClimateOS.

## Govern Third

Governance checks whether the routed concept is safe, compatible, and authorized.

Governance should prevent accidental conversion of PRI / Matrix concepts into ClimateOS runtime work.

## Execute Last

Execution is out of scope for Task211-220.

Any future execution requires explicit Founder authorization, implementation scope, review gates, and boundary confirmation.

## Boundary

PRI remains a governance and routing layer, not a ClimateOS implementation dependency. This document does not implement PRI, Matrix, MCP, n8n, agents, runtime, or automation.
