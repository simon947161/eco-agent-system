## 第一章练习（额外4题，均为作者练习）

1. 生成100kg、库存增5kg、无捕集和反应，有多少排向大气？**答：**只有在无流入/外流等明确假设下为95kg；不是任何实际填埋场默认值。
2. 捕集60kg是否等于毁灭60kg？**答：**不是，还要扣管漏、储存变化、旁路与未燃烧部分；捕集为内部转移。
3. 16kgCH4反应后产生44kgCO2是否不守恒？**答：**碳均12kg；氧来自O2。CH4物种消耗和碳守恒分别核查。
4. 5kg甲烷横向离开选定边界是否就是减排5kg？**答：**不是，最终去向未知；扩大边界后可能仍排向大气。

## 第八章复习题（额外3题）

1. 同一组测量用于拟合和验证可以宣称独立验证吗？**答：**不可以，需留出期/地点并控制共享误差。
2. 某PDF403而搜索摘要可读，状态如何记？**答：**正文/字节BLOCKED或METADATA_ONLY；不能制造哈希和条款。
3. 收到新指南后如何更新？**答：**先存版本/合法收据/章节差异，再追加理解变化、影响公式和审查记录，不改历史冻结条目。
