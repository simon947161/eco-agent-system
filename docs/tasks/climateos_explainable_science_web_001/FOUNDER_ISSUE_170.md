# CLIMATEOS-EXPLAINABLE-SCIENCE-WEB-001｜中文人话科学解释站
Founder：2026-11-26。执行者：Codex。目标：将已经存在的科学研究转成人人看得懂、可追溯原始证据的全中文网站，**不是开发新模型**。独立分支、Draft PR、不得合并部署。

## 1. 开工前只读核验
从最新远程 main 检查已有网站/组件、NEXT_SESSION及各研究索引；逐一确认以下 Draft PR 的 HEAD、来源、数据类型、状态、限制、引用路径：甲烷与物理计算 #135–#145（重点 #137、#138）；自然系统/ENSO/耦合场 #146–#149、#152、#153、#155、#157；CarbonOS/AWT #132、#163、#165、#168、#169；Cooma/地方研究 #125、#127、#129、#130；API研究记录 #161。建筑/社区能源韧性若只有本地文件，标记 NOT_FOUND_REMOTE，不猜测已上传。勿在不同未合并分支间盲目拼接核心代码。

## 2. 产品交付
在现有最恰当网站/静态目录做可运行、响应式、无登录、全中文的研究解释站（本地可预览，**不正式部署**）。首页回答：ClimateOS为什么存在、已经做过什么、没有证明什么、三分钟先看哪里、各研究分支关系与下一阶段科学闸门。采用路线地图/故事卡而非三栏管理后台。中文标题、描述、按钮、图例；缩写首次展开；技术细节折叠且可以追溯原始来源。

至少以下主题入口：
A 甲烷气压/温度/湿度/海拔：区分气体比例、单位体积浓度、实际排放；解释为什么选择沿海/内陆对比。
B PR #138 P1–P4 四个受限实验：逐一用“问题—为什么做—生活类比—假设和输入—计算结果—证明了什么—还没证明什么—原公式/代码/测试”讲清。首屏必须以甲烷气压为故事示范。
C 气象、ENSO、水文、时空场与多场耦合（#146–#155）；不同尺度，真实数据与合成数据区别。
D CarbonOS与AWT（#132/#163/#165）：核算数字和碳信用不是一回事；受限假设的四情景和数据缺口。
E Cooma本地研究与水文/环境证据（#125/#129/#136/#139/#169）：地址/空间位置不等于污染因果。
F BuildingOS / Energy / Resilience：仅展示有确证的现有研究和候选问题，不能冒充已建成系统。
G 给研究者的折叠层：原方程、单位、参数、输入、数值方法、对照实验、源代码和证据链接。

每张研究卡必须有一句话研究问题、出发点、数据类型、做法、结果、没有证明的事、研究状态、源PR/文件/固定SHA、日期、下一道验证门。增加“30秒读懂”“展开科学细节”和常见误解：浓度≠排放、测试通过≠现场有效、假设数据≠观测数据、DATA_NOT_READY不是失败。

## 3. 科学与合规界限
不得创造数据、发表新的气候/甲烷/健康/污染结论、开展未授权数值实验。保留当前状态：CarbonOS D3 DATA_NOT_READY、P1-A PENDING，#140 NO_VALID_PAIR，#141 NO_VALID_VERTICAL_PROFILE，#165 NO_SUITABLE_DATASET，#169 TOPOLOGY_UNVERIFIED及SCIENCE=PENDING。PR #138 P2是合成容器阀门模型，不等于实际填埋场；P1是浓度换算非排放证明；P3/P4是合成库存与假设响应。所有数字均链接原始输入和局限，不得包装为实测；不引入非公开Council数据、个人信息或受限来源。无新数据库、agent、求解器、付费调用、合并、上线。

## 4. 实施及真实验收
优先复用已有 Web 组件、模型与样式，不能搭建竞争系统；保持首页最重要，说明简洁、技术细节折叠。桌面及手机真实浏览器测试、截图、导航/来源链接、无JS错误、无水平溢出、无未经许可外网请求。三个阅读验收：普通人能解释甲烷浓度和排放的不同；Founder能解释四个实验为什么做；科学家能通过折叠层找到方程、输入和复算方法。产出：可用网页、源文件映射（页面→PR→SHA→数据类型→科学状态）、中文Founder验收报告、CRP记录及NEXT_SESSION。明确本地测试与远程CI结果区别。

## 5. GitHub交付
从最新主线创建隔离分支，在确认已有站点架构后做最小增量，commit/push并创建Draft PR。回报精确HEAD、实际预览方法、截图、中文报告和未完成项；不merge不deploy。最终只给Founder三个最重要的链接：网页入口/预览说明、Draft PR、中文验收报告。如外部源缺失，标记MISSING/PARTIAL，停在可证实边界。

## 6. 分支下一轮路线（仅记录，不授权执行）
P0优先完成可理解性网站与来源索引；P1独立科学评审与分支收敛；P2针对已识别的数据许可/时空配对缺口定向补证；P3建筑与社区能源韧性只读研究；P4符合科学门槛后再另批真实计算/现场试点。不要为了更新网站解冻上述科研任务。
