# Task711-715 Synthetic Cross-Domain Review Cases

The Review Workbench exposes four scenario descriptors:

- Climate-Water: invented rainfall timing and catchment response;
- Water-Land: invented soil moisture and runoff interaction;
- Land-Biodiversity: invented habitat-condition challenge;
- Energy-Climate: invented demand and heat challenge.

They demonstrate interface shape, uncertainty, challenge and human routing.
They contain no measured value, real place, real entity, scientific result,
ESG conclusion, compliance conclusion or model output. Each domain retains its
own review authority and provides evidence candidates rather than truth.
