# Task185 Translation Governance Registry

## Purpose

Task185 defines translation governance metadata for framework normalization.

This registry is especially important for China source-family work, but it applies to any framework with official multilingual material.

## Translation Status Values

| Status | Meaning |
| --- | --- |
| Official source language | Language of the official source text. |
| Official translation | Translation published by the official owner or authorized source. |
| Working translation | Internal working translation used only for navigation or review. |
| Machine translation | Machine-generated translation; not authoritative. |
| Human-reviewed translation | Translation reviewed by qualified human reviewer. |
| Legal/domain review required | Translation needs legal, regulatory, technical, or domain expert review before use. |
| Not reviewed | Translation has not been reviewed and cannot support claims. |

## Translation Registry

| Framework | Official language metadata | Working translation rule | Review requirement |
| --- | --- | --- | --- |
| IPCC | Multilingual official materials may exist for selected reports/factsheets; exact official language must be recorded per citation unit | Working translation allowed only as navigation aid | Human review required before using translated climate claim text |
| ISSB / IFRS | English official source family with IFRS translation and licensing pathways | Working translation cannot replace official standard text | Human review required for non-English use |
| ASRS | English official Australian source family | Working translation not required for baseline English use | Human review required if translated into another language |
| TNFD | English recommendation and guidance source family; other language resources require citation-unit check | Working translation cannot replace official recommendation text | Human review required for translated use |
| GHG Protocol | English and other-language document availability must be recorded per document | Working translation cannot replace official document language | Human review required for translated inventory or accounting use |
| GRI | Official translations may exist through GRI standards download/resource pathways | Working translation cannot replace official standard language | Human review required before translated terminology reuse |
| CDP | English current question bank page; questionnaire or guidance translations must be checked per cycle | Working translation cannot replace cycle-specific questionnaire text | Human review required for translated questionnaire or scoring-method use |
| China source ecosystem | Official Chinese text is primary for MEE/regulator/exchange sources unless an official English version is separately located | Working translation is allowed for internal routing only | Translation authority, human translation review, and domain/legal review required before any future use |

## Translation Metadata Fields

| Field | Requirement |
| --- | --- |
| Citation unit ID | Required. |
| Official title | Exact official-language title. |
| Official language | Required. |
| Official translated title | Only if official translation exists. |
| Working translated title | Allowed, clearly marked as working translation. |
| Translation source | Official, human, machine, or mixed. |
| Translation reviewer | Required before reuse in future claim work. |
| Translation review date | Required before reuse in future claim work. |
| Translation limitation | Required for partial, uncertain, or machine-assisted translation. |

## Boundary

No translated text in this registry is authoritative unless explicitly marked official and source-backed.
