# Task186 Framework Relationship Registry

## Purpose

Task186 records relationship metadata among framework families so future comparative work can start from traceable source relationships.

This registry does not map requirements, compare standards, rank frameworks, or infer equivalence.

## Relationship Types

| Relationship type | Meaning |
| --- | --- |
| Official reference | One official source explicitly refers to another source family. |
| Supporting standard | Source family uses or points to another standard, method, taxonomy, or guidance family. |
| Alignment statement | Official source describes alignment or relationship without creating a mapping in this task. |
| Shared source dependency | Multiple framework families may rely on the same upstream source family. |
| Jurisdictional adoption or adaptation | A jurisdictional source adapts, references, or aligns with another framework family. |
| Disclosure-cycle relationship | A questionnaire, portal, or reporting cycle interacts with other standards or frameworks. |
| Method / inventory dependency | Future records may depend on inventory, factor, calculation, or methodology source families. |

## Relationship Registry

| Source family | Relationship metadata | Future review requirement |
| --- | --- | --- |
| IPCC | Potential upstream climate assessment and methodology context for climate, mitigation, adaptation, inventory, and extreme-event work | Exact report/chapter/methodology citation required before relationship use |
| ISSB / IFRS | Official IFRS S2 page states relationship to TCFD and SASB-derived industry-based disclosure requirements; IFRS S1 relationship is visible on official page | Exact standard and related project citation required before mapping |

| TNFD | Nature-related recommendation ecosystem may relate to climate/nature disclosure work; relationship must remain source-backed | Recommendation version and guidance hierarchy required before mapping |
| GHG Protocol | GHG Protocol standard/guidance families are potential inventory and calculation-source dependencies for disclosure and carbon records | Exact standard/guidance/tool/correction citation required before mapping |
| GRI | GRI climate and energy topic-standard page notes project alignment context and authoritative instruments at a metadata level | Final standard versus project material boundary required before mapping |
| CDP | CDP question bank page states alignment with frameworks and standards and organizes annual questionnaire/guidance/scoring materials | Exact cycle, questionnaire, guidance, and scoring-method citation required before mapping |
| China source ecosystem | China sources may relate across ministry, regulator, exchange, national standard, market, methodology, factor database, and product-carbon-footprint families | Source authority segmentation and translation review required before mapping |

## Prohibited Relationship Claims

This registry must not state that:

- two frameworks are equivalent
- one framework satisfies another
- one framework is better or weaker
- one framework creates compliance with another
- a disclosure, inventory, or claim is acceptable under any framework

## Boundary

Relationship metadata is a pointer map, not a comparative map.
