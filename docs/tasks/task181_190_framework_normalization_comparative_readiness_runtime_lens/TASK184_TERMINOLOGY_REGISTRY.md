# Task184 Terminology Registry

## Purpose

Task184 creates a controlled terminology reference registry for future framework work.

This registry lists terms and official-reference targets only. It does not define terms, harmonize definitions, or interpret standards.

## Terminology Control Rules

| Rule | Requirement |
| --- | --- |
| No local definition | Do not write ClimateOS / CarbonOS definitions for framework terms in this task. |
| Official reference only | Record which framework families may contain official terminology references. |
| No harmonization | Do not merge terms across frameworks. |
| Version sensitive | Terminology references must point to a citation unit and version metadata before future use. |
| Translation sensitive | Chinese and translated terms require translation governance before use. |

## Future Terminology Record Fields

| Field | Requirement |
| --- | --- |
| Term | Exact source term. |
| Language | Official language and working translation status. |
| Framework family | Source family. |
| Citation unit ID | Required before term is reused. |
| Document location | Section, paragraph, question, table, annex, or equivalent. |
| Definition status | Official definition located, term located only, translation pending, or review required. |
| Use boundary | No interpretation until approved in later task. |

## Boundary

This registry does not define or compare terminology.
