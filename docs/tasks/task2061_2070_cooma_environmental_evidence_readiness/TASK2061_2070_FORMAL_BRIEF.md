## 2. Purpose

The accepted QGIS project establishes a spatial orientation foundation. It does
not establish whether Cooma has enough water, protects enough rainfall, faces a
particular fire condition, has safe drinking water, or has resilient wastewater
systems.

This batch defines the auditable bridge:

```text
named question
→ evidence requirement
→ admitted evidence object
→ reproducible derivation
→ bounded claim
→ conclusion level
→ accountable human review
```
