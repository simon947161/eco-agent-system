## L1 连续流控制体

```text
dV/dt = Σ Qin − Σ Qout
dM/dt = Σ(Qin Cin) − Σ(Qout Cout) + J
M = V C
仅在充分混合、稳态、保守物质、全部输入已观测时：
Cmix = Σ(Qin Cin) / Σ Qin
```

V[m³]，Q[m³/s]，C[kg/m³，指定分析物/相态]，M[kg]，J[kg/s，外源/相交换净项，不能默认0]。若降雨/蒸发/地下交换重要，须显式进入水量/溶质边界；不能为闭合而把未测贡献塞入J后宣称已验证。

最低独立输入：有向点位、连通时段、支流/排口流量与同时间浓度、采样截面代表性、误差、其他源项。可反驳预测：保守示踪物在独立下游样中符合允许误差的守恒与混合范围；违反时先检查采样/边界/非稳态，不能强迫拟合。反证不等于确定哪个设施有责任。

## L2 一维平流—弥散—反应

```text
∂(A C)/∂t + ∂(Q C)/∂x = ∂[A D ∂C/∂x]/∂x + A R(C,T,...) + sL
```

x[m]，t[s]，A[m²]，Q[m³/s]，D[m²/s]，R[kg/m³/s]，sL[kg/m/s]。每项单位kg/m/s；边界流、初始状态和A变化需与水量守恒一致。简化R=−kC仅是候选过程形式，k[s⁻¹]必须由特定分析物、相态及适用环境验证；不把所有PFAS或混合物强设同一k，也不使用甲烷GWP。

最低输入：L1全部条件，加有界河段几何、温度时序、旅时/弥散独立证据、吸附沉降/降解与生成途径、边界条件。不预设Arrhenius适用。可反驳预测：未用于参数选择的下游时序具有可验证的到达顺序/形态；同年相关性不足。混杂：未知支流、降雨冲刷、堰坝滞留、地下水、采样时滞。无独立数据时禁止校准、反演和源归因。

## L3 低流量与断开水潭

```text
dV/dt = (P − E) As + Σ Qin − Σ Qout + G
dM/dt = Σ(Qin Cin) − Σ(Qout Cout) + Jdep + Jgw + Jsed + V R − Jvol
C = M/V，仅V>0时定义
```

P/E[m/s]，As[m²]，G[m³/s]净地下水交换；Jdep/Jgw/Jsed/Jvol[kg/s]分别为沉降输入、地下溶质交换、沉积物净交换、挥发损失（可为非零/不适用，需逐物质论证）。蒸发不是自动把溶质等比例移走；CO2/挥发有机物与保守盐不能共享零挥发假设。V趋零/干涸时停止该浓度式，转换为干床储存问题；复连需要事件边界，不伪造连续下游负荷。

最低输入：潭体几何/水位、降雨蒸发、渗漏/补给、相态/沉积、连接与溢流事件、同期样本和QA。可反驳预测：独立水位与物质量变化与边界通量相容；若无水量闭合，不接受由浓度升高推污染输入增加。混杂：采样深度、分层、底泥再悬浮和未观测地下交换。
