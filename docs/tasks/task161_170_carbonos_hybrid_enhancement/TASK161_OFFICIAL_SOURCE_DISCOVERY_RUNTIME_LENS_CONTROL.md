# Task161 Official Source Discovery Runtime Lens Control

## Purpose

Task161 opens the official source discovery batch under the Architecture Baseline v1.1 runtime lens.

The task records official source locations and review metadata only. It does not interpret the content of any standard, guidance, regulation, questionnaire, or framework.

## Architecture Position

Task161 follows:

- Task151-160 Research Activation
- Task161-200 Runtime Integration Gap Analysis
- Architecture Baseline v1.1 Freeze

It precedes:

- Task171-180 Official Framework Intake
- Task181-190 Cross-Framework Comparative Mapping
- Task191-200 Evidence-based Comparative Reasoning Prototype

## Allowed Work

- Locate official source pages.
- Record source owner, source category, source URL, access date, and version signal.
- Flag source freshness risk.
- Identify whether the source has visible update, amendment, errata, portal, or version pathways.
- Add runtime relevance tags.
- Record unresolved verification questions.

## Prohibited Work

- Do not summarize standard requirements as factual findings.
- Do not compare frameworks.
- Do not produce compliance, assurance, certification, disclosure, or carbon conclusions.
- Do not create real Evidence Passport records.
- Do not create data files, databases, APIs, scoring, runtime, automation, MCP, or QCloud work.

## Runtime Lens

Each source candidate should be reviewed for possible future relevance to:

- evidence freshness
- evidence versioning
- amendment tracking
- official correction tracking
- reporting-period sensitivity
- physical risk or extreme-event update sensitivity
- cross-framework dependency risk
- claim confidence evolution
- human review triggers
