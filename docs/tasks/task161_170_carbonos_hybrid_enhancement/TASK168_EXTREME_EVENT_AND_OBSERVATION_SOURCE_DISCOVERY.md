# Task168 Extreme Event And Observation Source Discovery

## Purpose

Task168 defines source discovery rules for future extreme event and observation-related materials.

This task does not collect event data, analyze weather, forecast climate, validate an event, or create operational monitoring.

## Candidate Source Families

Future discovery may look for official source families such as:

- national meteorological agencies
- intergovernmental climate assessment bodies
- official disaster or emergency agencies
- official satellite and earth observation providers
- official climate data portals
- official public-health heat guidance sources

## Runtime Relevance

Extreme event sources require runtime lens metadata because they can change quickly.

Future records should identify:

- observation timestamp
- update cadence
- data revision policy
- event naming or identifier practice
- uncertainty statement location
- correction or reanalysis pathway
- cross-source comparison need
- human review trigger

## Source Boundary

Official observation sources may support future evidence anchoring, but they do not by themselves prove a governance, ESG, carbon, resilience, or disclosure claim.

## Prohibited Work

Do not:

- download data
- call APIs
- build adapters
- run models
- create forecasts
- produce event conclusions
- rank source credibility automatically
- create operational alerts
