## Discovery Notes

The register intentionally records source location and runtime relevance only.

It does not state what the sources require, recommend, prohibit, calculate, score, or certify.

## Runtime Lens Summary

The initial source set shows several future runtime-sensitive categories:

- sources with amendments or active projects
- sources with reporting-period version routing
- sources with annual disclosure cycles
- sources with guidance versus standard hierarchy risks
- sources with jurisdiction-specific legal status
- sources with cross-framework alignment dependencies

These are metadata observations only.
