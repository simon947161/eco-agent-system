## Purpose

This packet reframes the future Task1541–1700 programme.

The programme is no longer centred on reproducing UniCM as an end in itself. Its primary objective is to establish a ClimateOS capability for reading, comparing and governing multiple external computational worlds across spatial, temporal and structural scales.

UniCM remains a valuable reference model. It is not the centre of the ClimateOS worldview and is not presumed to be a production dependency.

## Founder direction preserved

External scientific models and theories are to be treated as parallel computational worlds. ClimateOS may trust that a model performs its stated computation while still examining:

- what the computation can observe;
- at what scale it observes;
- which variables and mechanisms it includes;
- which mechanisms it excludes;
- where its conclusions remain valid;
- which structural advantages can be reused;
- which analogies are justified for the ClimateOS problem;
- where cross-scale translation must stop.

The viewpoint must change with scale. A planetary view, continental view, regional view, city view and site view do not expose the same system.
