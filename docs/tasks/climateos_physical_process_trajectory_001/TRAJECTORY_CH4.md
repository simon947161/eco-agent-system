# 甲烷：源汇、丰度、辐射与响应

## A1–A2：保留可复用范围

PR144四边界账按库存增减、捕集、设备破坏、覆盖氧化与侧向离界分开。三组合成排出量重算为95、32.7、31.08kgCH4/所设区间；第三组另有5kg横向流出，最终命运UNKNOWN。反应时守恒的是碳元素，CH4物种被消耗并可生成CO2，不是甲烷分子始终守恒。[继承重放](evidence/computed-legacy.json)

PR143 P1以2ppm干基、80000Pa、293.15K、水汽1000Pa、3m³湿气体计算同一气团浓度与参考干体积；这是合成理想气体物理，**不能推出排放源强、全球库存或高度GWP**。全球库存须有大气质量/分布支持；排放反演还须输送、OH及其他汇和时间序列。全局账可写 `dB/dt = E - L_OH - L_other`，只有B或其增长不能唯一识别E。

## A3：新运行的已发表辐射公式

[NOAA AGGI 2025](https://gml.noaa.gov/aggi/aggi.html) Table1 CH4：

`F = (a√M + b√N + d)(√M - √M0)e`

M是全球干空气CH4平均丰度ppb，N是N2O ppb；M0=729.2ppb（1750）。a=−8.96×10⁻⁵，b=−0.000125，d=0.045194，e=0.86。a、b携带使括号与平方根乘积成为W/m²的经验量纲；不能用ppm数值直接代入。e是快速调整系数，**不是地表气候反馈或气候灵敏度**。取M=1936.03，N=338.86（2025），F=0.569344413968403W/m²。原表0.569，差0.000344414小于三位小数半个单位0.0005。

令s=√M、t=√N、s0=√M0、k=as+bt+d，则

`∂F/∂M = e[a(s-s0)+k]/(2s)`；`∂F/∂N = eb(s-s0)/(2t)`。

导数通过中心差分核验。输入±0.48、±0.02ppb若按独立标准误差解释，传播量为0.000175571W/m²；极端相关系数±1对应约0.000174576–0.000176561。网页没有完整置信水平定义，因此该量不是正式95%CI。M0、系数不确定性未混入这一项；NOAA给出的约10%公式不确定性量级单列0.0569344W/m²，不伪装成正态误差。

NOAA公式排除CH4间接改变臭氧/平流层水汽的贡献及地表温度反馈。此处是全球平均出版关系复算，不是新独立辐射测量，也不验证单设施减排效果。[事实/哈希](evidence/aggi-facts.json)、[结果](evidence/computed-A.json)。

## A4–A5：为什么不能继续报温度

候选响应形式 `C dT/dt = F - λT` 中C为J m⁻² K⁻¹，λ为W m⁻² K⁻¹；核形式 `T(t)=∫G(t-s)F(s)ds` 需要一致时间单位、气候响应与强迫历史。这里只检查合成能量账10W−8W持续60s=120J，没有给C、λ或G赋值。W/m²不能直接写成°C。

现阶段阶梯：合成库存/气团换算→**独立全球输入的ERF复算可执行**→全球温度响应BLOCKED_MODEL_VALIDATION→区域或释放高度影响NOT_INFERABLE。下一步必须有已验证响应模型、海洋热吸收/反馈、其他强迫、独立观测及授权；不扩大旧PR143 ChainB准入。反证CE01–CE03、CE07见 [登记](COUNTEREVIDENCE_REGISTER.md)。
