# Task171-180 Official Framework Intake Runtime Lens

## Purpose

This folder records Task171-180 as the first metadata-only Official Framework Intake batch after Task161-170 Official Source Discovery With Runtime Lens.

The objective is to describe official framework ecosystems that ClimateOS / CarbonOS may later use. It does not interpret standards, compare standards, map requirements, or create compliance conclusions.

- future mapping readiness
