# 不能直接比较的八类冲突

以下是基于[来源登记](GLOBAL_SOURCE_REGISTER.md)和PR144条款的研究解释，不是新法规解释权。每项明确允许比较的条件。

|冲突|错误结论/为什么错误|允许的处理|
|---|---|---|
|版本与报告年|用CER2025–26指南代表NGER C21的2026–27；把网页缓存日期当生效日期|固定instrument/version/effective_date/reporting_year与过渡条款；未闭合则NOT_ASSESSED|
|IPCC16/12 vs NGER1.336|只因数字接近就替换，忽略碳存量、当年衰减、单位和GWP层|分别复核PR144 G03/B01；只有相同物理量且明确单位/常数约定才能比较，法规系数不被“更精确”原子量偷偷替代|
|捕集 vs 破坏|98%装置破坏率被解释成全场98%甲烷消失|收集/管网/设备/覆盖层分账；C/G与X/D分母不同。US HH-8同样含收集效率估计，名称“measured”不证明全场通量直接实测|
|ppm vs kg/h|扫描或场外浓度直接乘常数当源强|P1只在同一气团已知P/T/e下转浓度；需流量/风场/几何/代表性与逆问题证据才能讨论通量，本轮不做。溶解mg/L不能进气相理想气体式|
|氧化/管漏/横向离界双计|已对未回收气氧化又对总气再扣；已计管漏又把全管网损失再加；5kg离界写成减排|互斥接口、上游/下游仪表位置与同时间窗；缺命运记UNKNOWN。本轮B显式测试双重氧化和遗漏L|
|反事实减排 vs 实测排放|项目基线减项目排放等同直接仪表观测；捕集量等同ACCU信用|基线、额外性、泄漏/运行/原本会燃烧WB分开；GHG Project与Corporate边界不同；本轮不算信用|
|卫星足迹 vs 设施|羽流增强、背景浓度、清单网格当作单个物理设施流量表|定位误差、风/背景、过境时间、设施/处理单元身份、检测限先配齐；本轮仅候选索引，不下载/反演|
|时空与“标准状态”|不同高度/时区/模型日历或0°C与15°C的m³混用|保存实际/参考状态、calendar、时区/观测支持、仪器坐标/高度和精度；未知不猜。坐标精度不是坐标小数位数|

反证必须可保留：算术正确但没有授权原始流量、校准和许可的C包仍 **EVIDENCE_INSUFFICIENT**；守恒正确但偷偷换掉原始输入同样失败。来源文本也可能冲突，例如ISO官方目录14064-2标题与摘要年份不一致；选定层级和未解决之处要随包传播。

不确定性分四层记录：输入仪表/采样；时间空间代表性；模型结构/参数；制度/基线边界。SHA只证明所检字节一致，不能消灭这四类不确定性。气压/温度/湿度/经纬度作为上下文，不生成全球GWP修正系数。PR143链A的协方差结果仍只是合成一阶近似，不升级为场址置信区间。
