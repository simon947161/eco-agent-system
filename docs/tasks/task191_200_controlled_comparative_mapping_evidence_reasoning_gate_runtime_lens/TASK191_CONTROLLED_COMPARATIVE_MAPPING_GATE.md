# Task191 Controlled Comparative Mapping Gate

## Purpose

Task191 defines the gate that must exist before future comparative mapping can begin.

This task does not perform mapping. It defines the conditions under which a later Founder-authorized task may begin mapping.

## Scope

The controlled comparative mapping gate applies to any future work that attempts to relate framework terms, citation units, evidence requirements, disclosure concepts, accounting concepts, climate-risk concepts, or claim-boundary concepts across framework families.

## Preconditions

Future comparative mapping cannot begin unless all selected source families have:

- exact citation-unit identifiers
- official source locators
- document hierarchy classification
- current version, amendment, reporting-period, annual-cycle, or notice-date metadata
- translation governance status where source material is non-English or multilingual
- source freshness status
- evidence-reference readiness status
- human review trigger status
- explicit Founder approval for the selected mapping scope

## Boundary

The gate does not authorize:

- standards interpretation
- framework comparison
- framework ranking
- compliance assessment
- assurance assessment
- certification assessment
- ESG conclusions
- carbon conclusions
- operational Evidence Passport records
- operational Claim Boundary decisions
- runtime, API, database, MCP, automation, or scoring work

## Approval Requirements

Future mapping requires a separate Founder authorization that states:

- selected frameworks
- selected citation units
- allowed mapping depth
- allowed output format
- review owner
- prohibited use boundary
- whether requirement-level mapping is permitted
- whether evidence reasoning is permitted
- whether the output may be used outside repository documentation

## No Comparison Implementation

Task191 creates no comparison rows, requirement mappings, equivalence claims, compliance logic, or decision logic.
