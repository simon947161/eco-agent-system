# Task193 Version And Reporting Period Verification

## Purpose

Task193 defines how version, reporting-period, revision, amendment, and publication-timing metadata must be checked before future comparative work.

This task records verification rules only.

## Version Verification

Version verification must record:

- current visible version or cycle
- previous version or lineage where relevant
- amendment status
- consultation or draft status
- publication date
- effective date where visible
- access date
- supersession or replacement warning
- source freshness status

## Reporting Period Alignment

Reporting-period alignment is required where source material is tied to a reporting period, disclosure cycle, annual questionnaire, effective period, or official portal period.

| Source family | Reporting-period concern |
| --- | --- |
| ISSB / IFRS | Annual reporting period and amendment status. |
| ASRS | Portal period selection and future/by-period version routing. |
| CDP | Annual disclosure cycle, questionnaire, guidance, and scoring-method versions. |
| China source ecosystem | Dated notices, annual work cycles, database editions, and methodology release timing. |

## Revision Compatibility

Revision compatibility must be checked before mapping two or more sources.

Minimum required checks:

- selected sources are current enough for the intended future use
- selected sources are not draft/project material unless explicitly authorized
- selected sources are not from incompatible reporting periods unless the future task explicitly studies timing differences
- selected sources have documented amendment or correction status
- selected sources have documented hierarchy status

## Known Amendment Checks

| Framework family | Amendment / revision check |
| --- | --- |
| IPCC | Assessment cycle, special report, methodology report, and error-handling status. |
| ISSB / IFRS | Issued standard, amendments, related active/completed projects, and taxonomy update status. |
| ASRS | Amending standards, portal period, compiled/uncompiled state, and support materials. |
| TNFD | Recommendation version, guidance updates, page update date, and sector guidance state. |
| GHG Protocol | Amendments, corrections, standard/guidance updates, tools, and under-development status. |
| GRI | Final standard, exposure draft, project page, basis material, and standards-development state. |
| CDP | Annual cycle, questionnaire updates, guidance, scoring methodology, and portal state. |
| China source ecosystem | Official notice date, final/draft status, database edition, methodology code, replacement status, and authority route. |

## Framework Publication Timing

Publication timing must be treated as governance metadata, not as framework quality or priority.

## Boundary

This verification record does not decide which framework version applies to any entity, project, claim, report, inventory, or disclosure.
