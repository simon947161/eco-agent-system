# Hardwick 工厂两段生产期的余热回收复算

2026-11-28。从 ARENA 发布的 Hardwick 最终报告第 3、4 页逐项抄录两期摘要，第 5 页核对实际记录时数，第 8 页核对首期节气、电耗列的含义。清洗仅包括拆除千位逗号、规范单位列名、用起止月份标记工况，以及分别保留记录小时和项目方年化小时。同一工厂在两个时期采用不同班次和运行条件。表中每行代表一个汇总期，没有独立小时样本。已下载 11 页源 PDF，并从第 3–5 页独立提取表格核对，原件 SHA-256 见 JSON 回执。仓库仅保存手工摘录的数字、原创程序和复算结果。[Hardwick 和 Joyce，最终报告，2025 年 6 月 11 日提交](https://arena.gov.au/assets/2025/08/Hardwick-Meatworks-Heat-Pump-Installation-and-Power-Upgrade-Demonstration-Final-Report.pdf)

源侧热量按表列热功率乘年化时数得到。把表列功率当作相应运行小时的代表功率是复算假设。所得数值尚未扣除储罐、输送及弃热损失。第二期节气两分项相加为 19,719 GJ/年。原始总量与两分项均予保留，分项归因有待作者底表核对。

按年化口径，源侧热量减少 2,324.816 MWh 热/年，约 33.3%。从乘积 P×h 对称拆分，运行时数贡献 Δh×(P₁＋P₂)/2＝−1,453.595 MWh，代表功率贡献 ΔP×(h₁＋h₂)/2＝−871.221 MWh。两项之和恰等于总差。这是算术分解。原报告描述同期的班次、供货和设定值都有变化，无法单独识别天气、班次、设备改造各自的因果效应。后一期只有八个月，年化结果受季节构成影响。

**工程判断。** 评估扩容时应单独检查生产计划能支持多少运行小时。若有效运行时间下降，即使装机不变，原来的年度热量预测也应重算。首期报告另列新增用电 730,480 kWh/年。两期汇总表无法同步验证同产量、同冷库温度、同热水质量和温级，也无法判定加罐或改班能节约多少净燃料、电费、碳排和峰值。需要同时段热水需求、储罐存量、燃气表、冷热设备电表及生产服务记录；不同场站数据只能分别验证各自的子问题。

**复跑。** 在本目录运行 `python3 hardwick.py`，标准输出是 JSON，可交 API 工作进程读取；`python3 hardwick.py | cmp - hardwick_result.json` 应通过。自定义 CSV 用 `--input`。程序核查两期身份、结构、数值、时间范围、热功率分项，以及算术分解闭合。报告自身的 8 GJ 差异产生质量标志。两次全量复跑输出逐字相同；另行注入错误功率合计、超年时数、空读数、重复期、非数值，五种输入均遭拒绝。JSON 内的哈希对应摘录 CSV。程序可用本地 Python 标准库运行。
