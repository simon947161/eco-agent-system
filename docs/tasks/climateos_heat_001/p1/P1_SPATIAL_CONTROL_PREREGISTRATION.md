# P1 补充预登记｜储罐移动、联合反例与独立复算

登记时点为主计算之前。此页补充共同主规范，沿用其冻结的全年 UTC 小时表、服务、源、热泵、费用/排放因子、逐小时守恒容限和期初末库存规则。以下每一次比较均使用同一套输入和同一账本。此页预先声明的选择不依据任何结果。[设计版空间试验](../MVTEE_SPATIAL_LAYOUT_CONCEPT.md) · [设计版反证](../MVTEE_FAILURE_MODES.md) · [授权 #176](https://github.com/simon947161/eco-agent-system/issues/176)

|试验|冻结的干预、对照及判决|
|---|---|
|储罐 C→B|对 L、T 各作一组。保持同一只罐、同一热泵、服务、年度逐小时输入与管线配置。C 罐放热经热干管，B 罐放热在末端；B 罐充热须经过热干管，C 罐充热在管前。优先即时需求，然后充罐；不足先放罐再备用。比较改变的热流边、热管吞吐/峰值、双环泵电、管损、燃料和期末库存。移到 B 不额外赋予保温、折扣或负碳。若某项数值差很小或为零，保留原结果。|
|温度单因素|除任务中的低温/低效率联合情景外，独立比较 A 出口 25、40、60 °C；热泵效率系数保持共同中心值。截取、COP、备用和供热等服务逐项核查。|
|管路与温级联合|将既定低源温/低 COP 与长管档相交，仍与其同工况 R0 和 R1 比较；不把两项单因素差额简单相加。|
|季节错配 × 容量|将既定季节错配档分别置于零可用容量、中心容量、大罐容量；分别查看夏季弃热/旁路、冬季备用及恢复终态的处理。|
|停源/无法扩展|设 A 全年可截取率为零而生产与原排热不变，保留已建资本，B 原锅炉逐时供同服务（N0）。另取合成冬季连续停供，并用服务能力不足的备用故障检查缺供拒绝条件。人为标记路权不通或受体超限只校验否决规则，真实路权与热暴露保持 UNKNOWN。|
|删表/重计/不等服务|对有效记录复制转移 ID、改错量纲、缺/负损失、删泵电、负或越容库存、改期末库存、篡改一小时交付额或 COP。检查拒收；不能用年总和抵消逐时违例。|
|收益符号与未决|差值为联网减分离。若在预定边界情景中同一差值出现正负两侧，报告跨零及改变它的假设；不给概率置信度。外部环境、制度可行性与独立科学审查不纳入合成收益验收。|

**证据材料。** 尽可能用原脚本重放主案例；独立从逐时已归档表重建服务、能量、损失、主要差值并核对公开回执。若主程序仅产出部分逐时档案，给出相同代码的离线生成方式，并区分“已实际重放”与“可生成”。每一补充案例记录输入、命令、结果、比较对象及剩余假设。
