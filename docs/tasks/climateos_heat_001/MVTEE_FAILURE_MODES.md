## 假设、输出和判决次序

|问题|零假设 / 备择|将来能怎样判断|
|---|---|---|
|H1 联网的净收益|H0：Δ一次能源、Δ生命周期 GHG 至少一项没有达到预注册改善幅度，或至少一项服务、成本、热/生态或空间护栏失败。H1：双主终点均达到改善幅度，且全部护栏满足。|先验守恒与服务，再审双终点与各护栏。若改善幅度为 δ，各自的配对差区间上界均须低于 −δ；护栏另按其方向/限值检查。某终点区间整体在失败侧或明确越限，否决该条件下的方案。跨界或缺必需证据则未决。|
|H2 排热转移的受体效应|H0：易受影响人群热暴露无改善、全影响域暴露上升，或某水/土受体变差。备择：目标受体改善、全域无增且各生态护栏通过。|P1 最多能标记何时、何处、向何种介质多排了热。合成升温标记只测试拒绝规则。缺少独立观测时真实 H2 始终未决。|
|H3 纯搬热的核对|在相同外部输入、边界通量和起末库存下，内部转移对合并能量净移除为零。|“搬走了多少热”产生正的地球净移除，应查重复边、失踪的下游出口或期末库存。只有另有辐射或排放机制及独立证据才可另立全球问题。|

**冻结清单。** δPE（kWh一次/MWh）、δGHG（kg CO₂e/MWh）、能量残差绝对/相对容限、分温级服务允许偏差/缺供时长、成本上限（AUD/MWh 或 ΔPV）、空间禁入与缓冲、空气暴露和水温/溶氧护栏、置信/覆盖水平及多终点联合区间规则均为 **TBD**。Founder 在任何 P1 输出前会同热工/用能和财务复核人签定合成量纲、最小可辨差、误差与停止规则。现场护栏另由获授权的环境/健康专业人员基于当地证据和许可决定。未冻结对应门槛只能做诊断，不能宣布通过。

## 强制反例

|编号 / 刻意改变的输入|保持与观察|预注册的失败或停止条件|
|---|---|---|
|F1 低源温、低流量或整段停供|固定 B 水温和同一小时气象；记录 A 允许出回水、蒸发/冷凝温级、COP、压缩机电和备用。|可取热为零仍有蒸发热，或 COP 超过可逆上界，拒绝账；合理低 COP 导致 ΔPE 或碳端点失败，则否决该工况。|
|F2 延长高温路段，加入弯头或潮湿保温|R0/R1 不变，对 L/T 分段及等长对照；观察送回温度、各管损、压差、泵电和 B 冬峰补热。|服务温级不足且备用无法恢复，先判服务不等；服务恢复后若能耗/成本越界仍判失败。等物理参数单改布局名出现差异则停查。|
|F3 夏季稳定产热、需求低，冬峰叠加停源|同一全年服务及起末温层；查满罐旁路、罐散热、冬季空罐、缺供和为恢复期末库存的购能。|满罐仍充、空罐仍放、借用期初库存不归还，算例无效。物理上有效而备用/弃热抵消收益，应保留负例。|
|F4 空气/水受体升温，能源账仍改善|保持服务，改变出口或排热时段，分别标记 R人 夜间下风、R水 枯水期、沿线土壤及域外下游；核对总排热和全域覆盖。|任一受保护受体越限即否决环境可接受性。只有排热量、风向未知、缺上下游对照时为未决；不能将其编码为零温升。|
|F5 低碳就地热泵替换锅炉反事实；管材、泄漏或峰电代价上升|同一温级、寿命和购能范围，重列 ΔPE、运行/全寿命 ΔGHG、ΔPV 和服务强度。|生命周期碳或经济护栏失败，否决对应口径；若合理基线使符号反转，只能作条件判断，通用收益命题不获支持。|
|F6 唯一源业主停供、绕行路权受限、备用价格上升|记录停供月份、原工艺产量、备用容量和故障同源性，检查地役权、检修、泄放、扩展口与合同期限。|备用无法供给同一服务、施工必穿禁入区或合同短于资产可回收期且成本越界，该选项停止。|
|N0 / N1 空效应和故障注入|N0 禁止截取，停用 C 且使用 R0 的全部设备/冷却规则；只比运行能量，另保留闲置资产资本和隐含碳。N1 重用流 ID、交换 kW/kWh、漏泵电、负库存或空值冒充零。|N0 的运行差应在登记容限内；N1 须触发拒收或未决。若仍输出净收益，所有相关案例退回重审。|

“算例无效”表示记录或物理关系有错，不能判科学假设。“条件下否决”保留为实验结果。“未决”保留缺失项、区间与重开条件。未来出现明确信号前，各布局均为待检。

## 不确定度与重放

- **参数误差。** 优先用有界区间传播。把共同天气、A 停供、B 负荷、峰时碳因子和价格作为关联块，向各比较臂施加同一扰动。温差计与流量的共同偏差按同组传播。若未来另用抽样，先冻结联合分布、种子和抽样规则；无来源的分布不赋予概率意义。
- **结构误差。** R0/R1、保温干湿、源热归属、罐温层和电网口径作为独立结构选择逐项报告，不能用跨基线平均掩盖变号。按季节、峰时、全年及服务温级出表；传播成对差及残差，并注明关键信号是否小于误差。H2 的真实缺测始终保留。
- **复现所需。** 冻结输入作者/用途/哈希、单位、小时顺序、拓扑及边号、公式版本、初末态、阈值版本、配对清单和故障例编号。未来由独立复核人用同源输入重建各表、对消内部边、追踪一段冬峰和一段夏季旁路，核对未舍入残差与逐项判决。重放不一致、服务不等或混入真实数据立即停审。
