# L2 未来受控实验设计与证伪矩阵

仅设计，不执行。唯一决策目标为：在相同逐时服务与匹配期末库存约束下，动态 L/T 是否改变 P1 合成排序/方案可行性；R0 锅炉和 R1 本地 ASHP 保留为服务基线。仿真启动、数值计算与模型实现均未授权。

## 1. 固定控制与空几何对照

冻结 #177 的 A–C–B：A 合成稳定余热源，C 热泵/可选罐站，B 季节聚合需求；仅 A–C 低温、C–B 高温供回水对。继承 L/T、设计版本、需求/气象合成序列、P1 固定输入、R0/R1 边界、相同服务/可靠性代理/末端库存、决策主指标和评分方向。任何差异作为新 scenario ID，不可回写 P1。

空/零效应对照（仅未来实现时的诊断，不代表物理布局）：
- no-network / zero-delay：去掉网络输送、压降和管库存，仅作与 P1 边界映射的账本桥接检查。
- zero wall/fluid added-capacitance：将新增管/壁热容效应消融，保留与物理基准相符的边界；仅用于识别机制。
- equal-geometry null：L/T 均赋同一管长/高程以查布局标签/实现偏差。
- zero elevation differential：用平坦局部设计面检查重力符号与闭环抵消，不替代 L/T 原高程。
以上为非真实物理反事实；不得把消融输出作为方案推荐。

## 3. 指标、初末库存与“更丰富模型有价值”判据

逐时记录 B 的交付热量、供回温、未满足服务；两段质量流、速度、压力包络、摩阻/局部压降、热损、管壁/水体库存；A 可用/取热；热泵功热和状态；C 罐温/库存；泵功；累计质量/能量残差。主要排序指标必须在看结果前预注册，并与 P1 口径映射；同时报告服务约束、峰值欠供、能耗/排放、泵电、热损，避免单一综合分掩盖失供。

R0/R1/L/T 服务量与期末库存需配对；明示源、管道、罐初始及终了库存，任何初值提供的能量计入边界。若试验周期期末罐能/管热/源侧库存不同，应延长至周期闭合或按库存价值/边界校正，不能把取初值当免费热源。

只有当模型通过解析、守恒、收敛、服务和独立复核，并且动态效应令可行性或预注册目标差异跨过预先冻结的最小有意义决策线，且该翻转不由无依据参数/模型错误驱动，才说明 L2 对本合成决策有增量价值。若 L1 与 L2 决策一致且遗漏物理影响边界远小于决策线，L2 对该决策可能不必要；不能外推到现场。

## 4. 证伪信号与失败处理

可证伪当前“几何可由静态长度/能账充分表示”的信号：高点局部绝压/泵吸入触限；压降/泵耗改写可行性；T 较大水容积造成到达延迟或峰值欠供；材料/水体热容导致启停损失；热泵温级和罐控制改变供水；L/T 排序跨决策线。反证性结果必须报告反例区间/主导输入，而不是挑一个有利参数点。

故障注入若产生不守恒、非物理压力/温度、库存负值、服务对照失配、步长不收敛或复核不能重现，结果标 INVALID/UNRESOLVED，不得给布局排序。任何真实地形、天气、建筑、Council 或现场测量均超出本实验授权。
