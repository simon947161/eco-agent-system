## 2. 冻结场景和物理参数

完整机器合同为 [L2_FROZEN_SYNTHETIC_CONTRACT.json](L2_FROZEN_SYNTHETIC_CONTRACT.json)。P1 所有参数由 `P1_SYNTHETIC_INPUTS.json` 原字节及 SHA 固定；L2 新增量全部标 `SYNTHETIC`，而非场址事实。

固定拓扑为 A 稳定合成余热源 → A–C 低温闭式回路 → C 热泵/高温侧可选水罐 → C–B 高温闭式回路 → B 单一季节聚合需求。每个低/高温回路的供水和回水管分别建模。L=80/40m、A/C/B 高程 0/+2/+3m；T=120/180m、高程 0/+6/+3m；为这份合成模型沿路径线性插值，无额外未观测高点、无 A–B 第三管、无 CRS 或实测路线。

流体常物性合成近似：ρ=1000 kg/m³、cp=4180 J/(kg·K)、μ=0.001 Pa·s，适用域仅称 12–68°C 合成情景，不声称水物性精确。压力安全使用 IAPWS-IF97 Region 4 饱和压力曲线的保守上界 80 kPa（0–90°C），再要求至少 50 kPa 裕度；同时绝压不得低于 120 kPa。参考：[IAPWS IF97 官方发布](https://iapws.org/technical-guidance/release/IF97-Rev)。

内径 0.20m、绝对粗糙度 0.000045m、钢近似壁厚 0.008m/ρ=7850 kg/m³/cp=500 J/(kg·K)、水到壁导热 200 W/(m·K)、每根管对固定 12°C 地温的等效 U′=0.26 W/(m·K)、每闭环 ΣK=4。U′继承 P1 的单管等效导热假设，不拆造不存在的保温实测层；土壤不做瞬态扩散。A/C/B 服务温级、A 150 kW 来源、HP 200 kW、COP Carnot 分数 0.49、C 处 320 kWh 单状态水罐/90 kW 充放率/0.0018 每小时损失、650 kW/0.9 效率备用锅炉均按 P1。罐的等效温差 25K、体积约 11.0239m³；不宣称分层。

水力按 Darcy–Weisbach + 局部 K，f 在 Re≤2300 用 64/Re，Re≥4000 用冻结的 Swamee–Jain 显式近似，中间线性插值，零流量时摩擦为零。采用准稳态动量、负荷跟随变速泵：泵最大曲线 `120000*(1-(Q/Qshut)^2) Pa`，`Qshut=3 Qdesign`；需求压头含继承 P1 25 kPa 设备压降、沿程摩阻及局部损失。流量不足由共同备用锅炉补齐；不截断服务需求。闭环静水项按供/回路径分别累计且总和应为零；沿线局部绝压仍逐点检查。

## 3. 方程、接口、初末库存与数值方案

- 质量：节点及管段控制体连续；当前各独立闭环无泄漏/补水，流体质量恒定。
- 动量：准稳态一维压力闭合，含摩阻、局部件、静水项和泵曲线；高点检查绝压/饱和裕度。
- 能量：有限体积迎风输送水焓；独立水温/管壁热容状态，水—壁导热及壁—固定地温 U′；C 热泵按动态源侧回水温和 65°C 网侧供水/3K approach 计算受限 COP；罐为单状态能量库存；B 服务按 P1 两表逐时匹配。热泵电功只计一次，泵电、管损、备用燃料和库存变化单列。
- 网格/步长：显式一维 FV upwind，空间 dx=50/25/12.5m；时间 dt=60/30/15s。最大设计流速约 0.228m/s；在 dx=25m、40m 最短管段分成两个 20m 单元及 dt=60s 下，最坏 CFL≈0.685。合同 v1.0.0 曾误记上限 0.6；在任何情景计算前修订为 CFL≤0.7（仍低于显式迎风稳定上限 1）。更细时间步/空间步的 CFL 更低。准入检查器逐式计算该边界。零流量停用平流但保留壁—地换热；反向流以反转迎风边界。
- P1 同等服务：45/35°C 空间供暖、60/12°C 生活热水，网络一次侧 65/40°C；≥63°C 一次供水合格。服务控制优先 HP 即时供热、再充罐；缺口先放罐、再由共同备用锅炉补齐。任何小时不足、温级不合格、备用超 650 kW 均标 INVALID。
- 管/水/壁初态由完全相同 8,760h 年型重复预热，分析下一个周期。要求每个流体/壁单元起末温差≤0.01K、罐期初末可用库存 0±1e-7kWh，水质量一致；未匹配就不与 P1 做排序比较，不将初始热量免费计入。

P1 主决策边界只作参考。L2 主指标冻结为年购入一次能源（电×P1 一次因子 + 气×P1 燃料因子）；次指标为运行 CO₂e 和按原 P1 寿命/资本公式另算的 LCOH。最小有意义差：一次能源 1,000 kWh/年、运行碳 200 kgCO₂e/年、LCOH 1.00 AUD/MWh。小于门槛标记低于决策分辨率；只有超过相应差值并跨排序线、且所有质量门通过时才作条件性支持。受体 H2=UNKNOWN，全球冷却 H3=NOT_TESTABLE。

## 4. 误差、测试和失败阈值

- 质量残差≤1e-9 kg/s；单子步能量残差≤1e-7 kWh；全年能量残差≤1e-5 kWh；每小时服务误差≤1e-7 kWh，年度相对误差≤1e-9。
- 解析锚点：静水 `ρgΔz` 相对误差≤1e-6；已知层流/湍流 Darcy 例误差≤1e-6；无损行波到达时差≤细步 15s；稳态管热传递、单有限热容温度误差≤1%；闭环静水累计差≤1Pa。
- 时间收敛：固定 dx=25m，dt=60/30/15s 三档。年能量/泵电/合格交付相邻细化变化≤0.5%，峰值≤1%，到达时间变化≤15s。
- 空间收敛：固定 dt=30s，dx=50/25/12.5m 三档。年能量/泵电/合格交付变化≤1%，峰值压力/温度变化≤2%。
- 验证器必须检查 fixture SHA、8,760 唯一 UTC 连续小时、所有来源标 SYNTHETIC、参数/单位完整、路线/电路定义、合同硬门和无正式 L2 输出。独立复算另用不同计算路径核验解析式、全年服务与逐时输出，误差≤1e-6 相对或合同绝对容差。
- 失败注入：零流/中断、COP失效低源温、高点绝压不足、备用不足/失供、P1 长管合成压力情景、负罐量、缺字段/错单位、反向流、非有限状态、期末库存不匹配。相应状态为 INVALID/INCONCLUSIVE/CONDITIONALLY_SUPPORTED；失败不得被年总量抵消。
