# L2 验证、确认与科学验收门

本文件规定未来模型的证据计划，不是实际测试结果。本 PR 没有运行 L2 数值模拟。

## 1. 分开回答三个问题

- Verification：方程/数值实现是否按定义求解？用解析和独立参考验证。
- Synthetic validation：合成情景下的系统响应是否与预期物理机制一致？不能据此宣称现场预测准确。
- Field validation（未来另行授权）：对独立留出地点/时段的预测是否在预登记测量不确定性内？需数据权利、现场测量与独立审批，本阶段不读取此类数据。

参数误差（几何、流量、物性、设备参数）与模型形式误差（充分混合/热前沿、集总/分层罐、准稳态/瞬态动量、土壤边界简化）分开分析；不得通过调参掩盖结构误差。

## 2. 解析与独立参考基准

|检查|参照基准|证据|
|---|---|---|
|静水压|零流等温单管 Δp=ρgΔz，绝压/表压一致|压力符号、节点高度、低压裕度|
|管摩阻|圆管 Darcy–Weisbach；层流解析、湍流摩阻关系的适用范围|Re、ε/D、f、压降，独立手算或独立工具|
|局部阻力|已知 K 的单元压差|速度、K、压降闭合|
|闭合供回回路|上升/下降静压项代数求和并抵消；泵差压独立|净静扬程和局部压力分别核验|
|无散热输送|塞流时间 V/Q；流体焓守恒|温度前沿到达时间、停流处理|
|管壁热损|恒定边界圆柱热阻稳态极限|热流跨水/壁/环境一致|
|绝热热容|单控制体混合能量解析|混合终态与储能变化|
|储罐/设备接口|常热源、无负荷、单充放热解析极限|功率、状态、累计能量闭合|

解析基准应与生产实现计算路径独立；同库复制相同实现不能算独立复核。文档中检查公式量纲时允许符号分析，不等于运行模型。

## 3. 守恒、正性与库存

在节点、段、设备/罐控制体、系统边界分别报告质量与能量残差。全系统能量要纳入 A 可用/取热、热泵电功与热输出、泵功（如归入热）、B 交付、管/罐散热以及初末管/水/罐库存差；说明热泵源侧和负荷侧避免重复记账。记录最大、累计、均方、绝对和尺度归一化残差。

检查绝压、温度、流量方向、密度、热泵能力、罐能量/层温、压力余量和累计库存均在定义的物理域内。初始罐/管/源库存提供的热量须计账；R0/R1/L/T 期末库存须匹配或明确校正。阈值与容差在运行前冻结，依据解析例、浮点误差和目标差异解释。

## 4. 时间步/空间离散收敛

对相同初始状态、输入、边界和控制事件逐次减半时间步（至少三个层级）；若使用管段空间离散或热前沿网格，也分别做空间分辨率收敛。监视 B 峰值/累计欠供、热到达时刻、压力最低值/最大压降、管损、泵电、热泵启停事件、罐库存及总能量差。报告相邻细化差值、趋势、事件时刻偏移与预设容差。联合仿真还要检查交换步、事件排序、状态回滚和时间通信误差，避免只看年度平均。

## 5. 独立复核、测量需求与 held-out 设计

未来合成 L2 至少由独立复核者以不同代码路径或工具复算解析基准、完整质量/能量核算和至少一个 L/T 配对案例，核对精确输入提交/哈希、方程边界、工具版本、日志、复核统计和排序。独立复核者不依赖结果作者复制表格。

如未来另获真实场址验证授权，先定义目标量和决策误差，再登记测量包与数据权利：A/C/B 端供回温与流量、关键高低点绝压/差压、泵/热泵功率和状态、罐温分层/库存、负荷交付及环境温度；各变量需校准证书、精度/分辨率、时间同步、缺失/异常规则、位置与许可。预先按场址、季节或时段划出校准集和未触碰的 held-out 验证集；不将留出数据用于调参。此项不属于当前合成设计授权。

## 6. 明确失败与 Founder 门

任一情况成立即不输出 L/T 推荐：拓扑/输入来源冲突；解析基准不通过；质量/能量超容差；物理状态越界；服务/初末库存不匹配；时间步/空间/耦合不收敛；独立复核不能复现；参数不确定性与模型形式误差未拆分；或排序跨越决策线而未揭示敏感条件。

未来验收包包含精确代码 SHA、工具与库版本/许可、合成输入冻结包和哈希、场景/设计版本、方程假设、解析基准、守恒、收敛、独立复核、资源记录、限制与未决项。Founder 可选 APPROVE L2 SYNTHETIC IMPLEMENTATION / REQUEST EVIDENCE OR REPAIR / HOLD。当前仅等待科学验收。
