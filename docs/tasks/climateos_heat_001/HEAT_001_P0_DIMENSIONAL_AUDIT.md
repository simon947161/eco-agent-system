# HEAT–001｜18 TW、46 TW 与 39% 的量纲审计

**判定。** 580 EJ/年到 18.4 TW 的换算成立，行业清单尚不能独立复原。46 TW 可重演为作者假设的结果，其大气分配与被引观测冲突。39% 能复算为两个约数的比值，不能据此认定废热导致了相应比例的近期增温。以下仅做原文算术与守恒检查。

## 地球能量边界

1. **大气顶（TOA）**。令 N = 吸收太阳短波 − 对外长波，向地球为正，单位 W/m²。温室气体改变同一参考状态下的辐射收支；温度、水汽、云、雪冰随后响应。有效辐射强迫 ERF 指外部扰动及快速调整引起的 TOA 净辐射变化；实况 N 包含气候响应。不得将 ERF 再加到已经观测的 N 上。[IPCC 第 7 章](https://www.ipcc.ch/report/ar6/wg1/chapter/chapter-7/)
2. **气候系统热库存**。海洋、陆地、大气、冰冻圈合并后，子系统间热交换抵消。若边界排除燃料化学能、裂变燃料和深部储热，热预算可写作 dH/dt = A·N + Pₛ + B。Pₛ 是从所排除库存实际转入此边界的净功率；B 为其余明列边界项（例如采用绝对量时的背景地热）。以扰动为账时各项均用相对同一基准的变化。若边界包含这些库存，须同时记库存耗减；地球总能量不会因人类用能凭空增加。观测热含量变化本身已包含实际发生的过程，不可在其上再加一遍排热。[Flanner，§1](https://doi.org/10.1029/2008GL036465)
3. **大气库存**。大气能量变化同时受大气辐射收敛、地表显热、潜热、水相变及输送控制；局地还要计平流。排到海洋、土壤或大气的热会继续交换。地表温度趋势（K/年）不是大气全柱热含量趋势（J/年）。从温度变化识别来源需要明确质量、热容、水分、垂直结构、反馈和反事实。[Trenberth 等](https://doi.org/10.1175/2008BAMS2634.1)
4. **同一时段的观测对照**。1971–2020 年储热率为 0.48±0.10 W/m²，约 245 TW；用同一时段的约 1% 大气份额，得到约 2.4 TW 的长期平均储热量级。2006–2020 年总储热率为 0.76±0.20 W/m²；2026 更新研究给出 2006–2025 年 1.04 [0.82, 1.25] W/m²，约 530 [418, 638] TW。它们采用不同统计期和不确定度约定；不将 1971–2020 的分配比例机械乘到后来年份。18.4 / 459 约 4.0%，也仅是跨口径尺度对照，不是“修正后的贡献率”。[von Schuckmann 等，§6、图 8–9](https://doi.org/10.5194/essd-15-1675-2023) · [Forster 等，§6、表 4](https://doi.org/10.5194/essd-18-3889-2026)

## 其余可能改变结论的主张

|v1 位置|成立的窄结论|证据不足或相反的部分|
|---|---|---|
|pp.1、3、7，“天气”与“气候”|长期平均功率与短时峰值应区分|Flanner 已做气候尺度平衡试验；将其描述为天气尺度比较会遗漏原研究。0.03–0.16 W/m² 的上下限在 v1 缺逐值对应的年份、地域和情景。|
|pp.5–6，35% 效率|不含外供有用热、以净电为产出的热机，(1−0.35)/0.35 ≈ 1.86 W 排热/W 电|独立电站转换损失可计量。电在终端耗散不应回填为第二笔燃料。联产、余热利用、不同电源效率与光伏地表改造均需独立边界。|
|pp.6–7，增长、复利和温度趋势|在给定增长率下，功率随时间增长，积分才得到释放能量|1.5–2%/年缺起止年、序列与不确定度。2035、2045 是条件外推。库存还受对外辐射和海气交换影响；无平滑算法、反事实或辨识，无法从温度趋势归因。作者给分子约 10–20% 的不确定度，未传播结构性分母错误。|
|pp.6–8，温室放大和技术排序|直接热与温室气体通过不同通道影响气候；本地热源值得制图|恒定正热源也会在前工业背景引起调整，直至新增出射平衡输入。城市 CO₂ 与排热共址不能证明超加性交互。“只有光伏和风能”、本地 CO₂ 高出 50–100 ppm 及普适的技术优先序缺对照；还须核查水能、热泵、效率、土地和反弹。|
|pp.7–8，城市效应|特定热浪、风场和混合条件下，局地排热可改变夜间近地气温|城市典型 20–80 W/m²、繁华区 >200 W/m² 等范围需要面积、时段、站点与排放高度。不得转为任一项目的温升、健康或全球收益。[Phoenix 研究](https://doi.org/10.1002/2013JD021225) · [局地模型结构不确定度](https://doi.org/10.1029/2024MS004431)|
