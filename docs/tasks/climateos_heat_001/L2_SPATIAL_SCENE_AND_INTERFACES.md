# L2 空间场景与多物理接口合同

## 1. 继承的场景，而非另建数据层

复用 ARCH–P0 所定义的同一概念场景、稳定节点/转移语义、provenance/uncertainty passport 和 L0–L4 保真度门。L2 不创建与 ARCH–P0 竞争的新场景模型。拓扑固定为 A=稳定合成余热源，C=热泵和可选水罐连接站，B=单一季节聚合热需求；A–C 为低温供回水对，C–B 为高温供回水对。只有这两条走廊/段，T 布局图上的任何几何连接线不是第三根管或新用户。

设计版本采用 #177 HEAD 369ee6b9703fedb54ca4da684920e6c23825d6ca 的 synthetic scene v1 与五幅研究图。L 低温/高温沟长 80/40 m，节点相对标高 0/+2/+3 m；T 为 120/180 m，标高 0/+6/+3 m。长度为单程概念沟长，不是成对两管总长。R0/R1 与 L/T 按 P1 合成服务/期末库存边界匹配。

## 2. 场景语义、标识与几何

稳定 node_id、transfer_id、port_id、设备和受体 ID 必须复用 ARCH–P0 / #177 的冻结字典；在具体清单未知或引用冲突时登记阻塞，禁止随意造一套平行标识。每个 transfer 唯一对应可追踪的物理/能量接口，供水与回水实体、热泵源侧/负荷侧端口及罐接点清晰区分。现有标识若需扩展，追加兼容字段且版本化，不能静默重命名。

几何字段最少包括：scene/design/schema version；node/transfer 稳定 ID；局部 XYZ 轴序与单位；坐标框架类型；沟中心线/管中心线顶点与明确的两者差异；端口位置/方向；时间基准；所有数据的来源提交、许可、有效期、测量/设计状态和不确定性；受体范围/时段/指标及 unknown 状态。当前概念坐标仅可使用任意右手局部 XYZ、z 向上、米制，原点与 datum 标为 null/任意；不可填真实 CRS、水平坐标、垂直基准或实测中心线。未来真实空间数据须给水平 CRS/历元、垂直 CRS/datum、轴序、单位、精度、测量日期、授权和 provenance。

概念空间示意不表示建成路线、高程或局部流场；用于力学计算的实际中心线必须是明确的合成设计几何或有授权的未来输入。求解网格/状态/边界与 ARCH 场景几何分开版本化。

## 3. 耦合交换与变量合同

全局约定：功率 W、能量 J、绝对温度 K（可显示 °C）、温差 K、压力 Pa（绝压或表压须标）、质量流 kg/s、体积流 m³/s、密度 kg/m³、焓 J/kg；每变量列时间戳/区间语义、方向、单位、参考状态与不确定性。流入控制体为正；库存不是通量。若与 P1 使用 kWh，显式换算并维持原 P1 边界，不修改其账本。

|接口|交换状态/通量|动态与责任边界|
|---|---|---|
|A 余热源↔A–C 低温环路|源侧入口/出口 T,h,ṁ,p，可用热功率和 source state|A 热量输入一次计量；可用性/温度边界来自冻结合成输入。|
|A–C 低温环路↔C 热泵蒸发侧|进出口 T,h,ṁ,p，管损/壁温|质量/能量闭合，输送延迟、高点压力、泵曲线。|
|C 热泵冷凝侧↔C–B 高温环路|供回水 T,h,ṁ,p，Q_HP、W_HP、设备状态|温级转换及设备限值；两侧流量不得未经物理连接假设强制相同。|
|C 水罐↔所属侧端口|端口 T,h,ṁ、罐能量/层温、状态|冻结侧别、初末库存、损失、充放热/混合限制。|
|C–B 高温环路↔B 聚合负荷|供水条件、回水状态、Q_B 服务/欠供|单一聚合节点，服务边界不与固定ΔT重复过定。|
|泵/阀/控制↔各环路|压力/流量观测、转速/阀位、控制指令|泵曲线、限幅、死区、传感器/执行时延、联锁和事件。|

每个耦合量明确 master clock、UTC/区间边界、通信步、因果方向、零阶保持/插值、事件、错误传播及状态回滚语义。时间不一致/重复、端口方向不匹配、单位缺失、transfer ID 重复/丢失、库存跨步不连续，均停止耦合。

## 4. 来源、不确定性和受体

每项输入标为 inherited synthetic / design assumption / future authorized measured / derived / unknown，保存 URI/commit/hash、所有者、许可用途、版本、单位、时间有效期、分布/范围依据、误差/相关性及审阅状态。未知写 UNKNOWN/null + 原因，不能默认为零或平均值。受体空气/水/土/人沿用 #177 字典和 ARCH 场景；没有观测覆盖、端点定义与阈值时响应为 UNKNOWN，系统供热量不等于受体升温证据。
