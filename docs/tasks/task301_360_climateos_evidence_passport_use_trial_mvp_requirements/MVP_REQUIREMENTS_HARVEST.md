# MVP Requirements Harvest

This file consolidates requirements harvested from the use trial. It is not architecture design, schema, runtime, or implementation.

## User Roles

- Founder.
- Human reviewer.
- Source analyst.
- ClimateOS assistant.
- External reader.
- Future agent.
- Archive maintainer.

## Workflow Requirements

- Create case.
- Add source.
- Classify source.
- Extract signal.
- Extract claim candidate.
- Create Knowledge Object candidate.
- Link evidence candidate.
- Assign readiness.
- Flag risk.
- Request human review.
- Escalate Founder Gate.
- Archive output.
- Close sprint.

## Source Intake Requirements

- Source ID.
- Title.
- Publisher / institution.
- Date.
- URL / citation path.
- Access date.
- Source type.
- Language.
- Translation note.
- Reliability caution.
- Version / update status.
- Attachment support requirement.
- Public / private source distinction.
- Retrieval status.

## Knowledge Object Requirements

- KO ID.
- KO type.
- Linked sources.
- Linked claims.
- Linked evidence candidates.
- Readiness status.
- Risk flags.
- Review status.
- Founder Gate status.
- Archive status.
- Stop point.

## Evidence Candidate Requirements

- Evidence candidate metadata.
- Source linkage.
- Claim linkage.
- Knowledge Object linkage.
- Readiness label.
- Risk flags.
- Reviewer notes.
- Founder Gate notes.
- Archive trail.

## Readiness Review Requirements

- Allowed readiness labels.
- Blocked states.
- Human review triggers.
- Founder Gate triggers.
- Non-scoring rule.
- Audit trail requirement.

## Risk Flag Requirements

- Political sensitivity.
- Source ambiguity.
- Outdated evidence.
- Translation risk.
- Compliance implication.
- Assurance implication.
- Certification implication.
- ESG / carbon implication.

- Overclaim risk.

## Human Review Requirements

- Queue item type.
- Reason for review.
- Linked source.
- Linked claim.
- Linked Knowledge Object.
- Reviewer note.
- Decision needed.
- Stop condition.
- Archive requirement.

No review queue is implemented.

## Founder Gate Requirements

- Escalate future architecture authorization.
- Escalate public / partner use.
- Escalate conclusion-risk language.
- Escalate operational Evidence Passport proposals.
- Block automatic continuation.
- Record Founder Gate status in future documentation.

## Archive Requirements

- Source archive.
- Decision archive.
- Review archive.
- Founder Gate archive.
- Sprint closure archive.
- GitHub documentation trail.
- Future reproducibility.

## Boundary

No runtime, API, database, MCP, n8n, QCloud, automation, scoring, operational Evidence Passport, architecture authorization, architecture design, implementation, compliance guidance, assurance guidance, certification guidance, standards interpretation, framework interpretation, ESG conclusion, carbon conclusion, or Task361 start is created by this requirements harvest.
