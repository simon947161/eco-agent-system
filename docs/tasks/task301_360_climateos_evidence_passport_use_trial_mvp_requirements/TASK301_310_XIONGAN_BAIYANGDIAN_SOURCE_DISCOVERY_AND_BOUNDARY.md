- Publicly citeable source path or publication reference.

- Access date recorded.
- Status marked candidate only unless future human review upgrades the source.

Exclusion criteria:

- Sources that require unsupported factual interpretation.
- Sources that would require standards interpretation, compliance evaluation, ESG / carbon conclusion, assurance, certification, or scoring.
- Sources that cannot be separated from political conclusion-making.
- Sources without enough citation metadata to support candidate tracking.

Provisional-only rule: discovery sources are candidate records only. They are not admitted as final evidence in this sprint.
