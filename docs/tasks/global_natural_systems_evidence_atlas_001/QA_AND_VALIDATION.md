# QA、真实证据与验收限度

**本地软件LOCAL_VERIFIED；科学准入PENDING。** 标准Python、无新增依赖。实际命令、时间、Python版本、测试名及exit code：[tests.txt](evidence/tests.txt)；查询重放：[validation.json](evidence/validation.json)。

针对性验证共93项：Atlas16 + 原CCZPS比较8 + PR145审查47 + PR144物料账11 + PR143物理核心11。不是93个独立科学实验。新增测试使用真实冻结元数据及语义错误/缺失反例，不将作者夹具当现场数据。

| 需求 | 验证与保守行为 |
|---|---|
| 全球完整性 | 同独立M49事实摘录逐项核名称/ISO/ID和集合；248项，缺失或重复失败；不声称世界政治实体全集 |

| 复现 | 查询与e2e两次规范JSON一致；LF文本SHA清单验证，普通重放不修改归档 |

原件可用性：M49、Scorecard、reports原HTML仅在作者忽略缓存；另一机器无需原HTML可复现查询和验证，但要独立核网页摘录仍需合法取得相同版本或逐条对照。NDC防护响应哈希可验证“取得的不是数据”，不能验证NDC全文。web读取但未下载的来源SHA明确null。

额外全库回归实际运行560项：沙箱中8个既有localhost HTTP测试因WinError10013失败，1项跳过，其余551项通过。核查这些测试仅使用127.0.0.1、临时数据库和合成流程后，在允许本地socket的环境仅重跑相关两模块，10项全部通过。没有重跑或扩展科学实验，也没有把首次失败隐藏成一次全绿；摘要与经过路径脱敏的日志见[evidence/full-suite-summary.json](evidence/full-suite-summary.json)。旧测试生成的4份已跟踪报告已恢复到原HEAD，未纳入本次提交。

`evidence/manifest.json`固定任务文件、新适配器/测试与调用的旧代码/夹具；这是同Git树内完整性检查，不是机构数字签名。执行日志、manifest自身及两份R/D交接JSON不自引用进manifest；R/D元数据通过Git提交与最终评论锚定。默认验证不执行网络采集、GIS叠加、新排放或气候模型。
