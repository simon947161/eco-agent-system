## ClimateOS Core Boundary

ClimateOS Core serves:

- environmental observation
- environmental evidence
- environmental validation
- environmental governance
- environmental action

Runtime, Agent, MCP, SDK, website, repository workflow, and Builder Dispatch are supporting mechanisms.

They are not ClimateOS Core's mission.

Any engineering work that cannot explain its environmental governance purpose must not enter ClimateOS Core.

## BuildingOS Boundary

BuildingOS may act as an engineering laboratory or demonstrator.

Engineering experiments may occur in BuildingOS before they are mature enough for ClimateOS.

Migration from BuildingOS experiments back into ClimateOS Core requires Architecture Review.

## Implementation Boundary

No runtime, API, MCP, website, scoring engine, workflow engine, blockchain, token model, or automated governance implementation was introduced.

The Task100 review remains documentation-only.

The interactive website, if created later, must be treated as a ClimateOS / BuildingOS demonstrator for human use testing, not as ClimateOS Core itself.
