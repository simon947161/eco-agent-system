# Task638 Founder Gate Trigger Contract Example

## Purpose

Show an Evidence Contract example that must stop at Founder Gate.

## Example Record

| Field | Example Value |
| --- | --- |
| Evidence ID | `EC-FOUNDER-GATE-001` |
| Origin Domain | GovernanceOS |
| Receiving Domain | ClimateOS core |
| Claim Type | Proposed cross-domain action with sensitive implications |
| Source Type | Fictional internal proposal |
| Source Status | Draft; gate required |
| Method Context | Proposal references multiple domains but lacks reviewed evidence |
| Spatial Context | Fictional community site |
| Temporal Context | Future planning window |
| Uncertainty | Evidence incomplete, affected humans not reviewed, domain disagreement unresolved |
| Review State | Founder Gate required |
| Prohibited Reuse | No action, public claim, model training, scoring, certification, or runtime implementation |
| Cross-Domain Notes | Requires Founder decision before any Task641+ work or public-facing use |

## Gate Trigger

Founder Gate is required because the proposed action could affect governance
direction, cross-domain priorities, public claims, and future implementation
scope.

## Interpretation

The Evidence Contract can identify that a record is too sensitive or incomplete
to continue through normal review.

## Validation Requirement

Future work should define what evidence must be attached before a Founder Gate
record can be accepted, deferred, rejected, or returned for revision.
