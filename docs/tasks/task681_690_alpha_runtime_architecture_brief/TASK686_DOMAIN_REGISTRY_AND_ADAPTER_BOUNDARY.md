# Task686 Domain Registry And Adapter Boundary

## Domain Registry Concept

A future registry may describe approved domains, capabilities, evidence types, review authorities, version, and current availability without centralising domain science.

## Adapter Contract Concept

A future adapter boundary may describe request scope, input provenance, model/provider identity, assumptions, outputs, uncertainty, failures, licensing, and human-review requirements.

## Provider Independence

ClimateOS must not become dependent on one model, vendor, agency, or language. Mature public tools should be assessed before original development.

## Private Extension Boundary

Private extensions require separate Founder authorization. No private EcoEngine detail may be inferred or encoded here.

## Boundary

No registry, adapter, connector, model call, or live retrieval is implemented.
