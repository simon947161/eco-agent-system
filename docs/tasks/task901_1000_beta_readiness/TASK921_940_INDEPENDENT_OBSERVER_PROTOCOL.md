Status: Prepared; not yet executed.

only this task:

> it, and find the audit record. Do not make a real environmental conclusion.

Shu Min may start the server but must not explain controls or point to the next
button. Record completion, hesitation, wrong turns, requests for help, language

but is not labelled independent observation.
