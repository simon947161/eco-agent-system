# 共享状态、中介与运行序列

状态包含17种字段定义，实际初态含11局地变量及5独立全局/季节字段。单位/量纲/介质/参考条件/值类型/时空支撑/来源hash/许可/QC/不确定性与协方差均随字段保存。`field identity`包含语义、网格和时间；当前State容器每个语义只容纳一个有效字段，多源同变量必须先仲裁或分State保存，未实现通用多来源数据库。

空间：实际演示二维矩形条带，局地平面米制，1D横向热交换。2/4/8格对照。经纬点仅支持EPSG4326↔3857转换，禁止用Mercator面积作保守积分；点样本不自动变区域平均。面积量以`sum(value*area)`守恒，权重为重叠面积/目标面积；广延量权重另用重叠/源面积并单测，本次字段目录全为强度量或单位面积库存，禁止假标extensive。球面、三维、不规则网格DEFER。

时间：ISO时区、显式起止、proleptic Gregorian。瞬时状态在区间起点采样并供下一慢步使用；平均通量保留其实际积分区间。严格相等才直接交换；完整相邻累计量可求和，缺测保留None、时域协方差未知时不报虚假标准差。没有月→小时分解、缺测插值或季节→秒级因果注入。显式偏移日界支持DST23小时测试，未推定BOM观测日。

每慢步：检查依赖和支撑 → 同步外强迫 → 固定旧库存 → 提案交换 → 校验范围/收敛 → 对账 → 原子提交。双向迭代的每一次试算都从同一旧库存出发，不能重复积累降雨。共享H/E两侧符号相反；独立策略无交换；单向策略把空气当无限边界储库，显式记出水/热，不能把这三者的差值解释为预测误差。

双向的气温升高改变密度/显热差，空气增湿降低蒸发驱动力，蒸发反过来改变地表温度/水分；局地热扩散连接相邻格。季节与全球组件在同一state/证据接口共存但无未经验证的数值边。稀疏q仅阻断需要它的边，独立地表和全球ERF继续可用。

checkpoint/reset保存不可变Field和revision，失败回滚至步前。`difference/apply_difference`携带前后值、来源元数据与两端hash，正逆重建必须命中基准hash；观测不可覆盖。当前运行史由trace和配置/hash保存，未建常驻历史服务。

结构验证不能认证来源：OBSERVED_STATE标签要求公开冻结来源模式及证据等级，但前缀本身不是密码学授权。实际调用只从已校验的PR147/149清单读取CONSTRAINED_ESTIMATE；任何未来外部接入仍需独立Evidence Passport准入。合成配置不能改标实测。
