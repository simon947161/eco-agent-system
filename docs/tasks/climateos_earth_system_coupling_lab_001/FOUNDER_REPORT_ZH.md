## 我们实际找到了什么

可复用机制是“状态有单位和时空支撑、组件只提出变化、同一通量两侧对账、失败回到原状态、最后再比较情景”。气温、气压、风、湿度、降雨、净辐射、水库存、蒸发和径流在同一局地状态中参与计算。空气与地表双向影响；ENSO统计与全球甲烷ERF在同一证据接口中独立存在，不伪造局地因果连接。

在固定6小时合成例子中，双向交换使空气增湿，蒸发驱动力减小。结果如下（不是Wagga天气预报）：
