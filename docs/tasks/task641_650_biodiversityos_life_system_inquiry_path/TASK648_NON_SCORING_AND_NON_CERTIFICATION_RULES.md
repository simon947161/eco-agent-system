# Task648 Non-Scoring And Non-Certification Rules

## Purpose

Prevent BiodiversityOS inquiry examples from becoming premature scoring,
ranking, certification, compliance, or public claims.

## Rule 1: Inquiry Is Not Scoring

An inquiry question asks what may be happening. A score claims to measure value
or performance. Task641-650 only creates inquiry language.

## Rule 2: Observation Is Not Certification

An observation can support learning. It cannot certify biodiversity value,
climate benefit, ecosystem health, or restoration success.

## Rule 3: Evidence Need Is Not Evidence Sufficiency

Listing evidence needs does not mean the evidence exists or is adequate.

## Rule 4: Review Is Not Approval

Review can improve interpretation. It does not automatically approve public use,
policy use, investment use, compliance use, or certification use.

## Rule 5: Founder Gate Before Capability Expansion

Any future move toward scoring, certification, runtime integration, model
execution, sensor integration, external data connection, deployment, or agent
automation requires a separate Founder Gate.

## Prohibited Outputs In This Batch

- biodiversity score;
- ecosystem-health grade;
- restoration certification;
- climate-resilience rating;
- carbon-credit or biodiversity-credit claim;
- compliance or assurance statement;
- operational recommendation;
- automated decision.

## Allowed Output

A safe learning record: question, observation, hypothesis, evidence need,
uncertainty, review requirement, and next inquiry step.
