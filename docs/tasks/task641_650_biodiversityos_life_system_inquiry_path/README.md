## Purpose

Task641-650 redirects the post-Task640 path from evidence-state bookkeeping
toward scientific inquiry. The batch asks how ClimateOS should begin to learn
about Life System and BiodiversityOS questions before any runtime, scoring,
certification, or model integration exists.

## Human-Language Summary

This batch says: do not begin with a table. Begin with a living-world question.

For example: how might biodiversity influence heat resilience, water buffering,
soil stability, carbon cycling, ecological recovery, and human climate
adaptation?

ClimateOS should learn by observing signals, forming hypotheses, identifying
evidence, checking uncertainty, preserving disagreement, and asking humans or
experts to review what the system cannot safely conclude.
