# 不确定性和验证状态

本轮无真实降雨序列；以下检查均 **NOT_EXECUTED_MISSING_RAIN**。既没有支持“关系稳定”，也没有支持“关系不稳定”的数值结果。

| 问题 | 预登记方法 | 必须保留的失效解释 |
|---|---|---|
| 小样本相位 | k/n、Wilson95%；n<5 LOW_N | 极宽区间不能改成确定性结论 |
| 年际自相关 | 真实相邻年相关；长度3与5年循环块2000次 | 60年短样本、块长选择与平稳性假设；不要拆站作独立年份 |
| 阈值估计 | 固定中位数主结果；块内重估基准敏感性 | 固定阈值区间未计阈值不确定性；基准重估有效季不足则阻塞 |
| 非平稳 | 原阈值下前30/后30；后30年中位数回顾性敏感性 | 后期重定阈值不能冒充训练外检验 |
| 极端阈值 | 预定Type7的20/80分位 | 小n、尾部估计不稳；不能事后挑选更显著阈值 |
| 留出年份 | 训练1961–1990；测试1991–2020；固定阈值与Jeffreys概率 | 当前修订RONI不等于真实实时hindcast；不得按测试结果调参 |
| 空间/季节依赖 | 所有地区共用年抽样，报告全部三配对 | JJA→SON与SON同期复用同一响应，不是两份独立复制 |
| QC/位置/源变 | 拒绝标记/缺测，不补零；检验坐标/来源变化 | 无daily完整性、仪器校准、同质化证明；严格完备筛选也可能偏样本 |
| 多重比较 | 不按p值筛选；全表nominal区间 | 不声称通过族错误率控制；只可探索性比较 |
| 混杂 | IOD/DMI和AAO分别按符号分层；每组至少5 | 单项分层不等于联合控制、独立归因或因果识别 |

留出评分为 `BS = mean((p_train_phase − event_test)²)`，并与冻结训练无条件概率比较；差值负值才说明该样本上较低平方误差，不代表已验证未来预测。当前BS及差值都是null。

bootstrap方案同时重采相位/响应/缺测日历槽，避免把相位独立打乱造成另一种零假设。有效重复<1800应说明不稳定，不能只删掉无组别的重复后隐瞒比例。真实计算前仍需独立检验实现及训练/测试泄漏；本轮没有开发这个完整统计引擎。
