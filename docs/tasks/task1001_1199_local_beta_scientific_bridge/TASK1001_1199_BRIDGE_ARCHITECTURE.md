# Task1001–1199 Local Beta To Scientific Roadmap Bridge

Status: Founder-authorized bounded bridge; Task1200 hard stop

## Purpose

Carry the conditionally accepted local Alpha into a usable, governed local Beta while preparing evidence contracts for future scientific-model admission. The bridge does not implement Task1200 science.

## Batch route

| Range | Deliverable | Runtime boundary |
| --- | --- | --- |
| 1001–1024 | onboarding, readable evidence/audit views, local time, declared responsibility, PowerShell launcher, keyboard/200% zoom regression | existing localhost prototype only |

## Persistent requirements

- local, project, NGO and regional nodes remain distinct;
- GIS meaning includes coordinates, address, geometry, jurisdiction and uncertainty;
- observations retain casual, structured, professional and validated levels without automatic promotion;
- every admitted source retains identity, version, licence, provenance and responsible submitter;
- Evidence Assets remain challengeable and cannot imply truth, ownership, certification or financial value;
- carbon methods and ESG++ translations require named methods, versions, uncertainty and human approval;
- dispute, counter-evidence and supersession never erase history;
- future model inputs remain evidence candidates subject to Task1200 Model Admission Gate.

## Prohibited throughout the bridge

No public deployment, authentication, multi-user runtime, live external data, unrestricted automation, automatic scientific/compliance/legal/investment conclusions, external model integration, operational warnings, private EcoEngine access or Task1200 execution.

## Gate discipline

Each range requires a clean baseline, bounded changes, proportionate tests, task record, Founder-readable retest or review instructions, and explicit closure. Task1200 requires a fresh scientific, repository, licence, data and compute preflight plus new Founder authorization.
