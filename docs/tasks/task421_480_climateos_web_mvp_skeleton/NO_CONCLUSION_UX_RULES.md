# No-Conclusion UX Rules

This document is part of the Task421-480 ClimateOS Evidence Passport Web MVP Skeleton Sprint. It is limited to static Web MVP skeleton, screen specifications, mock data, page inventory, and prototype boundary records. It does not authorize or create runtime, backend service, production API, database schema, MCP, n8n, QCloud integration, automation, scoring, compliance guidance, assurance guidance, certification guidance, ESG/carbon conclusions, standards interpretation, framework interpretation, operational Evidence Passport, deployment, or Task481.

## Required UI Warnings

The static skeleton must visibly communicate:

- Static skeleton only.
- Mock data only.
- Candidate records only.
- No final evidence.
- No verified claim.
- No score.
- No compliance result.
- No assurance result.
- No certification result.
- No ESG conclusion.
- No carbon conclusion.
- No standards interpretation.
- No framework interpretation.
- Human Review required.
- Founder Gate required before future escalation.

## Prohibited UI Labels

Do not label any item with wording that implies:

- Final source verification.
- Final claim acceptance.
- Certification status.
- Assurance status.
- Compliance status.
- ESG readiness.
- Carbon readiness.
- Accepted evidence.
- Operational Evidence Passport status.
- Production status.
- Deployment status.

## Stop Copy

Use stop copy where needed:

```text
Stop: this candidate cannot become a conclusion in this skeleton.
```

```text
Founder Gate required before external use or future implementation.
```

## Boundary

The no-conclusion UX rules are copy and layout rules only. They do not create enforcement automation.
