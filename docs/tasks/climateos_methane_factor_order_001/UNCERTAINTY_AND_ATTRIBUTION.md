## 数学结构

`c=x(P−e)M/(RT)`，域T>0、0≤e<P、x≥0；对数分析要求x>0。

`d ln c = d ln x + (dP−de)/(P−e) − dT/T`。

弹性：x为1，P为P/(P−e)，e为−e/(P−e)，T为−1。有量纲梯度（x,P,e,T顺序）为`J=(c/x,c/(P−e),−c/(P−e),−c/T)`。RH不是e，未知RH水/冰参考时不自行选饱和水汽公式。海拔无额外乘数；风在独立输送研究中处理。

正值两端A/B的精确对数差：

`Δln c=ln(xB/xA)+ln((PB−eB)/(PA−eA))−ln(TB/TA)`。

P/e耦合可合报干气压贡献，或采用两种替换顺序平均：

`CP=0.5[ln((PB−eA)/(PA−eA))+ln((PB−eB)/(PA−eB))]`

`Ce=0.5[ln((PA−eB)/(PA−eA))+ln((PB−eB)/(PB−eA))]`。

四个交叉角P−e均须正。CP+Ce恰为干气压对数贡献，交互平均分摊，不随先替换P或e改变；这是数学归账，不是因果归因。未应用于实际行；不报告实测排序。
