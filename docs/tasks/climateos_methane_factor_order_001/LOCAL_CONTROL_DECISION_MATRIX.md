# 地点与工艺条件决策矩阵（研究框架）

来源结构沿用PR138 P3/FOD、P2/P4及PR139；方法目录为[IPCC2006 Vol5](https://www.ipcc-nggip.iges.or.jp/public/2006gl/vol5.html)第3/6章。本表不宣布IPCC失效、不核发信用、不制定地区配额。参数未经标定均HYPOTHETICAL；候选措施不等于可执行建议。

|场景/目标|可测变量|方法与候选措施|支持地点选择的必要证据|当前不足/停止|
|---|---|---|---|---|
|填埋场：减少边界CH4逸散|分组入场量/组分/龄期，填埋体温湿、产气与库存、井网压差、捕集流量/组分、覆盖通量与氧化|FOD作为库存基准；质量平衡与现场通量作验证；候选为有机物分流、捕集维护、适宜覆盖氧化|当地物料和运行历史；气象事件前后覆盖状态；捕集效率与旁路；水/安全影响、资本及维护成本|CoomaFOGO是分流量而非残余入场量；BRW大气不是Cooma排放。不能给出措施减排率或经济排序|
|污水：控制气相及溶解CH4，同时管理N₂O/能源|水温、COD/BOD、流量、HRT/SRT、DO/ORP、工艺和气体流量/组分、溶解CH4、运行状态|污水清单框架、现场质量平衡；候选密闭捕集、脱气回收、工艺/负荷和能耗调整|同期水/气/能边界，溶解输送去向、工况与反事实、气体仪器/流量不确定度；N₂O与能源权衡|PR139水中23样本不能变大气ppm；1705流量行/311时间戳不是同期独立验证；The Glen不能继承区域5ML/d负荷|
|开放环境背景站：监测与验证代表性|干摩尔分数、风/边界层/气团、P/T/e、高度、校准与背景|P1状态换算只解释单位和环境条件；候选改善观测布点、校准与元数据|源受体设计、独立背景与设施观测；严谨反演另需授权|本站无设施控制量，不能开减排处方、估全国量或将海拔差当因果|

共同决策顺序：定义边界与目标→核对地点/工艺证据→建立监测和不确定性→比较候选的环境与经济权衡→独立核证及Founder决策。尚无措施实施授权。天气不可直接干预，但适应性运行假设可在后续授权协议中研究；不把气温代理当实际反应温度。
