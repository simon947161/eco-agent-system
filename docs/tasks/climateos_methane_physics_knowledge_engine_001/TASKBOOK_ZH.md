## 0. 真正目的
ClimateOS 是面向气候变化问题的科学计算体系，不以营销、通用聊天助手或门户为主线。
将现有自然科学知识中的**甲烷过程**分成「生成→转化/储存/捕集→排放→大气输送/化学→辐射/气候响应→减排干预」的因果与质量/能量关系网络。为每一条连接找已有方程、变量、单位、适用条件、原始来源、验证证据、可运行求解器；让 AI 根据明确的问题选择可计算路径，不能让语言模型随意编造物理定律或把相关性当因果。
先把甲烷作为一个完整可追踪的垂直切片，设计将来拓展 CO2、N2O、水、能量、生态系统的公共接口，但本轮不开发全地球通用模型。
Founder 的交付语言必须直白：什么影响什么、现在算得出什么、算不出什么、下一步缺什么。专业术语、方程、误差留在附录和机器契约。

## 2. 科学知识网络：完整扫描、有限深入
先做一份广覆盖的 FACTOR_UNIVERSE：甲烷排放与气候过程所有主要可辨机制，不按因素数量作为成果。最低覆盖：
A 生成：底物/有机碳、废物历史、厌氧条件、温度、水分、pH、营养、微生物、停留时间、工艺、土地利用/湿地、水位；
B 相态/储存/控制：溶解-气相平衡、亨利定律、压力、气体容积、孔隙度、渗透率、扩散、对流、氧化、覆盖层、火炬/捕集效率、管网泄漏、曝气；
C 排放：通量/源率/时间变化、设施操作、地形、气象压力变化、边界和监测方法；
D 大气：P/T/水汽、干湿摩尔分数、风、湍流、边界层、地形、光照、OH、O3、NOx、背景排放、季节/纬度/海拔、混合、化学损失；
E 气候：辐射效率、间接效应、寿命反馈、全球负荷、AGWP/GWP/温度响应、时域/背景、模型/碳循环约定；
F 干预：源头减量、分流、工艺优化、捕集、修漏、氧化、能源/共污染物权衡、成本/可靠性。
每个因子记录物理角色：INPUT / STATE / PARAMETER / FORCING / CONFOUND / OBSERVATION / INTERVENTION / OUTPUT；其所在空间/时间尺度；可观测性；适用介质和源类；已知数学关系；边界条件；不能跨越的科学推断。
再**优先选 10–15 个机制/公式节点深入核验**（不是所有因素逐一写百科），至少覆盖 P1、质量守恒、FOD、Henry、水相/气相、氧化/捕集、输运、CH4+OH、辐射脉冲响应、干预对照。若某公式无足够权威来源则保留候选而非发明参数。

## 3. 排序必须可解释，不得用AI直觉给科学因子绝对排名
同时产生四种不同排序：
1. 因果顺序（上游过程→下游结果）；
2. 研究优先级（影响范围、与目标问题相关性、可观测性、现有证据、可控性、成本/时间、验证可行性）；
3. 参数敏感性（仅对明确模型、范围和单位成立；可以在已有合成模型内做有界解析/局部敏感性，不可把它冒充实测因子贡献）；
4. 干预优先级（须实际设施输入与成本/基线，缺则 UNKNOWN，不输出通用减排百分比）。
优先级打分的权重、来源、规则透明；列出权重变化时排名是否稳定；不允许以未经证实的相关性推出物理因果。区分直接因素、共同原因、反馈和仅影响测量值的因素。
针对 0–3000m 地面设施与高空观测，地表高度/释放高度/气压/背景的作用分别标记；**禁止**由 P1 mg/m³差异直接推每吨GWP差异。CO2充分混合为可检验零假说，直接CH4排放与航空NOx/水汽/尾迹分开。

## 5. 一条真正可执行的物理链（核心工程验收）
在**现有已允许的合成/解析测试范围**内选择最小链，不必一次贯通所有全球气候过程。优先：
- 可运行链 A：给定甲烷干摩尔分数、P、T、水汽→P1质量浓度/参考体积，并验证质量守恒、单位/解析极限、误差传播；
- 可运行链 B（如现有代码支持且测试安全）：假设库存/生成→质量守恒→合成逸散；与 P1 的连接必须检查物理量、体积、时间、系统边界及气体组成，不能把同一份合成库存输出冒充现场观测。
**至少真正执行链A**，链B如无法科学自洽则输出明确的阻塞报告，不能硬接。所有运行标 SYNTHETIC_REFERENCE / ANALYTICAL_TEST，不生成真实排放、气候效应或治理收益。可用现有合成输入，拒绝新大型气候/化学模型或现场反演。
运行时必须生成：完整输入、逐步单位转换、每步方程/参数/出处、输出、守恒残差、失败原因、机器审计JSON、Founder通俗解释。写小型路由/方程注册/执行器，优先复用 cczps_lite 现有函数，禁止新建通用大型求解器或修改冻结核心。不得隐式设e=0、把CO2交给CH4函数、混用mg/L与ppm或将浓度当排放通量。
至少设计三个用户问题示例（“给定条件下空气甲烷浓度多少”“填埋场释放多少”“同吨数不同高度气候效应是否一样”），每个明确展示能算、只能合成演示、暂时不能算，以及最短数据缺口。

## 7. 从物理链到人能读懂的解释
每一条可执行计算输出两个并行视图：
(a) 工程可审计：方程、参数、输入、单位、误差、来源、版本、测试；
(b) 普通人说明：发生了什么→为什么→哪些条件改变结果→现在可以改变什么→还缺什么。文字清楚、简短，不用免责声明堆砌，也不能隐去真正阻塞。
明确解释“甲烷浓度变化”不等于“甲烷排放变化”，以及“排放变化”不等于“全球气候响应已算出”。
提供至少一个原创机制关系图（可用 Mermaid 或已有图工具）及一页中文Founder路线图；不开发新客户Portal、营销网站或商业服务。
