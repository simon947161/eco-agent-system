# 模型路由合同 v1

输入是闭集问题文本+严格JSON，不调用语言模型；未知或附带“忽略规则”的问题拒绝。没有自由代码执行、路径输入、联网、反演或大型模型安装。只读取固定目录的登记表与显式输入。

|问题|路由/结果|最短缺口|
|---|---|---|
|给定条件下空气甲烷浓度多少|SYNTHETIC_ONLY；已实际运行链A|只能合成参考；真实应用还须观测校准、共址时间、代表性和授权|
|填埋场释放多少|BLOCKED|废物历史/DOC、现场k与氧化/捕集、边界及流量|
|同吨数不同高度气候效应是否一样|BLOCKED|明确气体/时域/指标、输送化学、独立反事实验证|
|现有观测可否直接用于计算|STRUCTURAL_QC_ONLY；不输出数值|PR140/141元数据/校准科学门未齐|

CALCULABLE为将来符合数据/模型/许可/验证的非合成路径状态；本轮**没有**此路径，不将SYNTHETIC_ONLY升级。结构QA状态只是引用既有档案，未重新获取或复跑观测。

必须明确CH4、gas_dry_fraction_in_wet_air、SYNTHETIC_REFERENCE、source_id=TASKBOOK_SYNTHETIC_A1、合成用途许可、calibration=NOT_APPLICABLE_SYNTHETIC、同一瞬时均匀气团、p1_chain/1。这不是现场校准回执。所有P/T/e/x/V及参考P/T都必填，不隐式e=0；参考水汽0仅因输出明确为干参考气体。单位固定ppm_dry、Pa、K、m3实际湿气；CO2/N2O/mg/L/wet ppm拒绝。气压50–110kPa、温度230–330K、x≤100ppm、e≤10kPa、体积≤100m³是本原型合成包络，不是理想气体全部适用范围。

输入误差也必填且有声明来源；仅P/e相关，其余独立，常数按冻结约定精确、模型偏差不量化。大误差超出一阶包络拒绝；负/非有限/布尔数拒绝；未知字段拒绝。没有足够输入，返回BLOCKED及原因，没有填0。

执行器只允许E01–E05，先验证依赖图的完整性、循环、来源、权限和参考等级，再调用冻结P1。登记文本没有eval；即使写了复杂公式也不能调用新模型。输出输入、转换、每步公式/来源/单位、参数、残差、Jacobian及不确定性、限制和中文解释。仓库维护者是信任边界，不声称能防止有写权限者篡改代码；manifest和独立审查负责检测版本变化。
