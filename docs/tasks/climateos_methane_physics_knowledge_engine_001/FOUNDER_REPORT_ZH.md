# 给Founder：现在能算什么，下一步缺什么

这次把甲烷从“怎样产生”到“怎样影响气候”的关系组织成可查证的网络，并真正跑通了一小段：**给定空气中的甲烷比例、气压、温度和水汽，算单位体积里的甲烷质量，再换成统一参考体积，检查总质量有没有丢失。**

合成例子中，甲烷干摩尔比例为2 ppm，气压80 kPa、温度20°C、水汽分压1 kPa。结果约1.040 mg/m³；3 m³里的甲烷约3.120 mg。换成0°C、101.325 kPa的干气参考体积约2.179 m³，总甲烷仍约3.120 mg。电脑舍入造成的残差极小，未出现物理质量损失。

这说明同一份气体压缩或膨胀后，浓度可以改变，而甲烷总量不变。因此，“山上每立方米甲烷较少”不能直接推出“同一吨甲烷的气候作用较小”。我们没有用海拔替代气压，也没有证明释放高度无影响；要回答后一个问题，还需输送、化学损失、气候指标和反事实验证。

网络深入登记14个公式/机制节点。前5个构成可执行解析链；填埋降解、回收氧化、水气平衡等是有条件的文献/公式节点；气体传质、化学和全球响应有未补齐证据的候选节点。网络能指出缺口，不会自己发明参数。

30项测试通过，包括独立手算、导数核查、质量不守恒故障、错误单位、错误气体、缺水汽、来源不明和循环依赖拒绝。这是合成数学/软件验证，不是现场模型验证。假设输入误差下的浓度标准不确定度约0.0106 mg/m³，不是某台真实仪器的精度。

现在最值得做的是先审查这段基础链，再选择一个边界明确的生成—收集系统。链B暂不硬接：旧P2是假设纯甲烷容器，本例是含空气的稀薄甲烷；年度填埋库存也不能直接当小时气体库存。组成、流量、时间和库存边界缺失时，计算应停止。
