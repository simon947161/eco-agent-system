# Task228 PRI Routing For Knowledge Objects

## Purpose

Define how PRI / Matrix may route Knowledge Objects without becoming ClimateOS itself.

## Preserved Principle

```text
PRI translates.
PRI routes.
PRI governs routing.
PRI does not replace ClimateOS.
PRI does not create evidence authority by itself.
```

## Translation Role

PRI / Matrix may translate knowledge from one project context into ClimateOS-compatible routing language.

Translation should preserve source, context, uncertainty, and limits.

## Routing Role

PRI / Matrix may route Knowledge Objects toward:

- ClimateOS Mission Governance
- Signal Governance
- Knowledge Harvest
- Evidence Readiness Governance
- AEP review
- Roadmap Task200 planning
- Roadmap Task300 vision
- Deferred recommendations
- non-ClimateOS systems

## Governance Role

PRI / Matrix may help prevent cross-system confusion by recording where an object belongs and what it is not authorized to do.

## Authority Limitation

PRI / Matrix routing does not create:

- evidence authority
- runtime authority
- compliance authority
- assurance authority
- certification authority
- ESG or carbon conclusion authority
- Founder approval

## Relationship To Mission

Routing must preserve the ClimateOS Mission and must not substitute process convenience for mission alignment.

## Relationship To Human Governance

Human Authority remains above routing.

PRI / Matrix may support review but cannot silently bypass human responsibility.

## Relationship To Future Runtime Passport

Future Runtime Passport concepts may record runtime readiness or continuity metadata only if separately authorized.

Task221-230 does not create Runtime Passport operation.

## Prohibited Routing Outcomes

PRI / Matrix routing must not:

- convert a Knowledge Object into evidence
- authorize runtime
- trigger automation
- operate MCP or n8n
- create scoring
- produce public claims
- replace ClimateOS governance

## Boundary

This document does not implement PRI, Matrix, Runtime Passport, MCP, n8n, routing automation, or agent execution.
