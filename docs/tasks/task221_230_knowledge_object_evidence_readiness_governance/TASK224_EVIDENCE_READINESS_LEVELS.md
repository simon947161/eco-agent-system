# Task224 Evidence Readiness Levels

## Purpose

Define a readiness-level model for future evidence use.

These levels govern readiness language only. They do not admit real evidence.

## Evidence Readiness Level Model

| Level | Definition | Entry Criteria | Exit Criteria | Authority Requirement | Misuse Risk | Current Batch Permission |
| --- | --- | --- | --- | --- | --- | --- |
| ERL-0 | Unclassified Source | Source exists or is referenced | Captured as Signal or rejected | None beyond source capture | Source mistaken for evidence | Metadata only |
| ERL-1 | Captured Signal | Signal captured with origin and context | Registered as claim, Knowledge Object candidate, or deferred | Human or project review | Signal mistaken for truth | Conceptual only |
| ERL-2 | Registered Claim | Statement recorded for review | Classified, deferred, rejected, or routed | Claim review owner required | Claim mistaken for verified finding | Conceptual only |
| ERL-3 | Governed Knowledge Object | Provenance, maturity, uncertainty, and routing recorded | Evidence candidacy review or archive | Governance review required | Knowledge mistaken for evidence | Conceptual only |
| ERL-4 | Evidence Candidate | Knowledge Object is eligible for future evidence review | Admission gate pass, deferral, or rejection | Human review required | Candidate mistaken for admitted evidence | Future review category only |
| ERL-5 | Evidence-Ready Object | Future admission criteria satisfied | Operational admission only after future authorization | Founder / Human Authority review required | Readiness mistaken for operational use | Future-state only |
| ERL-6 | Operational Evidence | Evidence admitted for authorized runtime or Evidence Passport use | Runtime-specific lifecycle controls | Future Runtime / Evidence Passport authorization required | Operational misuse, false authority, automation drift | Not authorized |

## ERL-6 Restriction

ERL-6 is not authorized until a future Runtime / Evidence Passport authorization exists.

Task221-230 may name ERL-6 only to mark it as prohibited in the current batch.

## Authority Requirement

Higher readiness requires stronger authority, review, and traceability.

No readiness level creates public claim authority by itself.

## Boundary

This document does not create a scoring system, evidence engine, operational Evidence Passport, or runtime gate.
