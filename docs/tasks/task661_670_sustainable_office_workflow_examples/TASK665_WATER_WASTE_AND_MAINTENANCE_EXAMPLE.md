# Task665 Water Waste And Maintenance Example

## Purpose

Describe a safe Sustainable Office example involving water, waste, and
maintenance.

## Scenario

A fictional office pantry has confusing waste bins, frequent disposable cup
use, and a sink that appears to drip after use.

## ClimateOS Inquiry

ClimateOS should separate three kinds of issue:

- waste behavior and signage;
- procurement or facility setup;
- possible maintenance problem.

## Possible Records

| Record Type | Example |
| --- | --- |
| Observation | Sink appears to drip after use. |
| Uncertainty | It is unclear whether this is a leak or normal drainage. |
| Human action | Ask maintenance to inspect before claiming water loss. |
| Waste observation | Bin labels may be confusing. |
| Low-risk action | Improve plain-language signage after team review. |
| Review-required action | Change procurement or waste contractor process. |

## Boundary

ClimateOS should not estimate water savings, audit waste compliance, rank
employee behavior, or automate maintenance workflows in this batch.

## Learning Output

The useful output is a clearer question: what is a maintenance issue, what is a
choice-design issue, and what requires organizational review?
