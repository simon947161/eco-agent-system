## Purpose

Task661-670 explains how ClimateOS could help humans in an office or
organization notice environmental signals, discuss practical actions, preserve
uncertainty, and review outcomes without automation or behavioral control.

## Human-Language Summary

This batch asks: if ClimateOS eventually has a human-facing interface, how
should it help people act responsibly without pretending to command them?

The answer is: begin with observation, keep choices human, make evidence
visible, record uncertainty, ask for review when needed, and learn from what
happens after an action.
