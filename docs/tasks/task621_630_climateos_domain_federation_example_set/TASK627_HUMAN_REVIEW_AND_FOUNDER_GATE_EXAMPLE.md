# Task627 Human Review And Founder Gate Example

## Purpose

Show how human review and Founder Gate logic applies to domain federation
examples.

## Review States

| State | Meaning |
| --- | --- |
| Draft Signal | Record exists but has not been reviewed. |
| Human Review Needed | A person must judge relevance, scope, and next action. |
| Domain Review Needed | A domain specialist or informed reviewer is required. |
| Disputed | Domain positions conflict or evidence is insufficient. |
| Founder Gate Required | Scope, risk, public claim, private asset, or implementation boundary requires Founder decision. |
| Closed / No Action | Record is preserved but no action is taken. |

## Founder Gate Triggers

Founder Gate is required when an example would otherwise lead toward:

- runtime implementation;
- private EcoEngine access;
- public environmental claim;
- scoring or certification;
- sensitive biodiversity or community-impact decision;
- cross-domain governance action with unresolved uncertainty;
- Task631+ continuation.

## Example Review Note

used for claims, scoring, model training, certification, or automatic action.
