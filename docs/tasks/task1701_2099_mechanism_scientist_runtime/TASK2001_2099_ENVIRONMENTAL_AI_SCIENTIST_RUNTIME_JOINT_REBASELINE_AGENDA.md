Date: 2026-07-18

Status: DISCUSSION_AGENDA_ONLY / NOT_AUTHORIZED / NO_TASK2001_START

## 1. Why re-baseline now

Task2000 proved a minimum supervised interaction:

```text
question -> structured hypothesis -> human approval -> fixed local run
-> receipt -> quarantined passport -> human review
```

The original roadmap placed a closed-loop prototype mainly in Task2000–2049.
That minimum loop now exists earlier than expected, while genuine AI reasoning,
scientific tools, environmental inputs and expert ownership remain absent. The
remaining numbers should therefore grow the Runtime rather than repeat the same
paper contracts.

1. Should the next priority be experience quality, deeper AI reasoning, or a
   more realistic synthetic environmental experiment?
2. Should the local deterministic assistant remain the default while
   ChatGPT/Codex proposals are imported manually?
3. Which human burden should the next agent remove first: hypothesis structuring,
   experiment design, evidence checking, or review explanation?
4. Should the Runtime continue inside `cczps_lite`, or should the separated
   FastAPI/SQLite historical prototype be reconciled through a dedicated future
   migration milestone?
5. What observable experience should count as success at Task2099?
