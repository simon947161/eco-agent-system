# Mechanism Experiment No-Run Return Gate v0.1

## Entry rule

A reference may inform contract design without becoming a runtime dependency.
Paper claims, curated artifacts, numerical-model code, preprocessing, physics
and chemistry schemes, input assets and compute environments keep separate
identities and licence decisions.

## Hypothesis minimum

Every future hypothesis must specify a research question, mechanism chain,
expected direction, diagnostics for each link, alternative explanations,
falsification criteria, evidence threshold, scale/time assumptions and a named
expert owner. `NOT_TESTABLE` is a valid governed result.

## Experiment minimum

Every future experiment registration must specify baseline, perturbation,
control, sensitivity, model version, configuration hash, input and boundary
identities, diagnostics, stop conditions, compute ceiling and failure log.
Registration never implies execution authority.

## Current refusal reasons

- WRF 4.8.0 is only candidate-locked pending a consistent Release recheck;
- WRF-Chem, WPS, schemes and third-party dependencies are not jointly admitted;
- no real or synthetic experiment input is admitted by this batch;
- no build or compute environment, budget or carbon ceiling is admitted;
- no qualified expert owner is assigned;
- TianJi-Environ exposes curated artifacts rather than a complete runtime;
- autonomous code execution patterns remain reference-only and require a later
  sandbox and permission review.

The gate therefore returns `REFERENCE_REVIEW_INCOMPLETE`.
