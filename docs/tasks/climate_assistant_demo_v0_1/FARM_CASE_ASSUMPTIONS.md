# CA-DEMO-001 — Farm Case Assumptions and Calculation Skeleton

标识：`SYNTHETIC_DEMO_ONLY / NOT_A_REAL_FARM`  
规划视野：未来 10–20 年；不指定真实地址、河流、含水层或 licence。

## 1. 固定虚构输入

| 项目 | 演示输入 | 证据类型 |
|---|---:|---|
| 总面积 | 100 ha | Issue #124 固定假设 |
| 拟灌溉饲草 | 10 ha | Issue #124 固定假设；不是现状或许可 |
| 牛 | 20 头 | Issue #124 固定假设；品种/体重/阶段未知 |
| 常驻工作人员 | 2 人 | Issue #124 固定假设；不是所需人数 |
| 设施 | 住宅、设备棚、储水设施 | 是否存在、容量、状态均仅作案例结构 |

## 2. 必须保持未知

水源种类、与天然水体/含水层关系、Water Access Licence、Basic Landholder Right、Water Sharing Plan、取水/用水/供水工程批准、share 与当期 allocation、限制通知、可靠供水率、可达储量、补给与泵率、水质；作物/牧草、土壤、灌溉系统与效率、净灌溉需水深度；牲畜类别与饮水率；人员生活用水、设施用水、季节性活动、工时、技能和安全阈值。

## 3. 水量账

同一时期内：

`总需求 = 灌溉 + 牲畜 + 人员生活/建筑 + 其他已定义用途`

若输入的是**净灌溉需水深度**：

`灌溉体积 (ML) = 面积 (ha) × 净灌溉需水深度 (mm) × 0.01 ÷ 灌溉效率 e`

本案例面积 10 ha，因此只可化简为：

`灌溉体积 = 0.1 × d ÷ e ML`

其中 `d` 是经作物—土壤—气象方法确定的净补水深度（mm），`0 < e ≤ 1`。因为 `d` 和 `e` 均未知，不能给出 ML 数值。若输入已是毛灌溉深度，不再除以效率。`1 ha·mm = 0.01 ML`，所以量纲闭合。

供给侧另列：

`期内合法且可靠的可用供给 = 可合法取得的来水 + 期初可达储量 + 合法补给 - 不可达死库容 - 输配/蒸发/渗漏/污染损失`

年度总量不能替代最干月份、热浪或泵/电中断期间的供需比较；储水容积不能替代补给可靠性；物理存在的水不能替代合法取用条件。

## 4. 气候—资源解释链

`区域升温/热日增加 + 降雨可靠性与季节分布变化 + 火险天气增加`
→ `饲草需水与生长窗口、牲畜热负荷和饮水、开放水面/土壤损失、泵管路及电力连续性、户外工时与安全窗口发生压力`
→ `需求、供给、储量、输配能力和合法取用条件必须按季节对齐`
→ `比较维持规模、先改善管理、分阶段改变生产`
→ `用现场量测、许可核验、农业/水务/工程专业审查后再决策`。

这是因果假设框架，不是对该农场已经发生或必将发生事件的预测。
