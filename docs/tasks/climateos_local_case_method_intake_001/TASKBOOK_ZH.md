## 1. 目标与完成条件

推进两条相互关联、分别验收的研究线：

- **A 本地案例线：**优先Cooma及Snowy Monaro区域，查清填埋场和污水处理设施的公开身份、废物/污水负荷、工艺、历史运行、环境监测与同期气象资料，选择一个证据较完整的主案例。
- **B 方法验证线：**优先澳大利亚公开研究，寻找合法可取得、甲烷与气象时空对齐的原始数据。澳洲候选不足时，可单列一个国际方法参考案例，不能把国际资料当作本地证据。

两线不必来自同一设施。A有地图或水质资料，不代表B已有甲烷观测；B复现国外研究，也不代表方法已在Cooma验证。最终交付必须说明每线实际取得了什么、缺什么、能做哪一步。

## 3. A线：本地案例与资料可行性

### 3.1 首选范围

Cooma为首选，Snowy Monaro区域另选至多一个有更完整公开资料的填埋场或污水设施作对照。首轮最多核查3个独立场址；PR136中共用坐标的填埋、堆肥、reuse shop不能算3个独立场址。不要为了凑沿海/内陆比较跳到大量不相关设施。

### 3.2 资料入口与待核验内容

- Council公开污染监测页、环境管理计划、许可和监测位置图。先检查水质、地下水、渗滤液资料；不预设其中含甲烷。
- Council历年年报、公开废物策略、资产管理计划和污水公开报告。寻找逐年入场废物量、组成/分流、填埋历史、收集/燃烧运行、污水流量、有机负荷与处理工艺。
- NSW EPA公开许可及持证者监测资料。许可证要求什么、公开资料实际测了什么，分别记录。
- BOM站点目录及可用历史观测，核查站点身份、距离、高度、变量、时间步、缺测、时区和许可。绝对站压与海平面订正压分开，日资料不能伪造小时气压变化。
- 复用GA设施点位和已有GIS。新增地形、海岸线资料只有确有必要、合法且范围受限才取得；位置背景不能替代气体观测。

首轮优先精读至多8份最相关官方资料，避免批量抓取几十年大PDF。数据有则记录具体页码、表格、原始单位与适用年份；没有则标记NOT_FOUND_IN_REVIEWED_MATERIAL，不能写成数据一定不存在。

已知起点（仅来源入口，不代表已取得原始数据）：

- [Snowy Monaro污染监测与填埋场计划](https://www.snowymonaro.nsw.gov.au/Environment-Waste-and-Weeds/Waste-and-Recycling/Environment-Operations-Act-and-Pollution-Monitoring)
- [Council年报与资产管理计划](https://www.snowymonaro.nsw.gov.au/Council/Integrated-Planning-and-Reporting)
- [NSW EPA监测资料发布说明](https://www.epa.nsw.gov.au/Licensing-and-Regulation/Licensing/Environment-protection-licences/Licensing-under-POEO-Act-1997/publishing-and-providing-pollution-monitoring-data)
- [BOM气象站目录](https://www.bom.gov.au/climate/data/stations/)
- [CSIRO甲烷数据目录](https://data.csiro.au/categories/kw/Methane)：逐项识别实测、清单与模型输出，不能统称现场观测。

### 3.3 A线输出

设施身份对照表、公开资料与许可登记、逐年活动数据表（缺失为null）、监测变量清单、气象可用性矩阵、空间/时间对齐矩阵，以及主案例选择理由。

可做有限的表格转录与单位/时间一致性核对；原表保留，转录可追溯。没有独立气体观测时停留在案例与证据可行性，不输出本地甲烷排放或减排量。

## 4. B线：合法原始数据与方法验证

### 4.1 候选顺序与上限

先查澳大利亚研究机构、大学正式数据仓库及作者公开数据声明，优先填埋场，其次污水处理。首轮最多3个**新的**候选数据集。国际参考必须单独标明地点与迁移限制。

之前被拒或明确停止的NJ/NY、Victoria按需申请、Egypt/Mendeley及其他登记入口继续保持停止；不能改API、镜像、文件URL或账户重试。搜索结果再次出现，不算新候选，不恢复下载。若作者声明仅按需提供，记为CONTACT_REQUIRED，不替用户发信。

### 4.2 数据准入门槛

候选必须依次经过：

1. **来源与许可：**官方仓库/作者正式入口、固定版本、文件清单、下载/保存/分析许可与署名要求。公开可见不自动等于允许再分发。
2. **实际取得原件：**记录文档中提供的文件URL、获取时间、MIME、字节数、SHA-256；页面可读不等于CSV已取得。禁止猜测未公开端点或绕过403/登录。
3. **结构与语义：**原字段、单位、干湿基准、实际/参考体积、仪器、校准、检测限、QC、缺失、背景处理和时间基准。
4. **空间与测量算子：**设施、排放区域、塔/移动/箱法位置、高度、风场与footprint。浓度、通量、反演结果分别标识。作者反演结果不是独立直接观测真值。
5. **时间支持：**原生采样、插值和聚合分开。气压变化研究必须有足够分辨率的实际气压；温度响应应说明测到空气还是过程体温。雨量不能直接替代填埋体水分。
6. **独立性与可比性：**标签是否已使用同一气象驱动反演，是否存在泄漏；哪些数据可作独立验证、哪些仅作方法输入或背景。

没有质量文件不能假装无误差；没有原件不运行所谓真实数据QC。记录每个门槛PASS / GAPS / BLOCKED及证据。

### 4.3 获准的小型验证范围

本任务允许对合法取得、通过上述基本准入的公开原始文件做读取、结构/QC审计、单位转换、原时间步与覆盖统计、背景/变量定义核对及可复算描述图表。复用已验证P1转换时保留仪器基准，不把混合比变化解释为源强变化。

若原文、代码、输入和预期输出齐全，可复算一个**作者已公开的描述性统计或聚合结果**，比较数值与误差，并区分复算一致性与独立科学验证。

**当前不授权**根据真实设施数据拟合P2阀系数、P4温湿响应、反演源强、运行新的设施FOD排放估计或比较模型准确率。这些工作须在数据准入报告与ChatGPT评审后另获Founder授权。若只能取得作者汇总表，则只复核汇总表，不能冒充原始数据验证。

### 4.4 B线输出

候选与停止台账、许可/文件清单、原件收据与哈希、schema与QC报告、时间/空间/观测算子说明、实际执行脚本与结果、独立性和验证资格判定。若未取得可用数据，交付完整失败证据，不编造替代数据。

## 5. 两线共同的地理与气象字段

沿用PR137研究字段：facility_id、independent_site_id、经纬度/CRS、海拔/垂直基准、传感器离地高度、距海距离/岸线版本和算法、站压、海平面订正压、dP/dt、风速风向、温湿、降雨、稳定度、设施负荷/工艺/集气状态。

每项同时保存来源、版本、许可、原件哈希、观测时段、原时区/UTC、单位、空间代表性、精度/不确定度和缺失原因。未知保持null，禁止默认为0。

距海距离与经纬度是位置描述/代理；实际气压、压差、温湿和风才是相应机制的过程输入。沿海/内陆差异先检查工艺、负荷、集气与样本重叠，不预设因果或任设分组阈值。
