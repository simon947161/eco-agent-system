**P2 pressure/storage/venting:** implement the smallest *explicitly illustrative* lumped gas-storage mass balance with specified boundary pressure, pressure tendency, internal/external differential, storage and venting flux, nonnegative stocks and stated numerical stability. **P3 baseline FOD:** implement an isolated IPCC 2006 annual solid-waste FOD reference case (with 2019 refinement as separately versioned optional comparison, not mixed parameter tables). Validate exact time step, cohort inventory, DDOC stock, delay convention, methane generation, recovered methane and oxidation terms, kg/Gg conversions, and source equation/table provenance. Do NOT modify AWT2015 statutory formulas, generate credits or compare tCO2e credits to observed physical CH4.

**P4 nested climate-response hypothesis:** define C0 as identical to P3 under the same temporal discretization, input history, initial inventory and collection/oxidation assumptions. Demonstrate neutral-response C1 == C0 numerically; vary temperature and moisture separately; show time response, annual integral, sensitivity and parameter uncertainty/limits.
