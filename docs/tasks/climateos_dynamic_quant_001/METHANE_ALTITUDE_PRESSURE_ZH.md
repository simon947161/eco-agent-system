## 2. 土地和海面不自带两种固定气压

同一高度也有天气性气压变化；高海拔通常气压较低，是上方空气柱重量较小。海拔、离地高度、气压和天气系统必须分别记录。**海平面订正气压不是设施所在位置的实测绝对气压**，不能直接拿来做当地气体密度换算。[NOAA/NWS 气压定义](https://www.weather.gov/bou/pressure_definitions)

研究时至少保存：海拔与垂直基准、传感器离地高度、站点绝对气压 P、温度 T、水汽、时间和气压变化率 dP/dt。天气图上水平气压梯度与输送有关；填埋体内部对外的压差与逸散有关；它们也不是同一个变量。

## 3. “有多少甲烷”有六种不同问法

|量|常用单位|能说明什么|
|---|---|---|
|排放速率 Q / 累积排放质量|kg CH4/h / kg CH4|源向环境释放的量；浓度不能直接替代|
|单位面积质量通量 F|mg CH4/(m²·h)|有明确面积、足迹和采样方法的交换量|
|体积质量浓度 c|mg CH4/m³|实际温压下单位空气体积的甲烷质量|
|干空气摩尔分数 x|ppb、ppm|甲烷分子占干空气分子的比例；NOAA 常用这一量|
|质量混合比 r|kg CH4/kg dry air|甲烷质量相对干空气质量；不是 ppm 的同义词|
|柱总量 / 柱平均摩尔分数 XCH4|molecules/cm² / ppb|柱内分子总数 / 按空气柱与仪器敏感度加权的比例；二者不同|

同一气团若只膨胀、没有混合、源汇或化学反应，干摩尔分数不因气压下降而自动下降。mg/m³ 却可下降，因为每立方米空气的分子数少了。**“稀薄”不自动等于“甲烷比例更低”**；与背景空气混合才是另一种稀释过程。[NOAA CarbonTracker-CH4 定义](https://gml.noaa.gov/ccgg/carbontracker-ch4/glossary.html)

理想气体近似下，用 SI 单位：

\[
c_{CH4}=x_{dry}(P-e)M_{CH4}/(RT),\qquad
r=x_{dry}M_{CH4}/M_{dryair}.
\]

e 为水汽分压；x 输入 mol/mol，不能把 ppm 数字直接代入。若仪器报告湿摩尔分数，则先统一干湿基准。标况 m³ 还必须声明参考温度、压力和干湿条件；质量排放 kg/h 不能因换成另一个海拔的体积单位而凭空改变。

**算术例子，非现场数据：**固定干空气 x=2 ppm、T=293.15 K，P 从 101325 Pa 改为 80000 Pa，c 约从 1.334 降为 1.053 mg/m³；x 仍为 2 ppm，质量混合比均约 1.108 mg/kg dry air。这个约 21% 的体积浓度差不能解释为减排 21%，更不是温室效应减少 21%。[可复算示例](pressure_example.py)及[运行结果](pressure_example_output.json)固定了全部假设；压力没有映射成某座山的真实海拔。

## 4. 源强、输送和气压：填埋场与污水厂分别看

**填埋场：已有实测证据，但不是 Cooma 的结论。**Xu 等 2014 年研究美国 Bluff Road 填埋场，连续涡度相关观测发现降压阶段排放增强、升压阶段受抑，解释为气压抽吸/储气释放。作者明确限定：当时该场没有主动集气，不能直接套用到有负压集气的填埋场。它研究的是随时间变化的气压，不是把不同海拔的垃圾场放在一起就能推得同一系数。短期逸散变化也不等于甲烷生成量立即改变。[原始论文，DOI 10.1002/2013GB004571](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1002/2013GB004571)

**污水处理：溶解、产气和释放分开。**在适用的稀溶液平衡近似下，Henry 定律把溶解甲烷与气相甲烷分压联系；温度不变、气相比例固定时，总压降低可降低平衡溶解浓度，但气液传质、液深/静水压力、过饱和、气泡、曝气和工艺决定实际释放速率。不能把平衡定律当作所有污水的瞬时排放公式。[NIST 甲烷水溶解数据](https://webbook.nist.gov/cgi/cbook.cgi?ID=C74828&Mask=10)

IPCC 废水指南区分厌氧产甲烷、进入曝气系统的溶解甲烷，以及 N2O 等路径；工艺、有机负荷和运行状态不可缺。地形背景气压不是取代这些输入的新排放因子。[IPCC 2019 废水处理与排放，第6章](https://www.ipcc-nggip.iges.or.jp/public/2019rf/pdf/5_Volume5/19R_V5_6_Ch06_Wastewater.pdf)

**浓度变化可能来自输送而非源变化。**山谷积聚、逆温、边界层深度、坡风、风向风速和背景甲烷均可能改变读数。固定 Q 时，c 或 x 可随天气变化；固定观测 x 时，Q 也可能不同。反演需要观测算子、适用气象场和独立验证。低于检测阈值也不是零排放。本轮没有足够资料判断 Cooma 是否出现这些机制。

## 5. 压力展宽是真的，但不直接给出增暖倍率

分子碰撞会改变吸收谱线宽度。HITRAN 用压力和温度相关的 Lorentz 展宽、Doppler 展宽与 Voigt 等线型描述。相同温度下、通常的孤立谱线模型中，降低压力使碰撞展宽变小；归一化线型将吸收在谱线上重新分布，不能说“吸收带变窄，所以甲烷分子失去相同比例的吸热能力”。积分线强与线型宽度是不同参数。[HITRAN 参数定义与线型公式](https://hitran.org/docs/definitions-and-units/)

实际谱段还涉及饱和、与水汽/其他气体的重叠及空气柱。Etminan 等用辐射传输计算表明，甲烷强迫还包含短波贡献和谱带重叠影响，不能靠一个压力比例代替。[原始辐射研究，DOI 10.1002/2016GL071930](https://doi.org/10.1002/2016GL071930)

因此须先说明比较对象：同摩尔分数、同分子柱量、同排放质量，还是同几何路径？这些实验保持不变的量不同，结论可不同。辐射传输需整层 P(z)、T(z)、水汽和气体廓线、云、地表温度/反照率、太阳条件及统一通量诊断面；局部吸收系数变化不等于顶层净辐射强迫，更不直接等于地表升温。

## 6. 全球气候效应不能按场址海拔直接折价

甲烷寿命足以支持大尺度混合，其气候作用不仅是直接吸收，还包含通过化学改变臭氧、平流层水汽和自身寿命等作用。源排放、混合后的大气负荷、辐射强迫、温度响应，是不同步骤。[IPCC AR6 第6章](https://www.ipcc.ch/report/ar6/wg1/chapter/chapter-6/)

相同质量排放在不同地点的响应可能受化学和输送条件影响，但没有本轮证据支持“高海拔每公斤甲烷必然更暖/更冷”的通用规则。GWP 是给定时间范围与定义下的相对积分气候指标，不是给每个地方乘一个海拔系数的许可证。本稿不计算场址 GWP、温升、碳信用或法定责任。

## 7. ClimateOS 怎样把这个问题做成可验证研究？

以下为建议方案，尚未开展现场采样、拟合或物理模型运行。

|步骤|具体输入和比较|验收与停止条件|
|---|---|---|
|设施和空间身份|复用 PR136 点位；核验填埋区、污水工艺单元、真实排放口、地形与传感器高度|共址记录不当独立场址；点位不当源边界；身份不清停止归因|
|共同时间与仪器 QA|UTC 时戳、原时区、采样间隔、P/e/T、干湿基准、校准、检测限、不确定度与有效期|绝对站压与海平面订正压分栏；原值保留；缺失不补零；时窗或量纲不一致则不合并|
|填埋场天气过程|覆盖升压、降压和相对平稳的多个独立天气事件；同步 CH4、风/湍流、覆盖层温湿、集气负压和运行日志；优先独立通量方法|预先定义 dP/dt 时间窗与滞后；按事件分训练/留出验证，控制序列相关；只测浓度则只报告浓度响应，不能称 Q 响应|
|污水处理过程|流量、有机负荷、工艺/曝气、温度、液深、溶解 CH4 和气体通量、集气数据|做质量收支与独立测量对照；分开产气、携带溶解气、释气、回收/氧化；另列 N2O，避免偏看 CH4|
|海拔效应辨识|先做单站天气性气压研究；后用多个高低海拔同类设施与相近负荷/工艺比较|一个站点的海拔是常量，不能从它的时间变化回归出海拔效应；两座不同工艺设施的差异不能直接归因于海拔|
|输送验证|固定或独立约束源强，准备同窗气象、地形、背景/下风向观测和高度基准|按风向/稳定度分层，检查可观测性、风场代表性和独立留出误差；静态河网距线结果不能当气体传播模型|
|辐射敏感性（另阶段）|选已有辐射传输工具，固定版本/光谱、背景廓线与边界；分别比较固定混合比与固定柱量，检查水汽/云敏感性|先做参考谱段与通量守恒/收敛验证；不一致物理廓线仅标诊断实验；输出光谱/通量，未计算完整 ERF 就不叫 ERF|

优先检验三条假设：H1 同站降压过程是否伴随更高逸散通量（有源强观测才可检验）；H2 观测变化中多少是 P/T/湿度换算、多少与真实混合输送有关；H3 控制工艺和负荷后，高低海拔设施是否还有可重复差异。允许无效应、反方向和证据不足结果。需要多少天和样本由先导噪声、独立事件数和预期效应决定，不预设三天足够。

现在缺少：Cooma 同期气体原始观测、站点绝对气压/温湿和三维输送条件、设施运行/气体收集资料、经核验的垂直位置与辐射廓线。D3 继续 DATA_NOT_READY；不重试此前被拒数据，不用纽约天气或合成气体填空。
