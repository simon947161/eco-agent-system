# Task123 Evidence Passport Pilot Case Template

## Purpose

Task123 provides a reusable template for future fictional or non-operational Evidence Passport pilot cases.

This template is documentation-only. It is not a runtime schema, API contract, database model, calculator, compliance engine, assurance engine, scoring engine, or automated decision workflow.

## Template Use Boundary

Use this template only for fictional, illustrative, or non-operational pilot cases.

Do not use it to generate validated carbon conclusions, public disclosure claims, compliance declarations, investment recommendations, construction authorizations, operational approvals, or automated decisions.

## Pilot Case Header

| Field | Required content |
| --- | --- |
| Pilot case ID | Fictional identifier only. |
| Pilot case title | Fictional and non-operational title. |
| Case type | Fictional / illustrative / non-operational. |
| Domain | Generic carbon, ESG, or environmental review context. |
| Real-world data used? | Must be `No` unless separately authorized and fictionalized. |
| Public disclosure use? | Must be `Not authorized`. |
| Operational use? | Must be `Not authorized`. |

## Fictional Case Disclaimer

```text
This pilot case is fictional, illustrative, and non-operational.
It does not evaluate a real organization, project, site, asset, customer, supplier, or disclosure.
It does not generate a validated carbon or ESG conclusion.
It does not authorize compliance, assurance, investment, construction, operation, approval, or public environmental claims.
```

## Claim Under Review

| Field | Drafting instruction |
| --- | --- |

## Recommendation Field

Use this field only for review-oriented next steps.

Allowed recommendation language:

- "Further human review would be required in a real case."
- "Expert review would be mandatory before any real-world use."
- "The fictional claim is insufficient for a conclusion."
- "Additional evidence categories would be needed before evaluation."

Disallowed recommendation language:

- "The claim is verified."
- "The project is compliant."
- "The disclosure is assurance-ready."
- "The organization should invest."
- "The project may proceed."
- "The claim may be publicly disclosed."

## Action-Authority Boundary

A CarbonOS / ClimateOS recommendation is not an action authority.

It may identify a possible next step, review requirement, or decision option, but it cannot authorize implementation, approval, construction, investment, compliance declaration, public claim, or operational action without the required human, expert, or governance approval.
