## Conditions to reconsider computation

At least one of the following scientific paths must be defined:

### Path A — checkpoint observation

- authoritative checkpoint identity;
- licence;
- checksum and size;
- matching architecture;
- bounded input fixture;
- target output and acceptance rule.

### Path B — published metric reproduction

- exact paper configuration;
- exact transformed data;
- evaluation code and metric;
- accepted compute/storage budget;
- human scientific reviewer.

### Path C — no-weight structural observation

- a specific question that can be answered without trained weights;
- a tiny lawful fixture;
- proof that execution teaches more than static reading;
- explicit prohibition on skill or forecast claims.

All paths additionally require:

- an approved locked-environment proposal;
- channel and terms resolution;
- SBOM and artifact hashes;
- isolated runtime and rollback;
- zero-cost confirmation or a separately approved Paid Decision Brief;
- a new explicit Founder authorization.
