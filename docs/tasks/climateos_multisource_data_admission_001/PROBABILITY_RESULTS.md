# 可复算公式与完整主结果

Wagga固定三站组合，目标1961–2020、实有46个SON年份。以下为实测月汇编的派生描述性频率，不是未来概率保证。JJA_JJA因基准23<24阻塞。SON_SON与JJA_SON共用46个响应年，92条有效模式配对**不是92个独立天气年**。完整120年槽见[PAIRED_DATA](PAIRED_DATA.json)，缺测为null。

## 公式及单位

- 原月雨量 `x[s,y,m]=raw_tenth_mm/10`，单位mm。`R[y,m]=(x1+x2+x3)/3`；任何站缺失则null。`R[y,SON]=Σ(m=9,10,11) R[y,m]`。这是固定点组合平均，不是面积雨量。
- 相位 `H[y,s]=warm if RONI>=0.5; cold if <=-0.5; neutral otherwise`，RONI单位°C；不是官方连续五重叠季事件标准。
- `t=median(R[1961:1990,SON])=158.1166667 mm`。干 `R<t`，湿 `R>t`，相等neither。分数实现精确阈值见independent-exact-audit，不把显示小数当测量精度。
- `p_h=k_h/n_h`；`Δ_nonphase=p_h−k_not_h/n_not_h`，`Δ_all=p_h−k_all/n_all`，暖冷差 `p_warm−p_cold`，均为频率差，不是因果效应。
- Wilson95：`[p+z²/(2n) ± z√(p(1−p)/n+z²/(4n²))]/(1+z²/n)`，z=1.959963984540054。独立二项假设不完全满足，必须同时看块区间。
- Type7分位数：排序后位置`h=(N−1)q`，邻值线性插值。20/80属于敏感性，不能称法定干旱标准。
- 留出训练Jeffreys `p=(k+0.5)/(n+1)`；`Brier=mean((p_i−I_i)²)`，无量纲。训练1961–90，测试1991–2020只合格20年，同一测试行比较训练相位法与训练无条件法。
