# 同一问题、不同数据支持的可比性

| 产品 | 空间/物理量 | 时间适配 | 本轮可做的比较 |
|---|---|---|---|
| NOAA GHCN-M v4 | 原三站月观测汇编、固定等权 | 1961–2020部分合格 | 已取得真实结果；只同版本重放 |
| SILO | patched站点或0.05°插值 | 理论长覆盖，载荷未取 | 不与观测无声混合；须新support及source codes |
| AGCD | 站网插值格点，非单站 | 长历史潜力；未取 | 不把地图像素当三站原观测 |
| POWER | MERRA-2衍生网格 | 1981起，基准不足24年 | 不能替代当前全窗；没有跨源数值差 |
| ERA5 | 再分析网格/累积约定 | 1940起；需身份及许可接受 | 未取；单位转换和网格代表性另审 |
| CMA | 中国站点候选 | 当前版本/许可UNKNOWN | 仅未来跨区域候选，不映射澳洲 |
| CASEarth | 产品依赖的遥感/生态 | UNKNOWN | 平台发现不等于数据准入 |

只有一个实际产品，**没有完成多产品数值交叉验证**。任务中的“多来源”是有界调查、准入策略与替代决定，不等于七产品已接通。当前长路径CSV只替代旧失败归档访问方式，保留PR148 Wagga站点支持；原method_version不重写，新method_version=multisource/1、新source_id=GHCNM_V4_PRCP_20261105_WAGGA。无格点混算/重采样伪观测。

下一版本若改变源/日期、geometry、单位、观测/插值语义或时间窗，都须新登记与读取前协议；源SHA/契约不一致即拒绝，不能接受latest文件静默替换。
