## ClimateOS Core Boundary

ClimateOS Core serves:

- environmental observation
- environmental evidence
- environmental validation
- environmental governance
- environmental action

Runtime, Agent, MCP, SDK, website, repository workflow, and Builder Dispatch are supporting mechanisms.

They are not the ClimateOS Core mission.

Any engineering work that cannot explain its environmental governance purpose must not enter ClimateOS Core.

## Forward Boundary

Future work must inherit A100-01 Environmental Mainline Protection Principle.

Any ClimateOS Core change after this freeze requires a Change Request or a new approved task.

BuildingOS remains an engineering laboratory or demonstrator unless Architecture Review approves migration back into ClimateOS Core.

The interactive website, if created later, remains a ClimateOS / BuildingOS demonstrator for human use testing and is not ClimateOS Core itself.

## Post-Freeze Rules

- Do not begin Task101 inside the Task100 closure commit.
- Do not introduce runtime implementation into frozen Foundation documents.
- Do not migrate BuildingOS engineering experiments into ClimateOS Core without Architecture Review.
