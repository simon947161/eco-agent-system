## 1. Vision

CCZPS 2.0 is not a single software product, a climate model, a digital twin platform, or a multi-agent framework.

CCZPS 2.0 is a governance architecture.

Its purpose is to help human society explore, compare, evaluate, and select better futures under climate, ecological, social, financial, and technological constraints.

Traditional climate planning asks:

> What will happen?

CCZPS 2.0 asks:

> What futures are possible?  
> Which future is worth implementing?  
> What governance process should guide that choice?

This shift defines the transition from prediction to possibility computing.

## 4. Possibility Computing Framework

Traditional planning:

```text
One Site → One Plan → One Future
```

CCZPS planning:

```text
One Site → Many Futures → Comparison → Selection → Implementation
```

This process is called **Possibility Computing**.

It does not aim to predict a single future. It aims to generate, compare, and govern multiple possible futures.
