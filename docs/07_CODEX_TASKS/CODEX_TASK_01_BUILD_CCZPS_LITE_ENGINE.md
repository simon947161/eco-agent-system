## 1. Objective

Build the first minimal working prototype of **CCZPS-Lite v0.1**.

The goal is to create a small, transparent, file-based demonstrator that can compare three alternative future pathways for Batlow:

```text
Path A: Water Priority
Path B: Energy Resilience
Path C: Ecology / Fire Buffer Priority
```

This is the first practical step toward turning the existing CCZPS / EcoEngine methodology documents into a runnable comparison engine.

Do not build a large platform.
Do not add a database.
Do not add external APIs.
Do not add heavy frameworks.

Build a simple engine that reads local JSON inputs and produces CSV and Markdown outputs.
