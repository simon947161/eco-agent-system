## What ClimateOS Is

ClimateOS is an evolving Earth System Governance Runtime architecture.

It connects observation, relationship, radar, evidence, validation, governance,
participation, cultivation, EcoChain, Proof of Reality, and future value
translation.

## What ClimateOS Is Not

ClimateOS is not a finished application, dashboard, NASA viewer, carbon
accounting product, automated validation system, or governance decision engine.

## How To Contribute

- Start with documentation and boundaries.
- Keep changes small and reviewable.
- Distinguish implemented, planned, and vision content.
- Use existing layer names and repository patterns.
- Run tests when changing code or when requested.
- Report created files, modified files, tests, and limitations.

## Where To Work

- Project governance: `00_PROJECT_CONTROL/` and `docs/governance/`
- ClimateOS layers: `01_CLIMATEOS_CORE/`
- Subsystem foundations: numbered OS folders such as `02_CARBONOS/`
- Templates and guides: `docs/`

## Safety Reminder

Do not add runtime integrations, APIs, authentication, downloads, databases, or
automated decisions unless a task explicitly asks for them.
