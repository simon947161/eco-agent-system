# TianJi-Environ — Independent Reference Framework

Date: 2026-07-12
Status: Research reference / not an implementation authorization
ClimateOS role: Mechanism Experiment Layer and Environmental AI Scientist Runtime
Primary roadmap range: Task1701–2099

## Purpose

TianJi-Environ is registered as an independent reference for converting atmospheric-environment research questions into structured mechanism hypotheses, controlled WRF-Chem experiments, diagnostic evidence chains and auditable conclusions.

## ClimateOS lessons

- prediction and association are not sufficient for mechanism claims;
- each causal link should have an explicit diagnostic;
- numerical models should perform scientific calculation while agents orchestrate bounded workflows;
- experiment configuration, model versions, inputs and evidence thresholds must be reproducible;
- `INCOMPLETE_EVIDENCE` and `MODEL_FAILURE` are valid scientific outcomes;
- human scientific review remains mandatory.

## Intended use

ClimateOS may adapt TianJi-Environ's workflow ideas into a general Mechanism Hypothesis Protocol, Numerical Experiment Contract and Mechanism Evidence Passport. Any WRF-Chem or other scientific-model pilot requires separate data, compute, licence and expert-readiness approval.

## Non-goals

- not proof of a general autonomous scientist;
- not permission to launch WRF-Chem experiments now;
- not evidence that numerical-model interventions equal absolute natural causality;
- not automatically combined with PhysMetrics.Weather or AICON.
